## 正文

### 1.1 电、电荷与电流：先建立画面

这一节只做一件事：把“电”从一个抽象名词，变成你能在脑子里看见的画面。后面所有公式，都是在这个画面上做加减乘除。

#### 1.1.1 电荷：电的“原材料”

想象一个水池，里面装了多少水，我们心里有数。电也一样，是一种“东西”，只是小到看不见。

一切物质由原子组成。原子中心是**原子核**，带正电；外围是**电子**，带负电。平时正负电量相等、互相抵消，物体就“不带电”；一旦电子被搬走或塞进来，平衡被打破，物体就带电了。

这种“带电的多少”叫**电荷**（charge），符号常用 `Q`，单位是**库仑**（coulomb，符号 `C`）。

库仑是一个很大的单位。1 库仑约等于 `6.24×10¹⁸` 个电子所带电荷量的绝对值。这个数不用记，有感觉就行：单个电子的电量小到夸张，所以人们成堆地数它们，就像用“吨”来数米。

两个够用的直觉：

- **同性相斥、异性相吸**：正正互推、正负互拉。
- **电荷只转移、不凭空产生**：这叫电荷守恒。摩擦起电不是“造出电”，而是把电子从一个物体搬到另一个物体。

材料按“电子能不能自由跑”分成三类：

| 类别 | 特点 | 常见材料 | 在 PCB 上的角色 |
|---|---|---|---|
| 导体 | 电子能自由移动 | 铜、金、银、铝、焊锡 | 铜箔走线、焊盘、过孔内壁镀铜 |
| 绝缘体 | 电子被束缚，几乎不导电 | 玻璃纤维与树脂组成的 FR-4、塑料、陶瓷、空气 | 基材、阻焊层、导线外皮 |
| 半导体 | 导电能力介于两者之间，而且可以控制 | 硅、锗 | 二极管、三极管、MOS 管、芯片的原材料 |

半导体先留个印象：芯片不是“更高级的铜线”，而是用“可控制的导体/绝缘体”堆出来的开关阵列。它什么时候通、什么时候断，由电压和掺杂决定。第 05～08 章会逐个拆开。

**这在板子上**：一块 PCB 就是“导体 + 绝缘体”的三明治。中间是玻璃纤维（绝缘），两面贴铜箔（导体）；蚀刻掉不要的铜，剩下的铜线就是电路。你以后画的每一根走线，本质上都是这里的“导体”。

#### 1.1.2 电流：电荷的定向移动

水在水管里流动，我们叫水流；电荷在导体里定向移动，我们叫**电流**（current），符号常用 `I`。

电流的大小，用“单位时间内流过某个截面的电荷量”来定义：

$$\begin{aligned}
I=Q / t
\end{aligned}$$

- `I`：电流，单位**安培**（ampere，符号 `A`）
- `Q`：电荷量，单位库仑（`C`）
- `t`：时间，单位秒（`s`）

所以 `1 A = 1 C/s`：每秒钟有 1 库仑电荷流过这个截面。

这里要提前说清一个容易误会的地方：**电流的方向，物理上规定为正电荷流动的方向**，也就是从电源正极经外电路流向负极。但在金属导线里，真正移动的是带负电的电子，它们的方向正好相反。

这会不会矛盾？不会。这只是“记账约定”。就像地铁里人群往出口走，但你统计“客流方向”时可以从入口往出口记。工程上统一用“正电荷方向”，公式和符号才不容易乱。你只要记住：**算电路时按规定的电流方向算，不要一会儿按电子、一会儿按正电荷。**

电流还分两种情况：

- **直流**（DC，direct current）：方向不随时间改变，大小可以稳定，也可以有纹波。
- **交流**（AC，alternating current）：方向随时间周期性改变。家里插座就是交流，我们后面做实验只用隔离低压。

严格说，“直流/交流”描述的是随时间的变化方式，不是“电池/插座”的同义词。电池也可能被电路快速开关，变成脉冲电流；插座经过整流也能变直流。第 1.5 节会专门讲“随时间变化”这件事。

电流要持续流动，必须有**闭合路径**：从电源一端出发，经过负载，再回到电源另一端。路径断了，电流就停了（开路）；路径被一根几乎零电阻的线直接接通，电流会异常大（短路，1.2 节讲）。

**这在板子上**：电流从电源正极出发，经过稳压器、走线、过孔、器件引脚、负载，再经地线回到电源负极。走线不是“理想导线”，它有电阻，所以大电流路径会发热、会掉电压。第 1.3 节会算这件事。

#### 1.1.3 电压：两点之间的“电位差”

水为什么往低处流？因为高处和低处有高度差。电荷为什么愿意流动？因为两点之间有**电位差**。

**电压**（voltage）就是两点之间的电位差，符号常用 `U`（有些书用 `V`），单位**伏特**（volt，符号 `V`）。

电压的定义可以从能量理解：把 1 库仑电荷从一点搬到另一点，如果电场做了 1 焦耳的功，这两点之间的电压就是 1 伏特：

$$\begin{aligned}
1\,\mathrm{V}=1\,\mathrm{J}/C
\end{aligned}$$

这个定义现在不用深究，先记住一句更重要的话：

> **电压永远是两个点之间的事，不存在“某一点有 5V”这种绝对说法。**

我们说“这个引脚是 5V”，省略了参照点，完整意思是“这个引脚相对于电路的地（0V 参考点）是 5V”。如果换一个参考点，同一个点的“电压读数”会变，但两点之间的电压差不变。

这和身高很像：你说“他身高 1.8 米”，是以地面为参考；如果站在 10 米高的楼顶量，读数会变，但他和地面之间的高度差没变。电压也一样，**参考点决定读数，不决定电路里真实的电位差**。

电路里的**地**（GND，ground）通常被选作 0V 参考点。注意：这里的“地”不一定真的接到大地。它可能只是板上的一条公共回线，叫**信号地**；也可能是金属外壳，叫**机壳地**；还可能是通过隔离电源浮空的**隔离地**。它们不是一回事，后面第 11 课讲接口和隔离时会展开。

电压有正负。比如 `A 点比 B 点高 5V`，写成 $U_{AB}=+5\,\mathrm{V}$；反过来 $U_{BA}=-5\,\mathrm{V}$。负号只表示方向相反，不表示“比零小所以没有电”。

**这在板子上**：电源轨（3.3V、5V、12V）是对地电压；器件的“耐压”指的是它两端允许的最大电压差；万用表测电压时，表笔要分别接触两个点，读数是这两点之间的差。

**常见错**：把“电源电压”当成“某个电阻两端的电压”。比如 5V 电源串一个电阻和一个 LED，电阻两端并不是 5V，而是 `5V - LED 压降`。第 1.3 节会用算例纠正。

#### 1.1.4 电阻：对电流的阻碍

水在水管里流，会遇到管壁摩擦、弯头、阀门；电荷在导体里跑，也会遇到阻碍。这个阻碍作用叫**电阻**（resistance），符号常用 `R`，单位**欧姆**（ohm，符号 `Ω`）。

电阻的定义来自欧姆定律：

$$\begin{aligned}
R=U / I
\end{aligned}$$

- `R`：电阻，单位欧姆（`Ω`）
- `U`：电阻两端的电压，单位伏特（`V`）
- `I`：流过电阻的电流，单位安培（`A`）

所以 `1 Ω = 1 V/A`：在电阻两端加 1V，如果流过 1A，这个电阻就是 1Ω。

电阻的大小由材料、长度、截面积和温度决定。定性地说：

- 材料越难导电，电阻越大；
- 导体越长，电阻越大；
- 截面积越粗，电阻越小；
- 温度升高时，多数金属的电阻会变大（不是所有材料都这样，半导体通常相反）。

写成公式就是：

$$\begin{aligned}
R=\rho \times L / A
\end{aligned}$$

- `ρ`（读作“rho”）：电阻率，材料本身的属性，单位 `Ω·m`
- `L`：导体长度，单位米（`m`）
- `A`：截面积，单位平方米（`m²`）

这个公式现在不用代入复杂数字，但要记住它的三个结论：**长、细、材料差 → 电阻大**。PCB 走线为什么大电流要加宽？因为加宽就是增大 `A`，电阻和压降都会变小。

还要分清两个概念：

- **电阻**是物理性质，任何导体都有，哪怕是一根铜线。
- **电阻器**（resistor）是专门做出来、具有确定阻值的元件，原理图里用 `R` 表示，位号如 `R1`。

电阻器有额定功率。电流流过电阻会发热，超过额定功率可能烧毁。第 1.3 节会算。

电阻不一定是“线性的”。线性电阻满足 `U/I` 为常数；二极管、LED、灯丝、热敏电阻的 `U/I` 关系不是直线，不能简单套欧姆定律。这个区别在第 05 章讲二极管时会非常关键。

**这在板子上**：铜走线有电阻，过孔有电阻，连接器触点有电阻，电阻器本身更是故意做出来的电阻。小信号路径上，几欧姆可能无所谓；大电流路径上，几毫欧都会变成压降和热量。

#### 1.1.5 功率与能量：电到底在“干什么”

电流流过电阻会发热，灯泡会发光，电机会转。这些都是电在做功，也就是把电能转换成其他形式。

**功率**（power）是单位时间内转移或消耗的能量，符号 `P`，单位**瓦特**（watt，符号 `W`）。

最基本的公式是：

$$\begin{aligned}
P=U \times I
\end{aligned}$$

- `P`：功率，单位瓦（`W`）
- `U`：器件两端的电压，单位伏（`V`）
- `I`：流过器件的电流，单位安（`A`）

结合欧姆定律 $U=IR$，还能得到两个常用变形：

$$\begin{aligned}
P=I^{2} \times R \\
&P=U^{2} / R
\end{aligned}$$

这三个公式是同一件事的不同写法，用哪个方便就用哪个：

- 知道电压和电流：用 $P=UI$。
- 知道电流和电阻：用 $P=I^{2}R$。
- 知道电压和电阻：用 $P=\frac{U^{2}}{R}$。

**能量**（energy）是功率乘以时间：

$$\begin{aligned}
E=P \times t
\end{aligned}$$

单位是**焦耳**（`J`）。日常电费说的“度”，是千瓦时（`kWh`）：`1 kWh = 1000W × 3600s = 3.6×10⁶ J`。

功率和能量别混：

- 功率是“快慢”：1W 的灯，每秒钟消耗 1J。
- 能量是“总量”：1W 的灯亮 1 小时，消耗 3600J。

**这在板子上**：电阻的额定功率常见 0.125W、0.25W、0.5W、1W。算出实际功耗后，不能贴着额定值用，要留降额余量（比如按额定值的 50%～70% 设计，具体看温度和厂家要求）。一个 0.25W 的电阻上消耗 0.2W，虽然“没超”，但已经很热，长期可靠性会下降。第 02 章会专门讲选型。

#### 1.1.6 单位换算与数量级

电子电路里的数字跨度很大，从皮安到安培、从皮法到法拉。先建立“数量级感”，比死记换算表更重要。

常用前缀：

| 前缀 | 符号 | 倍数 | 例子 |
|---|---|---:|---|
| 皮 | p | 10⁻¹² | 10pF = 0.00000000001F |
| 纳 | n | 10⁻⁹ | 100nF = 0.1μF |
| 微 | μ | 10⁻⁶ | 10μF = 0.00001F |
| 毫 | m | 10⁻³ | 20mA = 0.02A |
| 千 | k | 10³ | 10kΩ = 10000Ω |
| 兆 | M | 10⁶ | 1MΩ = 1000000Ω |
| 吉 | G | 10⁹ | 1GHz = 10⁹Hz |

几个必须脱口而出的换算：

- `1 A = 1000 mA = 10⁶ μA`
- `1 V = 1000 mV`
- `1 Ω = 1000 mΩ`；`1 kΩ = 1000 Ω`；`1 MΩ = 1000 kΩ`
- `1 F = 1000 mF = 10⁶ μF = 10⁹ nF = 10¹² pF`
- `100 nF = 0.1 μF`
- `1 kHz = 1000 Hz`；`1 MHz = 1000 kHz`

做计算前，先把单位统一成“伏、安、欧、瓦、秒”。比如 `20mA` 要写成 `0.02A`，`10kΩ` 要写成 `10000Ω`。这一步不做，答案会差 1000 倍。

**这在板子上**：丝印上的 `103` 不是 103Ω，而是 `10×10³Ω = 10kΩ`；`104` 是 `100kΩ`。电容上的 `104` 是 `10×10⁴pF = 100nF`。这些标记法第 02、03 章会讲，现在先知道“数字不等于阻值本身”。

#### 1.1.7 停下来检查

1. 一个物体带负电，是多了电子还是少了电子？
2. `2 A` 的电流，10 秒内流过某截面的电荷量是多少库仑？
3. “这个引脚是 3.3V”这句话省略了什么？
4. 一根铜线被加粗后，电阻变大还是变小？为什么？
5. $P=UI$ 和 $P=I^{2}R$ 在什么条件下等价？
6. `100nF` 等于多少 `μF`？`10kΩ` 等于多少 `Ω`？

<details>
<summary>参考答案</summary>

1. 多了电子。电子带负电，负电荷过剩。
2. `Q = I × t = 2A × 10s = 20C`。
3. 省略了参考点。完整意思是“这个引脚相对于电路 0V 参考点是 3.3V”。
4. 变小。加粗增大了截面积 `A`，由 $R=\frac{\rho L}{A}$，电阻与截面积成反比。
5. 对线性电阻、且 `U` 是电阻两端电压时，由欧姆定律 $U=IR$ 可推出 $P=I^{2}R$。如果 `U` 拿的是电源电压而不是电阻两端电压，就不能直接代。
6. `100nF = 0.1μF`；`10kΩ = 10000Ω`。

</details>

### 1.2 电路的基本连接

#### 1.2.1 通路、开路、短路

一个能持续工作的电路，至少要有三部分：

- **电源**（source）：提供电压，推动电荷流动。
- **负载**（load）：消耗电能、完成工作的部分，比如 LED、电阻、电机、芯片。
- **连接路径**：把电源和负载连成闭合回路的导线、走线、接插件。

按路径状态，电路分三种：

| 状态 | 路径情况 | 电流 | 现象 |
|---|---|---|---|
| **通路**（closed circuit） | 闭合，电流能回到电源 | 正常 | 负载工作 |
| **开路**（open circuit） | 某处断开 | 近似为零 | 负载不工作 |
| **短路**（short circuit） | 电源两端被极低电阻直接连通 | 很大 | 发热、烧器件、电池危险 |

短路为什么危险？因为回路里几乎只剩电源内阻和导线电阻，按欧姆定律 $I=\frac{U}{R}$，电阻极小，电流会非常大。这个电流会在导线、接插件、电池内部产生大量热，可能烧毁器件、熔化焊锡、引燃附近材料，锂电池还可能发生热失控。

**短路不是“电压没了”**。短路时电源电压几乎都降在电源内阻和导线电阻上，负载两端反而接近 0V；但电流可能已经大到危险。所以“用万用表量到 0V”不能说明安全，必须断电查短路。

**这在板子上**：焊接桥连、锡渣、器件引脚搭到一起、电源与地接反、封装焊盘画错，都可能造成短路。第一次上电前，先断电用万用表通断档查电源正负之间是否直通，是基本习惯。

串联的特点：

- 流过每个器件的**电流相同**（同一根水管，水流量一样）。
- 各器件两端电压**相加**等于总电压：$U_{\text{总}}=U_1+U_2$。
- 总电阻**相加**：$R_{\text{总}}=R_1+R_2+\cdots$。

为什么总电阻相加？因为电荷要依次穿过每一段阻力，阻力当然越走越大。串联两个 10kΩ，总电阻就是 20kΩ。

**并联**：首首相连、尾尾相连，电流有多个分支。

并联的特点：

- 每个分支两端的**电压相同**（都接在同样的两个节点上）。
- 各分支电流**相加**等于总电流：$I_{\text{总}}=I_1+I_2$。
- 总电阻的倒数等于各分支倒数之和：

$$\begin{aligned}
1 / R_{\mathrm{tot}}=1 / R_1 + 1 / R_2 + \cdots
\end{aligned}$$

两个电阻并联时，有一个更顺手的形式：

$$\begin{aligned}
R_{\mathrm{tot}}=\frac{R_1 \times R_2}{R_1 + R_2}
\end{aligned}$$

两个 10kΩ 并联，总电阻是 `(10k×10k)/(10k+10k)=5kΩ`。**并联越并越小**，因为相当于给电流多开了一条路；总电阻一定小于最小的那个分支。这个直觉很重要，后面算负载、算上拉下拉都会用到。

串联分压、并联分流，是电路里最常用的两个“分配规则”。

#### 1.2.4 地（GND）只是参考点

原理图里经常看到一条横线、一个倒三角，或者 `GND`、`AGND`、`PGND`、`EARTH` 这些标记。零基础最容易以为“地就是没有电”，其实不是。

**地是人为选定的 0V 参考点。** 就像测身高以地面为 0，地只是“我们约定从这里开始量电压”。电路里的电流照样会流经地线，地线也有电阻，也会发热、掉电压。

常见的“地”至少有三种：

| 名称 | 含义 | 注意 |
|---|---|---|
| **信号地**（GND） | 板上大部分电路的 0V 参考，也是信号回流的公共路径 | 不是“万能吸收点”，大电流回流会抬高地电位 |
| **大地 / 保护地**（EARTH、PE） | 真正接到建筑物大地，用于安全保护 | 与信号地可能隔离，不能想当然短接 |
| **机壳地**（Chassis GND） | 金属外壳、屏蔽罩的参考 | 常与信号地通过电容/电阻/螺钉连接，具体看设计 |

还有**隔离地**：通过变压器、光耦、隔离电源隔开的地。隔离两侧的地之间可能有很高的电位差，直接用万用表把两边地夹在一起，可能损坏设备或引入危险。

**这在板子上**：`GND` 网络不是一个“点”，而是一大片铜、很多过孔、很多引脚。大电流（电机、电源）和小信号（传感器、ADC）共用一条地线时，大电流在地线电阻上产生的压降会叠加到小信号上，造成干扰。这就是后面要学的“回流路径”和“分区/单点接地”的由来。现在先记住：**地是参考点，也是电流的回流路径，不是垃圾场。**

### 1.3 欧姆定律与功率：电路计算的两把起子

#### 1.3.1 欧姆定律的三种形态

欧姆定律描述的是线性电阻上电压、电流、电阻三者的关系：

$$\begin{aligned}
U=I \times R \\
&I=U / R \\
&R=U / I
\end{aligned}$$

三个式子完全等价，只是把不同的量放在等号左边。做题时先看“已知什么、求什么”，再挑最省事的那一个。

- 已知电流和电阻，求电压：$U=IR$。
- 已知电压和电阻，求电流：$I=\frac{U}{R}$。
- 已知电压和电流，求电阻：$R=\frac{U}{I}$。

关键不是背公式，而是记住**每个量指的是同一段电路**。`U` 必须是这段电阻两端的电压，`I` 必须是通过这段电阻的电流，`R` 必须是这段电阻的阻值。三个量“对不上号”，算出来一定错。

#### 1.3.2 欧姆定律的适用条件

欧姆定律不是万能公式。它成立需要满足：

1. **线性关系**：电压和电流成正比，`U/I` 是常数。普通金属电阻、绝大多数电阻器在正常工作范围内满足。
2. **温度等条件基本稳定**：电阻会随温度变化，温度大幅变化时 `R` 不再是常数。
3. **是同一段导体/电阻**：不能拿电源电压和另一个器件的电流硬套。

下面这些**不能直接套欧姆定律**：

- 二极管、LED：正向电压和电流是指数关系，不是直线。
- 三极管、MOS 管：它们是受控器件，电流由控制端决定，不是简单 `U/R`。
- 灯丝灯泡：冷态和热态电阻差很多，开机瞬间浪涌电流大。
- 电机：启动、堵转、空载状态差别巨大。

所以看到“非线性器件”，要查数据手册或按器件模型分析，不能拿万用表量一个电阻值就代入。

#### 1.3.3 算之前先统一单位

电子电路里最常见的计算错误不是公式错，而是单位没统一。

规则很简单：**代入公式前，把电压换成伏（V）、电流换成安（A）、电阻换成欧（Ω）、功率换成瓦（W）、时间换成秒（s）。**

例如：

- `20mA` 写成 `0.02A`
- `10kΩ` 写成 `10000Ω`
- `100nF` 写成 `100×10⁻⁹F`
- `2ms` 写成 `0.002s`

如果题目给的是 `5V`、`10kΩ`，求电流，可以直接用 `I=5/10000=0.0005A=0.5mA`。如果先把 `10kΩ` 当成 `10` 代进去，就错了 1000 倍。

```svg
<text x="60" y="232" font-size="12" fill="currentColor">U_R + U_LED = 5V；R1 = (5V - 2V)/5mA = 600Ω，取 620Ω 更稳</text>
<text x="60" y="256" font-size="11" fill="currentColor">电阻功耗 P = I²R = (5mA)²×620Ω ≈ 15.5mW，0603 封装足够</text>
</svg>
```

电阻和 LED 串联，流过它们的电流相同。电源电压 5V 分在两部分上：

$$\begin{aligned}
U_R + U_{\mathrm{LED}}=5\,\mathrm{V}
\end{aligned}$$

**第二步：求电阻两端的电压。**

LED 正向导通时，两端大约有 2V 的压降（具体查手册，且随电流、温度变化）。所以电阻两端不是 5V，而是：

$$\begin{aligned}
U_R=5\,\mathrm{V} - 2\,\mathrm{V}=3\,\mathrm{V}
\end{aligned}$$

**第三步：用欧姆定律求电阻。**

目标电流 5mA = 0.005A：

$$\begin{aligned}
R=U_R / I=3\,\mathrm{V} / 0.005\,\mathrm{A}=600\,\Omega
\end{aligned}$$

600Ω 不是常用阻值，选标准系列里最接近的 **620Ω**。

**第四步：复核实际电流。**

$$\begin{aligned}
I=3\,\mathrm{V} / 620\,\Omega \approx 0.00484\,\mathrm{A}=4.84\,\mathrm{mA}
\end{aligned}$$

和 5mA 很接近，可以接受。实际还要考虑电源容差、LED 压降离散性、电阻容差。

**第五步：算电阻功耗。**

$$\begin{aligned}
P_R=U_R \times I \approx 3\,\mathrm{V} \times 0.00484\,\mathrm{A} \approx 0.0145\,\mathrm{W}
\end{aligned}$$

选 0.25W 电阻远远够用。

**第六步：做一次保守上界。**

如果电源偏高到 5.25V、电阻偏小到 646Ω（620Ω ±5% 的下限），并且极端假设 LED 压降为 0V：

$$\begin{aligned}
I_{\max}=5.25\,\mathrm{V} / 646\,\Omega \approx 8.13\,\mathrm{mA}
\end{aligned}$$

这个值是“最坏情况”的保守估计，用来确认不会超过 LED 允许电流。实际 LED 有正向压降，电流会比这个小。不能把绝对最大额定值（比如 30mA）当成推荐工作电流，仍要留余量和查温度降额。

**这道题的关键不是 600Ω，而是：电阻两端的电压 = 电源电压 − LED 压降。** 直接把 5V 代进 $R=\frac{U}{I}$ 会得到 `R=1kΩ`，电流只有约 3mA，LED 会偏暗；如果 LED 压降更低的型号，偏差更大。

#### 1.3.5 算例二：PCB 走线的电阻和压降

铜不是理想导体，走线有电阻。小信号可以忽略，大电流不能忽略。

**题目**：一条 1oz 铜、宽 1mm、长 100mm 的走线，流过 1A，估算压降和功耗。

1oz 铜厚约 `35μm = 35×10⁻⁶m`，宽 `1mm = 1×10⁻³m`，长 `0.1m`。截面积：

$$\begin{aligned}
A=35\times 10^{-6} \times 1\times 10^{-3}=3.5\times 10^{-8}\,\mathrm{m}^{2}
\end{aligned}$$

铜的电阻率约 `ρ = 1.7×10⁻⁸ Ω·m`（室温附近，具体随温度和铜纯度变化）：

$$\begin{aligned}
R=\rho L/A=1.7\times 10^{-8} \times 0.1 / 3.5\times 10^{-8} \approx 0.049\,\Omega
\end{aligned}$$

压降：

$$\begin{aligned}
U_{\mathrm{drop}}=I \times R=1\,\mathrm{A} \times 0.049\,\Omega \approx 0.049\,\mathrm{V}=49\,\mathrm{mV}
\end{aligned}$$

功耗：

$$\begin{aligned}
P=I^{2}R=1^{2} \times 0.049 \approx 0.049\,\mathrm{W}
\end{aligned}$$

49mV 的压降对 3.3V 逻辑可能已经接近允许范围，对 5V 电源也不小；0.049W 集中在一条细走线上，会局部升温。如果电流是 3A，压降和功耗都按平方/比例变大：压降约 0.147V，功耗约 0.44W。这就是大电流走线要加宽、加铜、多打过孔的原因。

注意：这是**估算**，没有算过孔、焊盘、连接器、铜厚公差、温度升高等。实际设计要用板厂参数、载流表或仿真复核。这里只建立“走线不是零电阻”的意识。

#### 1.3.6 功率、额定功率与降额

前面已经给出三个功率公式。工程上还要多问一句：**这个功率，器件受不受得了？**

电阻器手册里会写额定功率，比如：

- 0603 贴片电阻常见 0.1W
- 0805 常见 0.125W
- 1206 常见 0.25W
- 插件金属膜电阻常见 0.25W、0.5W、1W

额定功率是在规定环境温度、安装条件下的允许值，不是“超过一点也没事”。实际使用要**降额**：

- 电阻长期工作，建议按额定功率的 50%～70% 以内设计；
- 环境温度高、散热差、多个发热器件挨在一起时，还要再降；
- 脉冲、浪涌、启动电流要单独核算，不能只看平均值。

**这在板子上**：一个 0.25W 电阻实际耗 0.2W，看起来“没超”，但已经很热；长期高温会改变阻值、缩短寿命，甚至烧断。选型时宁可大一号，也不要贴着极限用。

功率和能量再区分一次：

- 功率是“每秒消耗多少能量”，单位 W；
- 能量是“总共消耗多少”，单位 J 或 kWh。

电阻的发热功率是瞬时/平均功率；一段时间的总发热量是 $E=Pt$。算温升要看热阻和散热条件，不能只拿功率对比额定值。

#### 1.3.7 常见错误清单

1. **拿电源电压当电阻电压**：串联多个器件时，每个器件只分到一部分电压。
2. **忘记 LED 正向压降**：`R=(5−2)/I`，不是 `R=5/I`。
3. **mA 没换成 A**：`5mA` 要写成 `0.005A`，否则结果差 1000 倍。
4. **把欧姆定律套在二极管/LED 上**：它们不是线性电阻，`U/I` 不是常数。
5. **忽略电阻功率**：算出阻值就选最便宜的 0603，结果一上电就发烫。
6. **把“额定功率”当“实际功耗上限”**：额定值要降额使用。
7. **忽略容差和温度**：`±5%` 的电阻，最坏情况要按边界算。
8. **把走线当理想导线**：大电流路径的压降和发热必须核算。

### 1.4 电路分析的两条“对账规则”

#### 1.4.1 为什么需要 KCL 和 KVL

简单电路可以靠直觉：串联时各元件电流相同，并联时各支路两端电压相同；电阻串联时，空载下电压按阻值正比分配（V1 : V2 = R1 : R2）。但电路一复杂，直觉就不够用了。比如一个节点连着三条支路，每条支路的电流是多少？一个回路里有电源、两个电阻、一个二极管，电压怎么分？

这时需要两条“对账规则”：

- **KCL**（基尔霍夫电流定律，Kirchhoff's Current Law）：电荷不会在节点上堆积，流进来的必须等于流出去的。
- **KVL**（基尔霍夫电压定律，Kirchhoff's Voltage Law）：绕一个闭合回路走一圈，电压升和电压降必须抵消，回到起点电位相同。

先定义三个词：

- **节点**（node）：两条或更多支路汇合的点。
- **支路**（branch）：连接两个节点的路径，通常是一段导线或一个器件。
- **回路**（loop）：从某个节点出发，沿支路走一圈回到该节点，途中不重复经过支路。

这两条规则本质上是**电荷守恒**和**能量守恒**在电路里的写法。它们对线性、非线性电路都成立，不依赖欧姆定律，所以比“分压公式”更通用。

这三句话都成立，但各有边界，后面会反复用到：

- 串联电流相同，对电阻、电容、二极管都成立；并联电压相同，对所有并联支路都成立。
- “电压按阻值正比分配”只对**电阻**成立，而且只在**空载**（输出端几乎不取电流）时成立。电容串联在直流稳态下电压按 `1/C` 分配，接上负载后电阻分压也会被负载效应改变。
- 所以这三句是“快速判断的起点”，不是“可以套用的公式”；要算准，仍然回到 KCL、KVL 和欧姆定律。


#### 1.4.2 KCL：节点上的电流账本

KCL 的一句话版本：

> 流入一个节点的电流总和，等于流出这个节点的电流总和。

写成式子：

$$\begin{aligned}
\sum I_{\mathrm{in}}=\sum I_{\mathrm{out}}
\end{aligned}$$

如果把“流入”记为正、“流出”记为负，也可以写成：

$$\begin{aligned}
\sum I=0
\end{aligned}$$

两种写法等价，选一种，全程不要混。

例子：一个节点连着三条支路，支路 A 流入 2mA，支路 B 流出 1mA，支路 C 的电流是多少？

```text
流入 = 流出
2mA = 1mA + I_C
I_C = 1mA（流出）
```

如果算出来是负值，说明实际方向和假设相反，不是“没有电流”。

KCL 的直觉很像十字路口的车流：不管路口里怎么拐，进路口的车总数必须等于出路口的车总数；车不会在路口堆起来。电荷也一样，节点不是仓库。

#### 1.4.3 KVL：绕回路走一圈的电压账本

KVL 的一句话版本：

> 沿一个闭合回路走一圈，所有电压升之和等于所有电压降之和；回到起点，电位差为零。

写成式子：

$$\begin{aligned}
\sum U_{\mathrm{rise}}=\sum U_{\mathrm{drop}}
\end{aligned}$$

或者把“升”记正、“降”记负：

$$\begin{aligned}
\sum U=0
\end{aligned}$$

例子：5V 电源、R1、R2 串联成一个回路。从电源负极出发，经电源升 5V，再经 R1 降 U1、经 R2 降 U2，回到负极：

$$\begin{aligned}
5\,\mathrm{V}=U_1 + U_2
\end{aligned}$$

这就是串联分压的来源。KVL 不需要知道电阻多少，先告诉你“总电压被分完了”。

符号约定很重要：

- 从 `+` 到 `−` 穿过一个器件，算**电压降**。
- 从 `−` 到 `+` 穿过电源，算**电压升**。
- 绕行方向可以自己选，选顺时针或逆时针都行，但一圈内要一致。算出的负号只表示实际极性与假设相反。

#### 1.4.4 用 KCL、KVL 解一个分压电路

题目：5V 电源，R1=10kΩ，R2=10kΩ 串联，求 R2 两端电压和回路电流。

**第一步：KVL 列电压账。**

$$\begin{aligned}
5\,\mathrm{V}=U_1 + U_2
\end{aligned}$$

**第二步：欧姆定律把电压换成电流。**

串联回路只有一条电流 `I`，流过 R1 和 R2：

$$\begin{aligned}
U_1=I \times R_1 \\
&U_2=I \times R_2
\end{aligned}$$

代入 KVL：

$$\begin{aligned}
5\,\mathrm{V}=I \times R_1 + I \times R_2=I \times (R_1 + R_2)
\end{aligned}$$

所以：

$$\begin{aligned}
I=\frac{5\,\mathrm{V}}{10\,\mathrm{k\Omega} + 10\,\mathrm{k\Omega}}=5\,\mathrm{V} / 20\,\mathrm{k\Omega}=0.00025\,\mathrm{A}=0.25\,\mathrm{mA}
\end{aligned}$$

**第三步：求 R2 电压。**

$$\begin{aligned}
U_2=I \times R_2=0.00025\,\mathrm{A} \times 10000\,\Omega=2.5\,\mathrm{V}
\end{aligned}$$

结果和分压公式 $V_{\text{out}}=V_{\text{in}}\frac{R_2}{R_1+R_2}$ 一致。分压公式不是新公式，它就是 KVL + 欧姆定律推出来的快捷方式。

**第四步：KCL 检查。**

这个串联回路只有一个回路电流，每个节点都是一进一出，KCL 自动满足：`I_in = I_out = 0.25mA`。如果电路有分支，KCL 才真正派上用场。

#### 1.4.5 负载效应：分压点为什么一接东西就跌

这是零基础最重要的“反直觉”之一。

前面算出 5V、10kΩ、10kΩ 的分压点是 2.5V。但这个 2.5V 是**空载**值。现在在输出点和地之间接一个 10kΩ 的负载，会发生什么？

负载 R_L 与 R2 并联：

$$\begin{aligned}
R_2 \parallel R_L=\frac{10\,\mathrm{k\Omega} \times 10\,\mathrm{k\Omega}}{10\,\mathrm{k\Omega} + 10\,\mathrm{k\Omega}}=5\,\mathrm{k\Omega}
\end{aligned}$$

下半段等效电阻从 10kΩ 变成 5kΩ，分压比变了：

$$\begin{aligned}
V_{\mathrm{out}}=\frac{5\,\mathrm{V} \times 5\,\mathrm{k\Omega}}{10\,\mathrm{k\Omega} + 5\,\mathrm{k\Omega}}=5 \times 5/15 \approx 1.667\,\mathrm{V}
\end{aligned}$$

从 2.5V 掉到 1.667V，跌了 0.833V，跌幅约 33%。

为什么？因为负载不是“白拿电压”，它要从分压点取电流。这个电流流过 R1，在 R1 上产生额外压降，输出自然被拉低。

从“输出端看进去”，这个分压电路不是一个理想电压源，而是一个带**内阻**的电压源。内阻等于 R1 与 R2 并联：

$$\begin{aligned}
R_{\text{out}}=R_1 \parallel R_2=5\,\mathrm{k\Omega}
\end{aligned}$$

负载 R_L 和 R_out 串联分压，负载越重（R_L 越小），拿到的电压越低。这个“内阻”概念是后面戴维南等效、信号源阻抗、传感器输入阻抗的基础，现在先建立直觉。

**结论**：

- 分压电路可以当**电压参考**（后级几乎不取电流时），不能当**电源**。
- 如果后级要取明显电流，需要加缓冲器（运放跟随器）、稳压器，或者把分压电阻取小（但功耗变大）。
- 万用表测分压点时，表的内阻也会形成负载。普通数字万用表输入阻抗很高（通常 10MΩ 量级），对 10kΩ 分压影响很小；但用低阻抗表或测高阻分压时，读数会明显偏低。

**这在板子上**：传感器分压、ADC 采样、基准电压，都要算“后级输入阻抗”。一个 100kΩ/100kΩ 的分压接进 10kΩ 输入，输出会严重偏离设计值，这不是器件坏了，是负载效应。

两个分压支路并联在同一个电源上：

- 上支路：R1 与 R2 分压，中点电压 $V_A=V_{\text{in}}\frac{R_2}{R_1+R_2}$。
- 下支路：R3 与 R4 分压，中点电压 $V_B=V_{\text{in}}\frac{R_4}{R_3+R_4}$。
- 输出电压是两点之差：`Vout = V_A − V_B`。

当电桥**平衡**时：

$$\begin{aligned}
R_1 / R_2=R_3 / R_4
\end{aligned}$$

或者交叉相乘：

$$\begin{aligned}
R_1 \times R_4=R_2 \times R_3
\end{aligned}$$

此时 $V_A=V_B$，`Vout = 0V`。

电桥的价值在于“测微小变化”：把其中一个电阻换成传感器（应变片、热敏电阻、光敏电阻），它的阻值随物理量变化，电桥就从不平衡输出一个小电压。这个电压很小，通常需要后面接仪表放大器或比较器。第 02 章讲电阻传感器、第 08 章讲运放时会再回来。

现在只要记住：**电桥不是新魔法，就是两个分压支路相减；平衡条件是阻值比例相等。**

5. 惠斯通电桥平衡的条件是什么？平衡时输出是多少？
6. KCL 和 KVL 只对线性电路成立吗？

<details>
<summary>参考答案</summary>

1. `I = 5mA − 3mA = 2mA`（流出）。
2. `I=5V/(2k+3k)=1mA`；`U2=1mA×3kΩ=3V`。
3. 负载取电流，负载与下臂电阻并联使等效阻值变小，同时电流在上臂电阻上产生额外压降。
4. $R_{\text{out}}=R_1\parallel R_2$；负载 R_L 与 R_out 串联分压，R_L 越小，分到的电压越小。
5. $\frac{R_1}{R_2}=\frac{R_3}{R_4}$（或 $R_1R_4=R_2R_3$）；平衡时 `Vout=0V`。
6. 不是。KCL 和 KVL 来自电荷守恒和能量守恒，对线性、非线性电路都成立；欧姆定律才要求线性电阻。

</details>

### 1.5 电压和电流随时间变化

前面几节默认电压、电流是稳定的：5V 一直是 5V，1mA 一直是 1mA。现实电路里，它们经常随时间变化：插座电压每秒来回变 50 次，开关电源每秒开关几十万次，单片机的引脚在高低电平之间跳变。

这一节建立一套描述“变化”的语言。不要求你会解微分方程，只要看到波形图、示波器屏幕或手册里的时序图，知道它在说什么。

#### 1.5.1 直流与交流

**直流**（DC，direct current）：电流方向不随时间改变。注意是“方向不变”，不是“大小绝对不变”。电池经稳压后的输出是直流；带纹波的电源输出也是直流，只是上面叠了一点波动。

**交流**（AC，alternating current）：电流方向随时间周期性改变。家里插座是交流；变压器次级、函数信号发生器输出的正弦波也是交流。

除了正弦，还有方波、三角波、锯齿波、脉冲等波形。它们都可能是交流，也可能是带直流偏置的交流。判断是不是交流，看**方向有没有周期性反转**，不看波形长什么样。

一个容易混淆的点：**“直流”和“交流”描述的是随时间的变化方式，“模拟”和“数字”描述的是信号的表示方式。** 这是两组不同的分类，不要混在一起。第 1.5.5 小节讲模拟/数字。

#### 1.5.2 波形、周期与频率

把电压随时间的变化画成图，横轴是时间，纵轴是电压，这张图就叫**波形**（waveform）。示波器屏幕就是实时画这个图。

一个周期性的波形，重复一次所用的时间叫**周期**（period），符号 `T`，单位秒（`s`）。

一秒钟内重复的次数叫**频率**（frequency），符号 `f`，单位**赫兹**（hertz，符号 `Hz`）。

周期和频率互为倒数：

$$\begin{aligned}
f=1 / T \\
&T=1 / f
\end{aligned}$$

例子：

- 中国市电频率 50Hz，周期 `T = 1/50 = 0.02s = 20ms`。
- 1kHz 的方波，周期 `1ms`。
- 1MHz 的时钟，周期 `1μs`。
- 2.4GHz 的 WiFi，周期约 `0.417ns`。

频率越高，周期越短，同样的走线长度更容易表现出“传输线”效应。这个后面讲高速设计时再说，现在只要会换算。

#### 1.5.3 幅值、峰峰值、平均值、有效值

一个变化的电压，有四个常用的“大小”描述，必须分清。

**峰值**（peak value，`Vp`）：波形在一个周期内达到的最大电压值（相对参考点）。如果波形有正负对称，峰值通常指正向最大值。

**峰峰值**（peak-to-peak value，`Vpp`）：一个周期内最大值与最小值之差：

$$\begin{aligned}
V_{pp}=V_{\max} - V_{\min}
\end{aligned}$$

**平均值**（average value，`Vavg`）：一个周期内电压的平均，也就是波形的“直流分量”。对称正弦波的平均值是 0；0～3.3V、50% 占空比的方波，平均值是 1.65V。

**有效值**（RMS，root mean square，均方根值）：一个周期内电压平方的平均值再开方：

$$\begin{aligned}
V_{\mathrm{rms}}=\sqrt{(1/T) \int v(t)^{2} dt}
\end{aligned}$$

这个公式看起来吓人，先不用手算积分。记住它的意义：**有效值是“产生同样热量”的等效直流电压。** 一个电阻 `R` 上，直流电压 `V` 的功率是 $\frac{V^{2}}{R}$；交流电压的瞬时功率是 `v(t)²/R`，平均功率就是 $\frac{V_{\text{rms}}^{2}}{R}$。所以有效值也叫“热等效值”。

常用波形的结论：

| 波形 | 平均值 | 有效值 |
|---|---|---|
| 恒定直流 `V` | `V` | `V` |
| 正弦波，峰值 `Vp` | 0 | `Vp / √2 ≈ 0.707Vp` |
| 0～`Vp` 方波，占空比 `D` | $DV_p$ | $V_p\sqrt{D}$ |
| 对称方波，±`Vp`，50% | 0 | `Vp` |

例子：中国市电标称 220V，这是**有效值**。它的峰值是 `220×√2 ≈ 311V`，峰峰值约 `622V`。所以说“220V”时，千万不要以为示波器上看到的峰值也是 220V；直接测市电峰值需要专用探头和隔离措施，零基础不要碰。

再比如 3.3V 单片机 PWM，50% 占空比：

$$\begin{aligned}
V_{\mathrm{avg}}=3.3 \times 0.5=1.65\,\mathrm{V} \\
&V_{\mathrm{rms}}=3.3 \times \sqrt{0.5} \approx 2.33\,\mathrm{V}
\end{aligned}$$

同样波形，平均值和有效值不一样。万用表打在 DC 档读的是平均值，打在 AC 档读的是交流部分的某种有效值；普通万用表按正弦校准，测方波/PWM 时读数可能不准，需要 true RMS 表或示波器。

#### 1.5.4 占空比与 PWM

**占空比**（duty cycle，`D`）是一个周期内“高电平时间”占整个周期的比例：

$$\begin{aligned}
D=t_{\mathrm{on}} / T
\end{aligned}$$

- `D=0%`：一直低。
- `D=50%`：一半高、一半低。
- `D=100%`：一直高。

**PWM**（pulse width modulation，脉冲宽度调制）就是保持周期不变，改变高电平宽度，从而改变占空比。它不是“输出一个可变的模拟电压”，而是“快速开关，让负载自己平均”。

PWM 的典型用途：

- LED 调光：快速开关，眼睛看到的是平均亮度。
- 电机调速：快速开关，电机电感把电流平滑掉。
- 开关电源：控制开关管导通时间，稳定输出电压。
- 舵机、加热器控制：用占空比表示目标位置/功率。

PWM 的频率要足够高，让负载“感觉不到”开关。LED 调光一般几百 Hz 到几 kHz；电机 PWM 常见几 kHz 到几十 kHz。频率太低会看到闪烁、听到啸叫；频率太高会增加开关损耗。

**这在板子上**：很多“模拟量控制”其实是 PWM。比如用单片机调 LED 亮度、调电机速度、调加热功率。看到 `PWM` 引脚，先问三个参数：频率、占空比、高电平电压。

#### 1.5.5 模拟与数字：两种表示方式

**模拟信号**（analog signal）：电压（或电流）在时间和数值上都连续变化。麦克风输出、温度传感器输出、正弦波，都是模拟信号。它的优点是能表示很细的连续变化；缺点是容易受噪声、温漂、传输损耗影响。

**数字信号**（digital signal）：只使用有限的几个离散电平表示信息，最常见的是两个电平：低电平（逻辑 0）和高电平（逻辑 1）。单片机 GPIO、UART、I²C、SPI 都是数字信号。

数字信号在物理上仍然是电压波形，仍然有上升沿、下降沿、过冲、振铃、噪声。它之所以“抗干扰”，是因为接收端只判断“高于某个阈值算 1、低于某个阈值算 0”，中间有一段容差；不是因为它变成了数学，不再受电学规律约束。

这里只建立三个词：

- **高电平**（VOH，output high voltage；VIH，input high voltage）：输出/输入被认作逻辑 1 的电压范围。
- **低电平**（VOL，output low voltage；VIL，input low voltage）：输出/输入被认作逻辑 0 的电压范围。
- **阈值**（threshold）：接收端判断高低的分界，通常是一个范围，不是某一个精确点。

数字逻辑门、时序、建立保持时间、信号完整性，放到阶段三“数字电路基础”系统讲。本章只要求你知道：**模拟是连续表示，数字是离散电平表示；两者都是电压/电流的具体形态。**

#### 1.5.6 边沿与带宽：先建立定性认识

数字波形不是瞬间从 0 跳到 1。真实波形有一个上升过程，从低到高所需的时间叫**上升时间**（rise time，`t_r`），通常定义从 10% 到 90%。从高到低叫**下降时间**（fall time，`t_f`）。

方波由很多不同频率的正弦波叠加而成：频率越高，边沿越陡。如果测量系统或传输通道的**带宽**（bandwidth）不够，高频成分被削弱，方波边沿就会变圆、变慢，甚至看起来像正弦波。

一个常用的估算关系（只适用于一阶系统、10%～90% 定义）：

$$\begin{aligned}
BW \approx 0.35 / t_r
\end{aligned}$$

例子：上升时间 10ns，对应带宽约 `0.35/10ns = 35MHz`。这意味着要观察这个边沿，示波器和探头带宽至少要在几十 MHz 以上，最好留 3～5 倍余量。

现在不用会算，只要记住：

- 边沿越陡，包含的高频成分越多；
- 带宽不够，边沿会被“抹圆”；
- 探头也有带宽和负载效应，不是接上去就绝对真实。

1. 50Hz 的周期是多少毫秒？1kHz 呢？
2. 一个 0～5V、25% 占空比的方波，平均值和有效值各是多少？
3. 正弦波峰值 10V，有效值约多少？峰峰值多少？
4. “220V 市电”的 220V 是峰值还是有效值？峰值约多少？
5. PWM 是“输出可变电压”吗？它为什么能让 LED 变暗？
6. 模拟信号和数字信号的根本区别是什么？数字信号是不是不受电学规律约束？
7. 上升时间 20ns，估算需要多高带宽的测量系统？

<details>
<summary>参考答案</summary>

1. `T=1/50=0.02s=20ms`；`T=1/1000=1ms`。
2. `Vavg=5×0.25=1.25V`；`Vrms=5×√0.25=2.5V`。

6. 模拟在时间和数值上连续，数字只用有限离散电平表示信息；数字信号物理上仍是电压波形，仍受噪声、边沿、带宽等电学规律约束。

### 1.6 安全与测量：先保证人和板子都活着

#### 1.6.1 电的危险在哪里

电伤人，主要不是“电压高”本身，而是**电流流过人体**，尤其是流过心脏、造成肌肉强直、灼伤或引发二次伤害。

人体电阻不是固定值：干燥皮肤可能几十 kΩ 到几百 kΩ，出汗、破皮、潮湿时可能降到几 kΩ 甚至更低。按欧姆定律，同样电压下，电阻越小，流过人体的电流越大。所以“36V 是安全电压”这种说法有严格前提（干燥、正常环境、特定标准），不能当成“所有低压都随便摸”。

大致感觉（仅用于建立危险意识，不是精确医学阈值）：

- 约 1mA：有轻微刺痛感。
- 约 10～30mA：肌肉可能不受控制地收缩，手可能“抓”住导线松不开。
- 约 50mA 以上，路径经过心脏：可能引发心室颤动，有生命危险。

家用 220V 交流电，在潮湿、破皮、单手到另一只手/脚形成回路时，电流足以致命。**零基础阶段不要测市电、不要拆电源适配器、不要碰任何带 220V 的板子。** 涉及市电的活，交给有资质、有隔离设备的人。

做低压实验也要养成习惯：

- 用**隔离低压电源**或电池供电，不用“裸”市电经整流桥直接搭电路。
- 用**限流电源**：先设一个较小的电流上限（比如 100mA 或更小），一旦短路，电源自动降压限流，而不是让电流无限大。
- 单手操作，另一只手不碰电路；不戴金属手表、戒指、项链。
- 用绝缘工具，桌面干净，不把板子放在金属上。
- 上电前确认电源正负、电压档位、极性；不确定就先用万用表量。
- 电解电容、大电容断电后仍可能存电。断电后等一会儿，用合适电阻放电，不要拿螺丝刀直接短路（会打火、烧触点、伤电容）。
- 锂电池短路、穿刺、过充可能起火。不要用普通电源直接给裸锂电池充电，要用带保护的充电电路。

**安全不是“小心一点”的口号，是一套固定动作**：断电、放电、限流、检查、再上电。每次按顺序做，不靠记性。

#### 1.6.2 第一次上电的正确顺序

新板第一次上电，最容易“啪”一声烧器件。按下面顺序，可以把损失降到最小：

1. **目视检查**：有没有锡渣、连锡、器件装反、极性电容反接、二极管方向反、芯片引脚歪、焊盘翘起。
2. **断电测短路**：万用表通断档，测电源正极与地之间是否直通。蜂鸣不代表一定坏（有些电路有低阻路径），但要和原理图对照，确认不是短路。
3. **空载/轻载上电**：限流电源先设小电流，电压从低到高，观察电流是否异常。
4. **测电源轨**：先测稳压器输出、各电源轨对地电压，确认不是 0V、不是偏高、不是振荡。
5. **摸温度**：断电后摸（或测温枪）芯片、稳压器、电阻，是否有异常发热。不要带电用手直接摸。
6. **接负载**：确认电源正常后再接负载，逐步加负载，观察电压跌落和电流。
7. **记录**：把电源电压、电流、关键点电压、温度、现象记下来。出问题时，这些数据比“好像不对”有用得多。

**“烟酒测试”不是好方法**。上电闻焦味、看冒烟已经晚了。限流电源和逐步上电才是可控的。

#### 1.6.3 万用表：最常用的四类测量

万用表（multimeter）是电压、电流、电阻、通断/二极管等测量的基础工具。先分清档位和表笔插孔。

**（1）直流电压档（DCV / V⎓）**

- 用途：测电源轨、器件两端电压、分压点。
- 接法：**并联**在被测两点上。
- 注意：表的内阻很高（常见 10MΩ），一般不会明显影响电路；但测很高阻值的节点时，表本身也会形成负载。
- 读数为负：表笔极性与实际电压方向相反，交换表笔即可，或按负数理解。

**（2）交流电压档（ACV / V~）**

- 用途：测交流电压，比如变压器次级、信号发生器输出。
- 注意：普通万用表按正弦波有效值校准，测方波、PWM、失真波形时读数可能不准；需要 true RMS（真有效值）表。
- 测市电有危险，零基础不要用普通表笔直接测插座。

**（3）直流电流档（DCA / A⎓）**

- 用途：测某条支路流过的电流。
- 接法：**串联**在支路中，让电流从表里流过。
- 注意：电流档内阻很小，**绝对不能并联在电源两端**，否则相当于短路。表内通常有保险丝，但不要依赖它。
- 负担电压：电流表串进去会引入一点压降，大电流测量时会影响电路，要查手册的 burden voltage。
- 换档前先断电，或至少先断开表笔；不要在带电情况下把表笔从电流插孔挪到电压插孔。

**（4）电阻档 / 通断档 / 二极管档（Ω / 🔊 / ➜|）**

- 电阻档：**必须断电测量**。带电测电阻，读数不准，还可能损坏表。
- 在路测电阻：其他并联路径会影响读数，通常要拆下一端或确认没有旁路。
- 通断档：测两点是否连通，蜂鸣不一定代表 0Ω，要看具体阈值；测电源短路时先断电。
- 二极管档：测二极管/LED 的正向压降，判断极性和好坏。普通二极管正向约 0.6～0.7V，LED 可能 1.8～3.3V 或更高，具体看型号。部分万用表二极管档提供的测试电流很小，LED 可能微亮或不亮，不代表坏。

**万用表的局限**：

- 精度、分辨率、温漂有限；
- 交流档通常假设正弦；
- 电流档有负担电压；
- 表笔、保险丝、接触电阻都会影响结果；
- 不能测高频、瞬态、噪声、波形，这些要示波器。

#### 1.6.4 示波器：只看“电压随时间怎么变”

示波器（oscilloscope）把电压随时间的变化画成波形。它比万用表多了一个关键维度：**时间**。万用表给你一个数，示波器给你“这个过程长什么样”。

基本组成和调节：

- **探头**（probe）：把电路节点接到示波器输入。常见 1× 和 10×。10× 探头把信号衰减 10 倍，输入电容更小、负载更轻，但屏幕上读数要乘 10（现代示波器通常能自动识别）。
- **接地夹**：探头的地线夹。它通常与示波器外壳/大地相连，不是“随便夹”的。
- **垂直档位**（volt/div）：每格代表多少伏。
- **水平档位**（time/div）：每格代表多少时间。
- **触发**（trigger）：让波形稳定显示。常用边沿触发，设置触发电平，选择上升沿/下降沿。
- **耦合**（coupling）：DC 耦合显示真实电压（含直流分量）；AC 耦合隔掉直流，只看交流波动。
- **带宽**（bandwidth）：示波器能准确观察的最高频率。带宽不够，边沿会被抹圆。
- **采样率**（sample rate）：每秒采样点数，要满足采样定理，通常至少是最高频率的 2 倍，实际要看边沿，建议更高。

示波器能测：

- 峰峰值、最大值、最小值；
- 周期、频率；
- 占空比；
- 上升时间、下降时间；
- 过冲、振铃、毛刺、噪声；
- 两路信号的相位关系（双通道）。

**安全红线**：

- 示波器探头的地线夹通常连着大地。**不能把地线夹夹到不是地的节点上**，否则可能通过大地形成短路，损坏设备。
- 测“浮地”或市电热地侧，需要隔离变压器或差分探头，零基础不要尝试。
- 探头也有输入电容和电阻，接到高阻、高频节点会改变波形。测开关节点、晶振时尤其要注意。
- 地线夹要尽量短，长地线会引入电感，测高频时波形失真。

**示波器和万用表的分工**：

- 想知道“现在多少伏”：万用表。
- 想知道“电压怎么变、有没有毛刺、边沿多快”：示波器。
- 想知道“电流波形”：用电流探头、分流电阻+差分探头，不能把示波器地线夹随便串进电路。

#### 1.6.5 误差、精度与记录

测量不是“读一个数就完了”。至少要知道这个数有多可信。

- **精度**（accuracy）：测量值与真实值的接近程度，通常写成“±(读数的 x% + 几个字)”。
- **分辨率**（resolution）：能显示的最小变化，比如 1mV。
- **量程**（range）：当前档位能测的范围，超了显示 `OL` 或溢出。
- **容差**（tolerance）：器件本身允许的偏差，比如电阻 ±5%、电容 ±10%。
- **负载效应**：表或探头接上去，改变了原电路。
- **负担电压**：电流表串入带来的压降。
- **温度、湿度、接触电阻、表笔好坏**：都会影响结果。

记录测量结果时，至少写清：

```text
日期/时间：
板子/版本：
测量点（网络/器件位号）：
仪器与档位：
电源条件（电压/限流值）：
负载条件：
环境温度：
预期值：
实测值：
现象/备注：
```

没有条件的测量数据，别人无法复现，也无法判断是电路问题还是测量问题。**“我量了，是 3.3V”不如“用 Fluke 17B+ DCV 档，限流 100mA，空载，TP1 对 GND，实测 3.28V，预期 3.3V”有用。**

#### 1.6.6 停下来检查

1. 为什么“36V 安全电压”不能理解为“36V 以下随便摸”？
2. 第一次上电，为什么要先用限流电源，而不是直接接稳压电源？
3. 测电压、测电流、测电阻，表分别怎么接？测电阻为什么必须断电？
4. 万用表电流档为什么不能并联在电源两端？
5. 示波器探头的地线夹为什么不能随便夹到任意节点？
6. 普通万用表测 50% 占空比的 3.3V PWM，DC 档和 AC 档分别大概读什么？为什么 AC 档可能不准？
7. 记录测量结果时，为什么必须写清仪器、档位、电源和负载条件？

<details>
<summary>参考答案</summary>

1. “安全电压”有干燥、环境、标准等前提；人体电阻会因出汗、破皮、潮湿大幅下降，低压也可能产生危险电流。零基础不要凭电压数字判断绝对安全。
2. 限流电源在短路或接反时会把电流限制在设定值，避免“啪”一下烧器件；直接稳压电源可能瞬间输出很大电流。
3. 电压并联；电流串联；电阻断电后并联在被测元件两端。带电测电阻读数不准且可能损坏表。
4. 电流档内阻极小，并联在电源两端相当于短路，会产生很大电流，可能烧保险丝、烧表或烧电源。
5. 示波器地线夹通常连大地，夹到非地节点可能通过大地形成短路，损坏设备或造成危险；浮地测量需要隔离/差分探头。
6. DC 档约读平均值 1.65V；AC 档读交流有效值，但普通表按正弦校准，对方波/PWM 不准，且不同表结果可能不同；准确值应用 true RMS 表或示波器算。
7. 没有条件的数据无法复现，也无法区分“电路本身如此”还是“测量方法/仪器负载造成的偏差”。

</details>

### 1.7 读图与查手册：看懂别人画的电路

#### 1.7.1 原理图到底在说什么

**原理图**（schematic）用符号和连线表示电路的逻辑连接，不表示器件实际长什么样、放在板子哪里。它是“电流该怎么走”的地图，不是“板子长什么样”的照片。

一张原理图至少包含四层信息：

1. **符号**：这个器件是什么类型（电阻、电容、二极管、芯片）。
2. **位号**（reference designator）：这个器件在板子上的唯一编号，比如 `R1`、`C2`、`U3`。
3. **参数/型号**：这个器件的值或具体型号，比如 `10kΩ`、`100nF`、`STM32F103C8T6`。
4. **网络**（net）：哪些点连在一起。网络是“电气上同一节点”的集合，可能跨很多页、很多器件引脚。

原理图里没有“导线必须从这里走到那里”的物理位置。两个引脚只要网络名相同，就是连在一起的；哪怕它们在图纸上离得很远，或者根本没画线。

#### 1.7.2 符号、位号、网络

常见符号先认个脸：

| 器件 | 符号要点 | 位号前缀 | 常见标注 |
|---|---|---|---|
| 电阻 | 折线或方框 | `R` | `10kΩ`、`103` |
| 电容 | 两条平行线 | `C` | `100nF`、`104` |
| 电解电容 | 一条直线+一条弧线/加号 | `C` | `10μF/16V`，注意极性 |
| 电感 | 连续半圆/线圈 | `L` | `10μH`，注意饱和电流 |
| 二极管 | 三角+竖线，竖线为阴极 | `D` | `1N4148`、`SS34` |
| LED | 二极管符号+向外箭头 | `D` 或 `LED` | 颜色、`Vf`、电流 |
| NPN 三极管 | 箭头向外 | `Q` | `MMBT3904` |
| PNP 三极管 | 箭头向内 | `Q` | `MMBT3906` |
| NMOS | 栅极、漏极、源极，箭头方向有讲究 | `Q` 或 `M` | `2N7002`、`AO3400` |
| PMOS | 与 NMOS 箭头/衬底方向相反 | `Q` 或 `M` | `AO3401` |
| 运放 | 三角形，两个输入一个输出 | `U` | `LM358`、`TL072` |
| 芯片/模块 | 方框，标引脚名 | `U` | `U1`、`U2` |
| 连接器 | 插针/插座符号 | `J`、`P` | `J1`、`P2` |
| 开关 | 触点符号 | `SW` | `SW1` |
| 晶振 | 晶体符号 | `Y` 或 `X` | `8MHz` |
| 保险丝 | 矩形/波浪线 | `F` | `F1`、`500mA` |
| 测试点 | 小圆点/靶标 | `TP` | `TP1` |

位号前缀不是死规定，但行业习惯很统一。看到 `U` 就知道是芯片/模块，看到 `Q` 就知道是三极管/MOS，看到 `J` 就知道是连接器。读图时先扫位号，能快速判断这块电路大概在干什么。

**网络**（net）是读图的核心。常见表示方式：

- 直接画线连接：线两端的引脚属于同一网络。
- **连接点**（junction dot）：两条线交叉处有实心圆点，表示连接；没有圆点通常表示只是交叉，不连接。
- **网络标签**（net label）：给一条线起名字，比如 `+3V3`、`GND`、`USB_D+`、`LED_EN`。同名标签在图纸任何地方都视为连接。
- **电源符号**：`VCC`、`+5V`、`+3V3`、`VBAT`、`GND`、`AGND`、`PGND`。它们本质上是全局网络标签，但用符号表示，减少画线。
- **跨页连接**：多页原理图里，同名网络标签跨页连接。

读图时最怕“以为连了，其实没连”：

- 两条线交叉没有圆点：通常不连。
- 两个网络标签拼写差一个字母：不连，而且可能是错误。
- `GND` 和 `AGND` 是两个不同网络：除非有 0Ω 电阻/磁珠/单点连接，否则不连。
- 芯片的电源引脚可能被隐藏，靠网络标签连接，不要以为没画线就没供电。

#### 1.7.3 读图的顺序

拿到一张原理图，不要从左上角逐行读。按下面顺序，先建骨架，再填细节：

1. **先找电源和地**：哪些电源轨（+5V、+3V3、VBAT、VIN）？哪些地（GND、AGND、PGND、EARTH）？电源从哪进来，经过哪些稳压器？
2. **找连接器**：对外接口在哪？USB、电源、排针、调试口。连接器决定了“外界怎么和板子打交道”。
3. **分功能块**：把图分成电源、主控、存储、接口、模拟、功率输出等块。先看块与块之间的信号，不要一开始陷进每个电阻。
4. **找主控/核心器件**：MCU、运放、电源芯片。看它的电源引脚、复位、时钟、启动配置、关键外设引脚。
5. **追信号路径**：从输入到输出，沿着网络名走。比如传感器 → 分压/滤波 → ADC；USB → 保护/匹配 → 主控。
6. **看无源网络**：上拉、下拉、分压、限流、RC 滤波、去耦。每个电阻电容都要能说出“它为什么在这里”。
7. **看保护与测试点**：保险丝、TVS、ESD、反接保护、测试点、跳线、DNP（不贴）器件。
8. **对照 PCB**：原理图网络和实际板子丝印、封装、引脚一一对应；注意 pin 1、极性、封装方向。

一个简单的读图例子：

（读图示例见图 1-6：R1 与 LED 串联，TP1 是测试点。）

- `R1` 和 `LED1` 串联，限制 LED 电流。
- `TP1` 是测试点，方便测 R1 与 LED 之间的电压。
- 如果 LED 不亮，先测 `+5V`、再测 `TP1`、再查 LED 极性和 R1 是否装错。
- 如果 `TP1` 电压接近 5V，说明 LED 可能开路或没装；如果接近 0V，说明 R1 可能短路或 LED 正常导通但电流很大。

#### 1.7.4 数据手册：先看三块，不要从头读到尾

**数据手册**（datasheet）是器件厂家给出的规格书。几十页很正常，零基础不要从头逐页读。先看三块：

**（1）绝对最大额定值（Absolute Maximum Ratings）**

这是“超过就可能永久损坏”的极限，不是正常工作范围。比如：

- 电源电压最大 6V；
- 某引脚电压范围 −0.3V～VCC+0.3V；
- 工作温度 −40～85℃；
- 结温最大 150℃；
- 输入电流最大 20mA。

绝对最大额定值不是“推荐使用值”。在 6V 下可能“没马上坏”，但寿命、参数、可靠性都没有保证。设计时通常要留余量。

**（2）推荐工作条件（Recommended Operating Conditions）**

这是厂家推荐的工作范围，比如：

- 电源电压 2.7～5.5V；
- 工作温度 −40～85℃；
- 输入电压范围 0～VCC；
- 时钟频率最大 20MHz。

设计应落在这个范围内，不要贴着绝对最大值用。

**（3）电气特性（Electrical Characteristics）**

这是具体参数表，通常给 **最小值（Min）、典型值（Typ）、最大值（Max）**，而且每行都有**测试条件**。

常见参数：

- `Vf`：正向压降（forward voltage），二极管/LED 导通时两端电压。
- `Vr`：反向耐压。
- `I_R`：反向漏电流。
- `Rds(on)`：MOS 导通时漏源电阻。
- `Vth`：MOS 阈值电压。
- `hFE`：三极管直流电流放大倍数。
- `VOH/VOL`：输出高/低电平。
- `VIH/VIL`：输入高/低电平阈值。
- `Iq`：静态电流。
- `CMRR`：共模抑制比（运放）。
- `PSRR`：电源抑制比（运放）。
- `GBW`：增益带宽积（运放）。

**读参数表的第一原则：先看条件列。** 同一个 `Rds(on)`，在 `Vgs=4.5V` 和 `Vgs=10V` 下可能差很多；同一个 `Vf`，在不同电流、不同温度下也不同。脱离条件比较数字，等于耍流氓。

数据手册后面还会有：

- 引脚图（Pin Configuration）和引脚功能说明；
- 封装尺寸（Package Outline）；
- 典型应用电路（Typical Application）；
- 热阻（Thermal Resistance）；
- 布局建议（Layout Guidelines）；
- 时序图/曲线图（Performance Curves）。

零基础先掌握“三块 + 引脚图 + 典型应用”，其余用到再查。

#### 1.7.5 型号、封装、批次与替代

**型号**（part number）不是随便一串字符。以常见芯片为例，型号里往往编码了：

- 系列/功能；
- 封装类型（SOT-23、SOIC-8、TSSOP-20、QFN-32、LQFP-48）；
- 温度等级（商业级 0～70℃、工业级 −40～85℃、汽车级 −40～125℃）；
- 包装方式（卷带、管装、托盘）；
- RoHS/无铅标识；
- 批次/日期码。

**封装**（package）是器件的外形和引脚排列；** footprint** 是 PCB 上对应的焊盘图形。两者相关但不完全一样：同一个封装可能有不同焊盘推荐（手焊/回流、带散热焊盘/不带）。画板时要按厂家推荐的 land pattern 或 IPC 标准，不要凭感觉。

**批次**（date code / lot）是生产批次。不同批次可能有轻微参数差异、丝印差异、甚至翻新/假货风险。关键物料要从正规渠道买，保留批次记录。

**替代料**不能只看“功能一样”。至少核对：

1. 电气参数：电压、电流、速度、精度、温度范围；
2. 引脚定义和封装：pin-to-pin 是否兼容，散热焊盘是否一样；
3. 外围电路：是否需要不同的电容、电阻、补偿网络；
4. 时序/协议：能不能直接替换；
5. 生命周期/供货：是否停产、是否车规/工业级；
6. 认证/合规：安规、RoHS、REACH 等。

**这在板子上**：丝印上的 `R1`、`C2`、`U3` 对应原理图位号；器件本体上的 pin 1 圆点/斜角对应封装方向；极性电容的“+”色带、二极管的色环、LED 的阴极标记，都是装配时不能搞反的。原理图正确、封装画反，板子照样报废。

#### 1.7.6 停下来检查

1. 原理图里的“网络”是什么？两个引脚没有画线，但网络名都叫 `LED_EN`，它们连不连？
2. 两条线交叉，没有实心圆点，通常表示什么？
3. `GND` 和 `AGND` 可以直接当同一个网络吗？
4. 拿到一张原理图，为什么要先看电源和地，而不是从左到右逐行读？
5. 绝对最大额定值和推荐工作条件有什么区别？
6. 数据手册里 `Rds(on)=10mΩ`，为什么不能直接拿来和另一个器件的 `5mΩ` 比？
7. 替代料除了“功能一样”，还要核对哪些东西？

<details>
<summary>参考答案</summary>

1. 网络是电气上连在一起的所有节点集合；同名网络标签视为连接，所以会连。
2. 通常表示只是交叉、不连接；有实心连接点才表示连在一起。
3. 不一定。它们可能是不同网络，只在设计指定的单点（0Ω、磁珠、特殊连接）相连；直接短接可能引入噪声或安全问题。
4. 电源和地是电路的骨架，先确定能量从哪来、回流到哪去，再看功能块，效率更高，也不容易漏掉供电/极性错误。
5. 绝对最大额定值是“超过可能损坏”的极限，不是正常工作范围；推荐工作条件是厂家建议的正常使用范围。
6. 因为参数必须看测试条件：`Vgs`、电流、温度不同，`Rds(on)` 差别很大；脱离条件比较没有意义。
7. 电气参数、引脚/封装兼容性、外围电路、时序/协议、温度等级、供货与生命周期、认证合规等。

</details>

### 1.8 本章复盘

#### 1.8.1 一页纸公式表

先不要把公式背成文字，理解每个符号指哪段电路、适用条件是什么。

| 公式 | 用途 | 条件与注意 |
|---|---|---|
| $I=\frac{Q}{t}$ | 电流定义 | `Q` 是流过截面的电荷量，`t` 是时间 |
| $U=IR$ | 欧姆定律 | 线性电阻，`U` 必须是该电阻两端电压 |
| $I=\frac{U}{R}$ | 求电流 | 同上，单位统一为 V、A、Ω |
| $R=\frac{U}{I}$ | 求电阻 | 同上；非线性器件不能直接用 |
| $P=UI$ | 功率 | `U`、`I` 是同一器件的电压和电流 |
| $P=I^{2}R$ | 电阻功耗 | 已知电流和电阻时最方便 |
| $P=\frac{U^{2}}{R}$ | 电阻功耗 | 已知电阻两端电压时最方便 |
| $E=Pt$ | 能量 | 功率乘以时间，单位 J |
| $R_{\text{串}}=R_1+R_2+\cdots$ | 串联总电阻 | 电流相同，电压相加 |
| $\frac{1}{R_{\parallel}}=\frac{1}{R_1}+\frac{1}{R_2}+\cdots$ | 并联总电阻 | 电压相同，电流相加 |
| $V_{\text{out}}=V_{\text{in}}\frac{R_2}{R_1+R_2}$ | 分压 | 输出端几乎不取电流；接负载会跌 |
| $I_1=I_{\text{总}}\frac{R_2}{R_1+R_2}$ | 两电阻并联分流 | 分子是“另一个电阻” |
| $R=\frac{\rho L}{A}$ | 导体电阻 | 长、细、材料差 → 电阻大 |
| `f = 1/T` | 频率与周期 | `f` 单位 Hz，`T` 单位 s |
| $V_{\text{rms}}=\frac{V_p}{\sqrt{2}}$ | 正弦有效值 | 仅正弦波，且无直流偏置 |
| $V_{\text{avg}}=DV_p$ | PWM 平均值 | 0～Vp 方波，占空比 D |
| $V_{\text{rms}}=V_p\sqrt{D}$ | PWM 有效值 | 同上 |
| $D=\frac{t_{\text{on}}}{T}$ | 占空比 | 高电平时间除以周期 |
| `BW ≈ 0.35/t_r` | 带宽估算 | 一阶系统，10%～90% 上升时间 |

#### 1.8.3 常见坑总表

| 现象 | 最可能的原因 | 排查顺序 |
|---|---|---|
| 一上电就大电流/发热 | 电源与地短路、器件装反、锡桥 | 断电测通断 → 查极性 → 查连锡 |
| LED 不亮或很快烧掉 | 限流电阻算错、LED 极性反、电源过高 | 测电源 → 测 LED 两端 → 查极性与电阻 |
| 分压点一接负载就跌 | 负载效应，分压电阻太大 | 算并联等效 → 测空载/负载电压 → 加缓冲 |
| 电阻发烫 | 功耗超过额定、降额不足 | 算 $I^{2}R$ → 查额定功率 → 换大功率/降流 |
| 万用表读数差 1000 倍 | mA/A、kΩ/Ω 没统一 | 检查单位 → 重算 |
| 电流档一接就烧保险 | 电流表并联在电源两端 | 断电 → 换保险 → 改串联 |
| 在路测电阻读数不对 | 带电测量或并联旁路 | 断电 → 拆一端 → 重测 |
| 示波器波形失真/短路 | 地线夹夹错、探头负载、带宽不够 | 查地线 → 换 10× 探头 → 查带宽 |
| 器件“没超绝对最大值”却坏了 | 把绝对最大值当工作值、没留余量 | 查推荐工作条件 → 降额 → 查散热 |
| 换替代料后不稳定 | 引脚/参数/外围不兼容 | 对照手册 → 查 pinout → 查外围 |

#### 1.8.4 综合自测

1. 5V 电源、红色 LED（`Vf≈2V`）、目标电流 8mA，限流电阻取多少？实际电流多少？
2. 两个 4.7kΩ 电阻并联，总电阻多少？串联呢？
3. 12V 经 R1=10kΩ、R2=2kΩ 分压，空载输出多少？接一个 2kΩ 负载后输出多少？
4. 一个 0～3.3V、占空比 75% 的 PWM，平均值和有效值各是多少？
5. 一条走线电阻 0.05Ω，流过 3A，压降和功耗多少？
6. 为什么“GND 上量不到电压”不代表地线没有问题？
7. 示波器探头拨到 10×，但示波器里的探头设置仍是 1×，屏幕上读到 0.5V，实际电压多少？
8. 数据手册写 `VIN` 绝对最大 6V，推荐工作 2.7～5.5V，能不能长期用 5.8V？

<details>
<summary>参考答案</summary>

1. `R=(5−2)/0.008=375Ω`，取标准值 390Ω；`I=3/390≈7.69mA`。
2. 并联 `2.35kΩ`；串联 `9.4kΩ`。
3. 空载 `12×2k/(10k+2k)=2V`；接 2kΩ 负载后下臂变 1kΩ，`12×1k/(10k+1k)≈1.09V`。
4. `Vavg=3.3×0.75=2.475V`；`Vrms=3.3×√0.75≈2.86V`。
5. `U=3×0.05=0.15V`；`P=3²×0.05=0.45W`。
6. 地是参考点，万用表以地为参考时读数为 0，但地线有电阻，大电流回流会产生压降和电位抬升；要用毫伏档/差分测量查。
7. 实际约 `0.5V × 10 = 5V`（若示波器未自动换算）。
8. 不能。5.8V 超过推荐工作范围，虽然没到绝对最大值，但参数、寿命、可靠性没有保证；应降到 5.5V 以下并留余量。
