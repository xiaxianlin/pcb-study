## 8.1 它解决什么问题

### 场景一：传感器信号太小，ADC 读不到

热电偶、应变片、光敏二极管、麦克风的输出可能只有几毫伏到几十毫伏。单片机 ADC 的分辨率有限，直接接上去，噪声一盖，什么都测不到。需要运放把信号放大到 0～3.3V 的范围，再送 ADC。

### 场景二：信号源太弱，一接后级就掉电压

一个高输出阻抗的传感器，空载时 1V，接到 ADC 的输入电阻后变成 0.6V。这叫**负载效应**。用运放做电压跟随器，输入阻抗高、输出阻抗低，可以把信号“缓冲”一下，后级就不再拖垮前级。

### 场景三：需要把电流/差分信号变成单端电压

电机电流采样、电桥传感器、电池电流检测，输出的都是两个点之间的差分电压。运放组成差分放大，把差分信号变成以地为参考的单端电压，再送 ADC。

### 本章在课程里的位置

第 01 章讲过电压、电流、分压、负载效应；第 02 章电阻、第 03 章电容、第 04 章电感、第 05 章二极管、第 06 章三极管、第 07 章 MOS。本章是第一阶段最后一章，把前面所有器件组合成一个完整的模拟信号链：**传感器 → 运放 → ADC**。

## 8.2 它是什么

### 8.2.1 一句话定义

**运算放大器（Operational Amplifier，简称运放，Op-Amp）** 是一个高增益的差分电压放大器：它放大“同相输入 + 与反相输入 −”之间的电压差，输出一个电压。通过外部电阻、电容构成负反馈，可以实现放大、缓冲、滤波、求和、比较等功能。

三个信号端子（实际芯片还有电源脚）：

- **同相输入 +（Non-inverting）**：输出与它同相。
- **反相输入 −（Inverting）**：输出与它反相。
- **输出 Vout**：输出电压。

原理图位号常用 **U**，如 U1A、U1B。一个芯片里可能有一个、两个或四个运放，电源脚可能共用。**符号只画信号脚，实际电路必须接电源和地**，否则不工作。

### 8.2.2 理想运放模型

理想运放有三个假设：

1. **开环增益无穷大**：`Aol → ∞`。
2. **输入阻抗无穷大**：输入端不取电流，`I+ = I− = 0`。
3. **输出阻抗为零**：输出能驱动任意负载（实际不是）。

由 1 和 2，在负反馈稳定且未饱和时，可以推出两个重要结论：

- **虚短**：两个输入端电压几乎相等，`V+ ≈ V−`。
- **虚断**：输入端电流几乎为零，`I+ ≈ I− ≈ 0`。

> **术语解释：虚短 / 虚断**
> “虚短”不是真的用导线把两个输入脚短接，而是负反馈让运放自动调节输出，使两脚电压差极小；“虚断”不是内部断开，而是输入阻抗极高，几乎不取电流。**它们只在负反馈、未饱和、频率/共模/输出范围都满足时成立。** 开环比较、饱和、过载时不能套。

### 8.2.3 负反馈

把输出的一部分送回**反相输入端**，叫负反馈。负反馈的作用：

- 降低增益，但增益由外部电阻决定，更稳定；
- 扩展带宽；
- 减小失真；
- 改变输入/输出阻抗。

**正反馈**（送回同相端）会锁定到电源轨，通常用于比较器/振荡器，不用于线性放大。

### 8.2.4 运放的供电与输入输出范围

运放不是理想器件，有几个现实限制：

- **电源范围**：单电源 0～5V，或双电源 ±12V。
- **输入共模范围**：两个输入电压必须落在允许范围内，否则运放不工作/输出反相。
- **输出摆幅**：输出不能完全到电源轨，普通运放可能差 0.5～2V；轨到轨（R2R）也有条件。
- **输出电流**：带不动太小负载。
- **带宽/压摆率**：高频大信号会失真。
- **失调/偏置电流/噪声**：影响精度。

## 8.3 关键参数与手册

### 8.3.1 一张表看懂运放手册

| 参数 | 符号 | 含义 | 为什么重要 |
|---|---|---|---|
| 供电范围 | Vs | 允许电源电压 | 单/双电源 |
| 输入共模范围 | VCM | 输入允许范围 | 超出会失真/反相 |
| 输出摆幅 | Vout | 输出能到的范围 | 接近电源轨时 |
| 开环增益 | Aol | 开环电压增益 | 闭环精度 |
| 增益带宽积 | GBW | 增益×带宽 | 频率能力 |
| 压摆率 | SR | 输出最大变化速率 | 大信号高频 |
| 输入失调电压 | Vos | 输入等效误差 | 直流精度 |
| 输入偏置电流 | Ib | 输入端电流 | 高阻源误差 |
| 共模抑制比 | CMRR | 抑制共模变化 | 差分测量 |
| 电源抑制比 | PSRR | 抑制电源波动 | 电源噪声 |
| 输入噪声 | en | 电压噪声密度 | 微弱信号 |
| 输出电流 | Iout | 驱动能力 | 负载 |
| 静态电流 | Iq | 自身耗电 | 低功耗 |

### 8.3.2 读手册的四个关键点

**第一，GBW 不是“能放大到多少倍”。** GBW 是增益带宽积。闭环增益 10 倍时，带宽约 `GBW/10`。比如 GBW=1MHz，增益 10，带宽约 100kHz；增益 100，带宽约 10kHz。具体还要看相位裕度、压摆率。

**第二，压摆率限制大信号。** `SR` 单位 V/μs。输出 1V 峰值的 100kHz 正弦，最大斜率 `2π×100k×1≈0.628V/μs`；如果 SR 只有 0.5V/μs，波形会变成三角波。小信号看 GBW，大信号看 SR。

**第三，失调电压是直流误差。** `Vos=1mV` 经增益 100，输出误差 100mV。高精度直流测量要选低失调运放，或加调零/校准。

**第四，输入共模范围不是电源范围。** 很多运放的输入不能到电源正极附近；单电源 3.3V 运放，输入 3.0V 可能已经超出共模范围。要查 `VCM` 或“输入电压范围”一栏。

### 8.3.3 运放 vs 比较器

| 对比 | 运放 | 比较器 |
|---|---|---|
| 用途 | 线性放大、缓冲、滤波 | 判断大小，输出高低 |
| 反馈 | 通常负反馈 | 通常开环/正反馈 |
| 输出 | 模拟电压 | 逻辑电平/开漏 |
| 速度 | 看 GBW/SR | 看传播延迟 |
| 输入范围 | 共模限制 | 也有范围 |
| 能互换吗 | 低速、条件满足时可以 | 不建议用运放替代 |

**运放当比较器**可能遇到的问题：输入共模超限、输出不到逻辑电平、饱和恢复慢、功耗大。要判断高低，优先用专用比较器（如 LM393、TLV3201）。

图 8-2 电压跟随器：输出直接接回反相输入

```text
Vin ── + 输入
输出 ── − 输入
输出 ── 后级
```

理想条件下 `Vout ≈ Vin`，增益为 1。它不放大电压，但输入阻抗高、输出阻抗低，能减轻后级对前级的负载。

**算例**：传感器空载 1.0V，输出阻抗 10kΩ；ADC 输入阻抗 10kΩ。直接接，分压后 `1.0×10/(10+10)=0.5V`，掉了一半。加跟随器后，运放输入几乎不取电流，传感器仍是 1.0V；输出能驱动 ADC，`Vout≈1.0V`。

**限制**：输入共模要包含 1.0V；输出要能到 1.0V；如果传感器输出接近电源轨，普通运放可能跟不上。

### 8.4.6 电路六：有源低通滤波（了解）

在反相/同相放大器的反馈网络里加电容，可以做成有源低通/高通滤波。比如反相低通：`Rf` 并联 `Cf`，截止频率 `fc=1/(2πRfCf)`。它比无源 RC 滤波更陡，但需要运放带宽和稳定性支持。

本章只要求知道“运放+RC 可以做出比 RC 更好的滤波器”，具体设计在后续阶段展开。

## 8.5 选型与降额

### 8.5.1 按用途选类型

| 用途 | 首选 | 备选 | 避免 |
|---|---|---|---|
| 通用缓冲 | 通用运放（LM358、TLV2372） | 轨到轨 | 高速运放（功耗大） |
| 单电源 3.3V 信号链 | 轨到轨输入/输出 | 低电压运放 | 高压运放 |
| 精密直流 | 低失调、低漂移 | 斩波稳零 | 普通通用运放 |
| 高阻传感器 | 低偏置电流（CMOS/JFET） | — | 双极型高 Ib |
| 音频 | 低噪声、足够 GBW | — | 通用慢运放 |
| 高频 | 高速运放 | — | 低 GBW |
| 比较 | 专用比较器 | — | 运放硬当比较器 |

### 8.5.2 降额参考

| 参数 | 建议 | 说明 |
|---|---|---|
| 电源 | 不超过额定 | 留 10～20% |
| 输入共模 | 留余量 | 接近电源轨要查 |
| 输出电流 | ≤额定 | 看负载 |
| 带宽 | 信号最高频率 ≤GBW/增益 的 1/5～1/10 | 留余量 |
| 压摆率 | 大于最大斜率 2～5 倍 | 大信号 |
| 功耗 | 结温留 20～30℃ | 封装热阻 |
| 稳定性 | 容性负载要查 | 可能振荡 |

1. 定信号范围、源阻抗、负载。
2. 定电源（单/双、电压）。
3. 定增益和带宽。
4. 查输入共模、输出摆幅。
5. 查失调、偏置电流、噪声。
6. 查 GBW、压摆率、稳定性。
7. 查封装、通道数、功耗。
8. 写完整料号，核对供货。

## 8.6 测量与仿真

### 8.6.1 测运放的基本步骤

1. 先测电源脚电压，确认供电正常。
2. 测两个输入脚电压，确认在共模范围内。
3. 测输出，判断是否饱和（接近电源轨）。
4. 输入小信号，用示波器看输出波形、增益、相位。
5. 改变负载，看输出是否掉压/振荡。

**注意**：探头地线可能短路，测高压/高边电路要用差分探头。

### 8.6.2 常见故障现象

| 现象 | 可能原因 |
|---|---|
| 输出贴电源轨 | 输入超出共模、反馈断、饱和 |
| 输出为 0 | 没供电、输入短路、负载短路 |
| 输出振荡 | 容性负载、反馈相位、布线 |
| 增益不对 | 电阻值错、反馈没接、输入源阻抗 |
| 直流偏置大 | 失调、偏置电流、电阻误差 |

### 8.6.3 仿真记录表

| 仿真 | 改什么 | 预期 | 实际 |
|---|---|---|---|
| opamp-buffer | 改负载 | 输出是否掉 | |
| opamp-noninvert | 改 Rf | 增益变 | |
| opamp-invert | 改 Rin | 增益变、反相 | |
| analog-comparator | 改 Vref | 翻转点变 | |

### 8.6.4 动手任务

1. 用 LM358 搭电压跟随器，输入 1V，测输出；再接 1kΩ 负载，看是否掉压。
2. 搭同相放大 10 倍，输入 0.2V，测输出；把电源改成 3.3V，观察输出上限。
3. 搭反相放大，输入 0.1V，测输出相位；解释为什么单电源不能输出负压。
4. 用比较器搭一个光控开关，测翻转阈值。

## 8.7 常见坑

### 坑 1：忘记接电源

运放符号只画信号脚，新手常忘记 V+/V−，输出当然不动。每个运放都必须接电源，并加 0.1μF 去耦。

### 坑 2：输入超出共模范围

单电源运放输入不能到电源正极附近，超了输出会反相/锁死。查 `VCM`。

### 坑 3：输出不能到轨

普通运放输出比电源轨低 1～2V，3.3V 供电可能只能到 2.5V。需要轨到轨（R2R）或更高电源。

### 坑 4：虚短乱用

开环、饱和、正反馈时，`V+ = V−` 不成立。不能拿虚短公式算比较器。

### 坑 5：忽略压摆率

大信号高频时，GBW 够但 SR 不够，输出变三角波。要同时查。

### 坑 6：容性负载振荡

运放驱动长线/电容负载可能振荡。加隔离电阻或选稳定型号。

### 坑 7：电阻容差忽略

增益 10 倍，1% 电阻可能让增益变 9.8～10.2，满量程误差明显。精密电路用 0.1% 或校准。

### 坑 8：用运放替代比较器

速度慢、输出电平不兼容、恢复慢。判断高低优先用比较器。

### 坑 9：高阻源 + 高偏置电流

偏置电流流过源阻抗产生误差。高阻传感器选 CMOS/JFET 输入运放。
