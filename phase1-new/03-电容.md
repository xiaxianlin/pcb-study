## 本章目标

学完本章，你应该能够：

1. 用 `Q=CV` 解释电容为什么“存电荷”，并说出电容和电池的区别。
2. 算 RC 充放电的时间常数、63%/95%/99% 时刻，画出充放电曲线。
3. 解释去耦电容为什么必须靠近芯片，100nF 和大电容各自管什么。
4. 算 RC 低通/高通滤波的截止频率，知道它为什么能滤噪、隔直。
5. 分清 MLCC、铝电解、钽电容、薄膜电容的适用场景。
6. 查电容的耐压、容差、ESR、DC 偏压、温度特性，做降额。
7. 用万用表/LCR 表测电容，知道在板测量为什么会偏大。
8. 说出至少 8 个电容常见坑，并给出排查顺序。

电容是“时间”的元件。电阻决定电流大小，电容决定电压**怎么随时间变化**。去耦、滤波、复位延时、耦合、振荡、峰值检测，背后都是电容在充放电。

## 正文

### 3.1 它解决什么问题：三个真实场景

#### 场景一：芯片一工作，电源就抖

芯片内部晶体管每秒翻转几百万次，每次翻转都要瞬间取一点电流。电源和走线离得远，有电阻和电感，不能瞬间把电流送过来，芯片电源引脚上的电压就会短暂下陷。下陷太大，芯片可能误动作、复位、甚至死机。

在芯片电源引脚旁边放一颗 100nF 电容，它就像“随身水杯”：芯片突然要电流，电容先就近供给；电源平稳时，电容再慢慢补满。这就是**去耦**（decoupling）。

#### 场景二：按键按下，单片机要等一会儿才启动

有些芯片要求电源稳定一段时间后再释放复位。用电阻和电容组成 RC 延时：上电时电容从 0V 慢慢充电，复位引脚电压缓慢上升，超过阈值后芯片才开始工作。这是电容的**定时**作用。

#### 场景三：音频信号要跨过两级，但直流偏置不能互相影响

前级可能有 2.5V 直流偏置，后级可能是 0V 偏置。直接把信号线连过去，两级的直流会互相打架。串一颗电容，直流被挡住，交流信号通过，这叫**耦合**（AC coupling）。

这三个场景对应电容的三类角色：**储能/去耦、定时/滤波、隔直/耦合**。同一个 100nF，并联在电源上是去耦，串联在信号路径上是耦合，位置决定角色。

### 3.2 它是什么：两块导体夹一层绝缘

#### 3.2.1 生活类比：小水池

想象一个很小的水池，进水口很细。打开进水阀，水慢慢流进池子，水位上升；关掉进水阀，池子里的水不会立刻消失，还能继续供给下游一会儿。

电容就像电路里的“小水池”：

- **电压**像水位；
- **电荷**像水量；
- **电容值 C** 像水池的底面积：底面积越大，同样水位变化能装更多水；
- **充放电**像进水/放水，需要时间。

但电容和电池不同：电容储存的是**电场能量**，不是化学能；它放电极快，自放电也比电池快；它不能像电池那样维持长时间稳定电压。电容是“短跑选手”，电池是“长跑选手”。

#### 3.2.2 物理直觉：电场存能量

电容由两块导体（极板）和中间的绝缘介质组成。给两极板加电压，正负电荷分别聚集在两侧，介质中建立电场，能量储存在电场里。

基本关系：

```text
Q = C × U
```

- `Q`：极板上储存的电荷量，单位库仑（`C`）
- `C`：电容值，单位法拉（`F`）
- `U`：电容两端电压，单位伏特（`V`）

所以 `1F = 1C/V`：加 1V 电压，能存 1 库仑电荷，就是 1 法拉。法拉是非常大的单位，实际电路常用：

- `1F = 1000mF = 10⁶μF = 10⁹nF = 10¹²pF`
- `1μF = 1000nF`；`1nF = 1000pF`
- `100nF = 0.1μF`

电容的电流和电压变化率有关：

```text
I = C × dU/dt
```

- `dU/dt`：电压随时间的变化率，单位 V/s。
- 电压变化越快，充放电电流越大；电压不变（直流稳态），电流为 0（理想电容）。

这解释了“通交流、阻直流”：交流电压一直在变，电容一直在充放电，外电路一直有电流；直流电压稳定后，电容充满，电流趋近于 0。

电容储存的能量：

```text
E = ½ × C × U²
```

例子：100μF 电容充到 5V，储能 `0.5 × 100e-6 × 25 = 1.25mJ`。不大，但短路放电瞬间电流可能很大，所以大电容断电后要放电，不能直接用手碰。

#### 3.2.3 电容 vs 电池：别混用

| 特性 | 电容 | 电池 |
|---|---|---|
| 储能方式 | 电场 | 化学能 |
| 电压 | 随电荷线性变化 `U=Q/C` | 放电过程中相对平稳 |
| 充放电速度 | 很快，可高功率脉冲 | 较慢，受化学过程限制 |
| 自放电 | 较慢但比电池快 | 慢 |
| 寿命 | 很长（电解有寿命限制） | 充放电循环有限 |
| 典型用途 | 去耦、滤波、定时、耦合 | 长时间供电 |

电容不能替代电池做长时间供电；电池也不能替代电容做高频去耦。

**极性**：

- **MLCC 多层陶瓷电容**：一般无极性。
- **铝电解电容**：有极性，外壳色带通常标负极；反接可能发热、鼓包、漏液甚至爆裂。
- **钽电容**：有极性，色带通常标正极（不同厂家可能不同，必须查手册）；反接可能短路、起火。
- **薄膜电容**：多数无极性，部分高压/脉冲型号有规定方向。
- **超级电容**：有极性，单体电压低，需要均衡。

**反接不是“不工作”这么简单**：电解/钽电容反接可能迅速发热、失效，甚至起火。上电前一定核对极性和丝印。

#### 3.2.5 串联与并联

**并联**：电压相同，容量相加。

```text
C_total = C1 + C2 + … + Cn
```

两个 1μF 并联 = 2μF。并联还能降低等效 ESR/ESL（多个电容并联），所以去耦常用多个电容。

**串联**：电荷相同，容量倒数相加。

```text
1/C_total = 1/C1 + 1/C2 + …
两个电容：C_total = C1×C2/(C1+C2)
```

两个 1μF 串联 = 0.5μF。串联时电压分配不一定均匀，取决于漏电/等效电阻；电解电容串联需要均压电阻，不能简单把耐压相加。

### 3.3 关键参数与数据手册

电容手册比电阻复杂得多。只看“10μF/16V”远远不够。

#### 3.3.1 电容值、容差与标记

**标称电容值**：厂家标的值，比如 `100nF`、`10μF`。实际有容差，常见：

- MLCC：`±5%`、`±10%`、`±20%`，高容值 X5R/X7R 可能 `±20%`。
- 铝电解：`±20%` 常见，部分 `−20%/+80%`。
- 钽电容：`±10%`、`±20%`。
- 薄膜：`±1%`、`±2%`、`±5%`、`±10%`。

**三位标记**（以 pF 为单位）：

- `104` = `10 × 10⁴ pF = 100nF = 0.1μF`
- `223` = `22 × 10³ pF = 22nF`
- `471` = `47 × 10¹ pF = 470pF`
- `102` = `10 × 10² pF = 1nF`
- `101` = `100pF`

注意：不是所有电容都遵循这个规则。小尺寸 MLCC 可能无字，电解电容直接印 `10μF 16V`，钽电容可能用代码。**无字电容不能凭颜色/大小猜容值，必须测或查包装。**

#### 3.3.2 额定电压与降额

**额定电压**（voltage rating）：电容允许长期施加的最大直流电压。交流/脉冲场景还要看交流耐压、脉冲电压、dv/dt。

降额建议：

- **MLCC**：实际工作电压建议不超过额定电压的 50%～80%；高可靠/高压场景更保守。
- **铝电解**：建议不超过 80%，高温/长寿命场景 50%～70%。
- **钽电容**：建议不超过 50%，并且要控制浪涌电流；钽电容对过压/反接很敏感。
- **薄膜**：按厂家脉冲/交流曲线，不能只看 DC 额定。

**电压不是“不超过就行”**：电容在额定电压附近长期工作，漏电、寿命、可靠性都会下降；击穿时可能短路、起火。

#### 3.3.3 ESR：等效串联电阻

**ESR**（equivalent series resistance，等效串联电阻）是电容内部电极、引线、接触电阻的等效总和。它让电容不再是理想电容：

- 充放电时，ESR 会产生热量 `I²×ESR`；
- 滤波时，ESR 会让纹波变大；
- 大电流脉冲时，ESR 上的压降会让电容“反应变慢”。

电解电容的 ESR 通常比 MLCC 大；MLCC 的 ESR 很小，但具体看系列/尺寸/电压。开关电源的输出电容、电机驱动、大电流脉冲，必须看 ESR 和纹波电流。

#### 3.3.4 ESL 与自谐振频率

**ESL**（equivalent series inductance，等效串联电感）来自引脚、内部电极、封装。频率越高，ESL 的阻抗越大。

电容的阻抗近似：

```text
|Z| = √( ESR² + (2πfL − 1/(2πfC))² )
```

- 低频：容抗 `1/(2πfC)` 主导，频率越高阻抗越小。
- 某个频率：容抗和感抗抵消，阻抗最低，等于 ESR；这个频率叫**自谐振频率**（SRF，self-resonant frequency）。
- 高于 SRF：感抗主导，频率越高阻抗越大，电容看起来像电感。

所以“100nF 去耦”不是所有频率都有效。高频去耦要用小封装、短走线、低 ESL 的电容；大电容在高频可能已经“变电感”了。

#### 3.3.5 漏电流

理想电容充满后电流为零；实际电容有**漏电流**（leakage current），尤其是电解电容、钽电容、超级电容。

漏电流会影响：

- 长时间保持的采样/保持电路；
- 低功耗待机；
- 电荷泵/峰值检测；
- 高阻节点电压。

精密场合要查漏电流规格，必要时选薄膜/C0G，或加缓冲/复位。

#### 3.3.6 介质类型：C0G、X7R、X5R、Y5V

MLCC 的“介质”决定了稳定性、容值范围、温度特性、DC 偏压特性。

| 介质 | 温度特性 | 容值稳定性 | 典型用途 | 注意 |
|---|---|---|---|---|
| C0G/NP0 | 极稳定，接近不随温度/电压变 | 很好 | 定时、滤波、谐振、精密 | 容值通常较小，体积大 |
| X7R | −55～+125℃，±15% | 较好 | 一般去耦、滤波 | 有 DC 偏压损失、老化 |
| X5R | −55～+85℃，±15% | 一般 | 大容量去耦 | 温度范围窄，DC 偏压损失 |
| Y5V | −30～+85℃，+22/−82% | 差 | 廉价旁路 | 容值随温度/电压大幅下降，不适合定时/滤波 |
| 铝电解 | 有极性，容量大 | 一般 | 电源储能/低频滤波 | ESR 大、寿命有限 |
| 薄膜 | 稳定、低损耗 | 好 | 音频、脉冲、精密 | 体积大、价格高 |
| 钽 | 有极性，容量大 | 一般 | 紧凑储能 | 过压/反接敏感，需降额 |

**DC 偏压效应**：高介电常数 MLCC（X5R/X7R/Y5V）加上直流电压后，有效容值会下降，可能下降 30%～80%。比如标称 10μF/16V 的 0603 X5R，在 10V 偏压下可能只剩 4～6μF。选型必须查厂家的“capacitance vs DC bias”曲线，不能只看标称值。

**温度与老化**：X7R/X5R 容值随温度变化；Class II 陶瓷还会随时间老化（容值缓慢下降），需要高温烘烤/焊接重新“复位”。精密定时用 C0G，不要用 Y5V。

#### 3.3.7 纹波电流与寿命

电解电容、钽电容有**纹波电流**（ripple current）限制。纹波电流在 ESR 上产生热量，温度升高会缩短寿命。

铝电解寿命常用“每升高 10℃ 寿命减半”估算（具体看厂家公式），所以开关电源输出电容要选低 ESR、长寿命、额定纹波足够的型号，并注意散热。

#### 3.3.8 数据手册速查表

| 参数 | 英文 | 为什么重要 | 典型条件 |
|---|---|---|---|
| 容值 | capacitance | 决定储能/滤波/定时 | 25℃、指定频率 |
| 容差 | tolerance | 误差预算 | ±5%/±10%/±20% |
| 额定电压 | voltage rating | 击穿/寿命 | DC 或 AC |
| ESR | equivalent series resistance | 纹波/发热/滤波 | 100kHz 等 |
| ESL | equivalent series inductance | 高频阻抗/自谐振 | 频率曲线 |
| 漏电流 | leakage current | 高阻/低功耗 | 额定电压、时间 |
| 介质 | dielectric | 稳定性/DC 偏压 | C0G/X7R/X5R/Y5V |
| 纹波电流 | ripple current | 发热/寿命 | 频率、温度 |
| 工作温度 | operating temperature | 环境限制 | −55～+125℃ |
| 寿命 | endurance/life | 电解电容更换周期 | 105℃、额定纹波 |

**读手册第一原则**：容值、ESR、耐压都要看测试条件（频率、偏压、温度）。同一个 10μF，在 1kHz 和 100kHz 测出来可能不一样；加了 10V 偏压后更不一样。

#### 3.3.9 选型顺序

1. **定功能**：去耦、滤波、定时、耦合、储能。
2. **定容值**：按公式算，留容差/降额。
3. **定类型**：C0G（精密）、X7R/X5R（一般）、电解（大容量）、薄膜（音频/脉冲）、钽（紧凑）。
4. **定耐压**：按降额规则。
5. **查 ESR/纹波**：电源/大电流场景。
6. **查 DC 偏压/温度**：MLCC 必查有效容值。
7. **定封装/极性**：手焊/回流、高度、极性。
8. **写完整料号**。

**过程**：

1. 开关刚闭合：电容电压为 0V（电容电压不能突变），全部 5V 加在电阻上，充电电流最大 `I=5V/10kΩ=0.5mA`。
2. 随着电容充电，`Vc` 上升，电阻两端电压 `5V−Vc` 减小，电流减小。
3. 时间足够长，`Vc` 接近 5V，电流接近 0。

**时间常数**：

```text
τ = R × C
```

- `τ`（tau）：时间常数，单位秒（s）
- `R`：电阻，单位欧姆（Ω）
- `C`：电容，单位法拉（F）

`Ω × F = 秒`。计算前必须把 kΩ 换成 Ω、μF 换成 F。

例：`R=10kΩ=10000Ω`，`C=100μF=100×10⁻⁶F=10⁻⁴F`：

```text
τ = 10000 × 10⁻⁴ = 1s
```

**充电曲线**（初始 0V，最终 5V）：

```text
Vc
5V ────────────────────────  ← 最终值
   │                 ******
   │            *****
   │         ***
   │      **
   │    *
   │  *
0V *───┼────┼────┼────┼────┼──→ t
   0   1τ   2τ   3τ   4τ   5τ
```

| 时间 | 充到最终值的比例 | 5V 时电压 |
|---|---|---|
| 1τ | 63.2% | 3.16V |
| 2τ | 86.5% | 4.32V |
| 3τ | 95.0% | 4.75V |
| 4τ | 98.2% | 4.91V |
| 5τ | 99.3% | 4.97V |

公式：

```text
Vc(t) = Vfinal + (Vinitial − Vfinal) × e^(−t/τ)
```

- 从 0V 充到 `Vfinal`：`Vc=Vfinal(1−e^(−t/τ))`
- 从 `V0` 放电到 0V：`Vc=V0×e^(−t/τ)`

**关键直觉**：

- 电容电压不能突变，但电流可以突变。
- 刚接通瞬间，电容像短路（电压为 0），电流由外电阻限制。
- 充电久了，电容像开路（电流为 0），电压等于电源。
- τ 不是“充满时间”，只是“充到 63% 的时间”；5τ 仍有约 0.7% 误差。

**例子：1kΩ + 100nF**

```text
τ = 1000 × 100×10⁻⁹ = 100×10⁻⁶ = 0.1ms
```

0.1ms 肉眼看不到，示波器才能看清。1τ 约 63%，3τ 约 95%。

**放电**：断开电源后，电容通过放电路径放电。若放电路径电阻仍为 R，τ 相同；若路径不同，重新算 τ。大电容断电后可能存电，必须放电再操作。

走线电感会让高频电流“过不去”，电容再大也来不及供给。

**去耦电容不能替代稳压器**：它只在短时间内提供电荷，平均电流仍由电源提供。它也不能消除所有噪声，尤其低频/共模/辐射噪声需要其他手段。

图 3-4 RC 低通滤波器

**原理**：频率越高，电容容抗 `Xc=1/(2πfC)` 越小，越容易把高频旁路到地；频率越低，容抗越大，信号越容易通过。结果：低频通过，高频被削弱。

**截止频率**（−3dB 点）：

```text
fc = 1 / (2π × R × C)
```

例子：`R=1kΩ`，`C=100nF`：

```text
fc = 1 / (2π × 1000 × 100×10⁻⁹)
   ≈ 1 / (6.283 × 10⁻⁴)
   ≈ 1592Hz
```

约 1.59kHz。低于 fc 的信号基本通过；高于 fc 的信号被衰减，远高于 fc 时大约每十倍频衰减 20dB（一阶）。

**阶跃响应**：输入从 0 跳到 5V，输出按 τ=RC 上升：

```text
τ = 1k × 100n = 0.1ms
上升时间（10%～90%）≈ 2.2τ ≈ 0.22ms
```

**负载影响**：如果输出端接一个低阻负载，负载会与 C 并联/分流，截止频率和幅值都会变。RC 滤波器输出不适合直接驱动重负载，必要时加缓冲。

**典型用途**：

- ADC 输入抗混叠/降噪；
- 按键消抖（配合施密特触发器）；
- 传感器信号平滑；
- 电源纹波滤波（大电容/LC 更常见）；
- 音频低通/分频。

**RC 低通的局限**：一阶滤波衰减慢（−20dB/decade），要求陡峭时用二阶/有源滤波；电阻会带来热噪声和压降；电容容差/温度会影响 fc。

**原理**：电容隔直通交。串联电容与后级的输入电阻/偏置电阻组成高通，截止频率：

```text
fc = 1 / (2π × R × C)
```

例子：`C=1μF`，`R=10kΩ`：

```text
fc = 1 / (2π × 10000 × 1×10⁻⁶)
   ≈ 1 / (0.06283)
   ≈ 15.9Hz
```

低于 15.9Hz 的信号被衰减，高于它的通过。音频耦合常选 1～10μF，具体看输入阻抗和低频要求。

**极性**：如果用电解电容，正极接直流电位较高的一侧，避免反接。音频信号本身是交流，但两端可能有直流偏置，必须按实际直流电位接。

**耦合电容的副作用**：

- 低频响应受限，太低会“低频不足”；
- 电容漏电会让后级偏置漂移；
- 上电/关电时电容充放电可能产生“噗”声（pop）；
- 容差/ESR 影响音质/信号失真。

**位置决定角色**：同一个 100nF，并联在电源与地之间是去耦；串联在信号路径上是耦合。看位置，不要只看容值。

图 3-6 RC 复位延时

**原理**：上电瞬间电容为 0V，复位引脚被拉低（复位有效）；电容通过 R 充电，电压上升；超过芯片复位阈值后，复位释放，芯片启动。

充电公式：

```text
Vc(t) = Vcc × (1 − e^(−t/τ))
```

求达到阈值 `Vth` 的时间：

```text
t = −τ × ln(1 − Vth/Vcc)
```

例子：`R=10kΩ`，`C=10μF`，`τ=0.1s`；`Vcc=3.3V`，`Vth=1.6V`：

```text
t = −0.1 × ln(1 − 1.6/3.3)
  = −0.1 × ln(0.515)
  ≈ 0.066s = 66ms
```

**实际注意**：

- 电源不是理想阶跃，上升时间、掉电、反复上电都会影响；
- 复位阈值有容差，温度/批次不同；
- 电容漏电、复位引脚内部电流会改变曲线；
- 高可靠设计用专用复位监控芯片（voltage supervisor），不要只靠 RC。

#### 3.5.3 DC 偏压：标称 10μF 可能只剩 4μF

高容 MLCC 的容值随直流偏压下降。选型步骤：

1. 确定实际工作电压（不是电源标称，而是电容两端最大电压）；
2. 查厂家“capacitance vs DC bias”曲线；
3. 按最小有效容值核算；
4. 不够就换更大封装/更高耐压/更大标称值；
5. 不能拿标称值直接代入 LDO 稳定性/滤波计算。

例子：某 LDO 要求输出电容在实际条件下 ≥4.7μF。某 10μF/16V 0603 X5R 在 10V 偏压、−40℃ 时只剩 4.0μF，就不满足；应换 0805/1206、更高耐压或聚合物电容，并重新核对 ESR/稳定性。

#### 3.5.4 ESR 与纹波

开关电源输出电容的纹波电压近似：

```text
Vripple ≈ ΔI × ESR + ΔI / (8 × f × C)
```

- `ΔI`：电感电流纹波/负载瞬变；
- `ESR`：电容等效串联电阻；
- `f`：开关频率；
- `C`：有效电容。

大电流/低电压输出（比如 1.2V/5A）对 ESR 很敏感。电解电容 ESR 较大，可能需要并联多个或改用聚合物/MLCC。

#### 3.5.5 寿命与温度

铝电解的寿命与温度强相关。常见估算：温度每升高 10℃，寿命约减半（具体看厂家公式）。例如 105℃/2000h 的电容，在 85℃ 下理论寿命约 8000h（仅示意，实际按手册）。

选型要：

- 选 105℃ 而不是 85℃（如果环境热）；
- 查额定纹波电流，实际纹波不要超；
- 远离热源，留散热空间；
- 长寿命产品选固态/聚合物/薄膜。

#### 3.5.6 机械应力与音频效应

MLCC 是陶瓷体，受板子弯曲、热冲击、螺钉挤压可能产生裂纹，导致短路/漏电。布局时：

- 不要放在板边、连接器受力区、螺钉孔附近；
- 大尺寸 MLCC 避免靠近拼板 V-cut；
- 手工焊接不要过度弯折；
- 高可靠场景用软端电极（soft termination）。

高-K MLCC 有压电效应：电压变化会让陶瓷微小形变，振动也会产生电压。音频/高精度模拟附近可能听到“咔嗒”声或引入噪声，敏感场合用 C0G/薄膜。

### 3.6 测量与仿真

#### 3.6.1 万用表测电容

**步骤**：

1. **断电**，等电容放电（大电容用电阻放电）。
2. 拆下电容，或至少拆开一端，避免板上并联路径影响。
3. 万用表打到电容档（如果有），选择合适量程。
4. 表笔接触电容两端，等待读数稳定。
5. 与标称值/容差比较。

**在板测量为什么会偏大**：

电容在板上通常与多个电容并联（比如电源轨上有很多 100nF + 10μF）。万用表读到的是总电容，不是单个电容。比如测一个 100nF，旁边还有 10μF，读数会接近 10.1μF。

排查顺序：

1. 看原理图，确认并联电容；
2. 拆一端复测；
3. 如果读数仍不对，再怀疑电容本身；
4. 电解电容可能已失效（开路/短路/容量下降/ESR 变大），万用表电容档不一定能判断 ESR。

**注意**：

- 电容档测试频率/电压很低，不能反映工作条件下的有效容值；
- 大电容测试需要时间；
- 有极性电容反接测试可能损坏；
- 带电测电容可能损坏表。

#### 3.6.2 LCR 表与 ESR 表

**LCR 表**可以测电感 L、电容 C、电阻 R，通常可设测试频率、测试电压/电流、偏压。

- 测电容时，测试频率要接近实际工作频率；电解电容在不同频率下容值/ESR 不同。
- 测 MLCC 的 DC 偏压特性，需要偏压夹具，在施加直流电压的同时测小信号电容。
- 测 ESR 要用 ESR 表或 LCR 表的 ESR 模式，普通电容档测不出来。

**ESR 表**：专门测电解电容的等效串联电阻，判断电容是否老化/干涸。开关电源不启动、输出纹波大，ESR 变大是常见原因。

### 3.7 常见坑

#### 坑 1：电解/钽电容接反

**现象**：上电后电容发热、鼓包、漏液、冒烟，甚至起火。
**原因**：极性接反，或丝印/封装方向搞错。
**排查顺序**：

1. 断电，核对电容正负极和 PCB 丝印；
2. 查厂家标记规则（铝电解色带通常负极，钽电容色带通常正极，但不绝对）；
3. 换新电容，确认无误再上电；
4. 上电用限流电源，观察电流/温度。

#### 坑 2：耐压贴着额定值用

**现象**：电容寿命短、漏电大、击穿短路。
**原因**：工作电压接近/超过额定，或忽略浪涌/瞬态。
**排查顺序**：

1. 算电容两端最大电压（含浪涌）；
2. 按类型降额（MLCC 50%～80%，电解 ≤80%，钽 ≤50%）；
3. 换更高耐压/更大封装；
4. 加 TVS/钳位。

#### 坑 3：忽略 MLCC 的 DC 偏压

**现象**：标称 10μF，实际滤波效果像 4μF；LDO 振荡、纹波大。
**原因**：高-K MLCC 在直流偏压下有效容值大幅下降。
**排查顺序**：

1. 查 DC bias 曲线；
2. 按实际工作电压/温度算最小有效容值；
3. 换更大封装/更高耐压/更大标称；
4. 用聚合物/电解补足。

#### 坑 4：忽略 ESR 和纹波电流

**现象**：电解电容发热、鼓包、寿命短；开关电源输出纹波大。
**原因**：ESR 大，纹波电流在 ESR 上发热；或电容额定纹波不够。
**排查顺序**：

1. 查 ESR/纹波电流规格；
2. 算 `Iripple²×ESR`；
3. 选低 ESR/高纹波/105℃ 型号；
4. 并联多个或改聚合物/MLCC。

#### 坑 5：用 Y5V 做定时/滤波

**现象**：定时时间随温度/电压大幅变化，滤波截止频率漂移。
**原因**：Y5V 容值稳定性差（+22/−82%），随温度/偏压变化大。
**排查顺序**：

1. 查介质类型；
2. 定时/精密滤波换 C0G/NP0；
3. 一般去耦可用 X7R/X5R；
4. 不要只看标称容值。

#### 坑 6：在板测电容读数偏大

**现象**：测 100nF 读到 10μF。
**原因**：板上并联了其他电容。
**排查顺序**：

1. 看原理图，找并联电容；
2. 拆一端复测；
3. 不要直接换电容；
4. 用 LCR 表在特定频率测。

#### 坑 7：去耦电容放太远

**现象**：芯片高频噪声大、电源抖动、偶尔死机；加电容也没用。
**原因**：电容到引脚/地的走线太长，ESL 大，高频电流供不上。
**排查顺序**：

1. 看布局：电容是否紧贴电源脚；
2. 过孔是否靠近焊盘；
3. 回流路径是否完整；
4. 按芯片手册调整容值/数量/位置。

#### 坑 8：耦合电容太小

**现象**：音频低频不足、信号低频段衰减大。
**原因**：高通截止频率太高，`fc=1/(2πRC)` 与输入阻抗不匹配。
**排查顺序**：

1. 确认后级输入阻抗；
2. 算 fc；
3. 加大电容或调整偏置电阻；
4. 注意极性/耐压。

#### 坑 9：RC 滤波器带重负载

**现象**：空载截止频率正常，接负载后输出幅度下降、fc 偏移。
**原因**：负载与电容并联/分流，等效 R/C 变了。
**排查顺序**：

1. 算负载等效阻抗；
2. 加缓冲/运放；
3. 降低 R 或增大 C（但功耗/响应变差）；
4. 重新仿真。

#### 坑 10：大电容断电后存电

**现象**：断电后触碰板子被电到，或短路打火。
**原因**：大电容储存能量，断电后仍保持电压。
**排查顺序**：

1. 断电后等待；
2. 用合适电阻放电（不要螺丝刀直接短路）；
3. 测电压确认接近 0V；
4. 再操作。

1. `100nF` 等于多少 `μF`？`104` 是多少？
2. 10kΩ+100μF 的 τ 是多少？1τ 时电压到多少（5V 充电）？
3. 1kΩ+100nF 的 τ 和低通 fc 各是多少？
4. 1μF+10kΩ 的高通 fc 是多少？
5. 去耦电容为什么必须靠近芯片电源脚？
6. 10μF X5R 在 5V 偏压下可能只剩多少？选型要看什么曲线？
7. 电解电容和钽电容的降额建议是多少？
8. RC 复位 10kΩ+10μF，Vcc=3.3V，Vth=1.6V，延时约多少？
9. 在板测 100nF 读到 10μF，最可能的原因是什么？
10. 大电容断电后为什么不能直接用手碰？

<details>
<summary>参考答案</summary>

1. `100nF=0.1μF`；`104=100nF`。
2. `τ=10000×100e-6=1s`；1τ 约 `5×0.632=3.16V`。
3. `τ=1000×100e-9=0.1ms`；`fc≈1.59kHz`。
4. `fc≈15.9Hz`。
5. 走线有电感，放远了高频瞬态电流供不上；电容—引脚—地回路要短。
6. 可能只剩 4～6μF 甚至更低；要看“capacitance vs DC bias”曲线，按实际电压/温度算最小有效容值。
