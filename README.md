# PCB 设计系统教学课程

> 从电学基础到 PCB 设计、制作与验证。以理解、练习、实物验证和复盘为推进依据，不以课时或月份作为完成标准。

## 使用方法

课程按建议学习顺序重新编号。基础课先学能支撑下一步实践的部分；焊接、工程实践与测试的进阶章节可在项目推进时回看。练习从安全低压电路开始；市电、锂电池及高风险维修只在具备明确条件和指导时学习。

项目成果分为**设计练习、参考工程解读和实物验证**。只有实际完成并保留记录，才能标注为实测通过。STM32 示例固件仅完成编译与镜像结构检查，尚未下载或在实板运行。

## 学习路径与练习资料

先从安全低压测量、基础器件和典型电路入手；学完第 04、05 课的相关内容后，练习传感器、比较器与驱动。完成第 07～09 课的 EDA 与基础焊接后，可继续开展首板、循迹小车和 STM32 项目。以下练习资料与 26 课并行使用，不改变课号和原有学习勾选项。

- [基础练习与实验记录手册](基础练习与实验记录手册.md)：限流、分压、滤波、开关和比较器的带答案练习与实验记录表。
- [模拟电路进阶练习](模拟电路进阶练习.md)：运放、高低端电流检测、恒流反馈、比较器迟滞与跨阻放大的带答案练习。

新项目的设计、仿真、规则检查、生产准备与实板测试分别记录；没有实际结果的项目保持待验证。初学练习只使用合适的隔离低压供电。

## 贯穿练习与项目记录

以低压 LED / RC 练习连接电路计算、测量、EDA 和焊接；接着通过纯硬件循迹小车练习传感、比较器与驱动，之后以 STM32 项目串起数据手册、供电、接口、代码和测试。实践时记录：

1. 目标和范围：功能、输入输出及不包含的部分。
2. 设计依据：具体型号、手册版本、约束出处和选型条件。
3. 设计文件：原理图、PCB、封装、BOM 与生产文件版本。
4. 制作条件：板厂工艺、器件来源、替代料与装配方式。
5. 验证结果：仪器、接线、条件、预期值、实际值和异常。
6. 复盘与未决项：修改记录、未验证事项和下一步。
