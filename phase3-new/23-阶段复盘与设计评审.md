# 第 23 章 · 阶段复盘与设计评审

> **所属阶段**：阶段三 · 单片机与第一块项目板
> **前置课程**：第 17～22 章
> **本课难度**：⭐⭐

## 本章目标

学完本章，你应该能够：

1. 用一张评审清单覆盖原理图、PCB、BOM、测试四类问题。
2. 组织一次 30～60 分钟的设计评审，并记录结论。
3. 区分“必须改”“建议改”“接受风险”三级问题。
4. 用 FMEA/风险矩阵给问题排优先级。
5. 把评审结论转成改版任务和验证计划。
6. 复盘阶段三的学习成果，找出下一个短板。
7. 说出至少 8 个评审常见坑。

设计评审不是“挑毛病大会”，是“在投板前用别人的眼睛找自己的盲区”。评审记录比评审本身更重要。

## 正文

### 23.1 它解决什么问题：三个真实场景

#### 场景一：评审只看了原理图，PCB 封装错了

评审会上大家对着原理图讨论，没人打开 PCB 看封装。投板后发现 USB 座封装反了。评审要覆盖“图—板—料—测”四块。

#### 场景二：问题记了一堆，没人闭环

评审记录写了 20 条，改版时只改了 5 条，剩下的又带到下一版。每条问题要有责任人/截止/验证方式。

#### 场景三：评审变成“领导拍板”

没有清单，靠个人经验，漏掉电源余量/ESD/测试点。评审要有固定清单和分级。

### 23.2 它是什么：四块清单 + 三级结论

四块：

1. **原理图**：电源、复位、时钟、接口、保护、ERC。
2. **PCB**：布局、地、差分、晶振、电源、DRC、丝印。
3. **BOM/生产**：封装、替代料、钢网、坐标、测试点。
4. **测试**：Bring-Up、功能、环境、可靠性。

三级结论：

- **P0 必须改**：会导致不工作/损坏/无法生产。
- **P1 建议改**：影响可靠性/成本/可维护性。
- **P2 接受风险**：记录原因，下一版再改。

> **术语第一次出现**：风险矩阵（risk matrix）用“严重度×发生概率”给问题分级，决定先改什么。

### 23.3 关键检查项

| 类别 | 检查项 | 判据 |
|---|---|---|
| 电源 | 余量/散热/去耦 | 峰值×1.3 |
| 复位 | RC/按键/BOOT | 按手册 |
| 时钟 | 晶振/负载电容/包地 | 起振 |
| 接口 | ESD/差分/终端 | 协议 |
| PCB | 地/跨分割/DRC | 清零 |
| BOM | 封装/替代料 | 可采购 |
| 测试 | 测试点/文档 | 可复现 |

### 23.5 选型与降额

评审不是“越严越好”，要按产品定位：

| 产品 | P0 门槛 | 说明 |
|---|---|---|
| 学习板 | 能亮/能下载 | 允许飞线 |
| 小批量产品 | 功能/安规/可生产 | 不能飞线 |
| 工业/医疗 | 可靠性/认证 | 全项 |

### 23.6 测量与仿真

#### 23.6.1 评审记录模板

| 编号 | 问题 | 等级 | 责任 | 措施 | 验证 | 状态 |
|---|---|---|---|---|---|---|
| 1 | USB 封装反 | P0 | | 改封装 | 3D/打样 | 关闭 |
| 2 | LDO 余量不足 | P1 | | 换 1A | 满载温升 | 关闭 |
| 3 | 无测试点 | P2 | | 下一版加 | — | 接受 |

#### 23.6.2 CircuitJS

```circuitjs
rc-lowpass-159
```

用评审中争议的 RC 参数复算，避免“凭感觉”。

#### 23.6.3 动手任务

- 给自己阶段三的板子做一次评审。
- 填 10 条问题，分 P0/P1/P2。
- 给每条写责任/措施/验证。
- 写一段阶段三复盘：会了什么、还缺什么。

### 23.7 常见坑

1. **只看原理图不看 PCB**：封装/布局漏。
2. **没有清单**：靠记忆漏项。
3. **问题不分级**：P0 和 P2 混一起。
4. **不写责任/验证**：改了没确认。
5. **评审太晚**：投板前才看。
6. **只挑错不给方案**：无法闭环。
7. **忽略 BOM/测试点**：生产/调试出问题。
8. **评审记录不归档**：下一版重犯。

### 23.8 本章复盘

#### 23.8.1 公式与规则表

| 公式/规则 | 用途 | 条件与注意 |
|---|---|---|
| 四块清单 | 评审覆盖 | 图/板/料/测 |
| P0/P1/P2 | 分级 | 按后果 |
| 风险矩阵 | 排序 | 严重×概率 |
| 每条闭环 | 改版 | 责任/验证 |
| 评审在投板前 | 时机 | 越早越好 |

#### 23.8.2 术语表

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 设计评审 | design review | 投板前集体检查 |
| P0/P1/P2 | priority | 问题等级 |
| 风险矩阵 | risk matrix | 严重度×概率 |
| 闭环 | closure | 问题改完并验证 |
| 改版 | revision | 下一版设计 |
