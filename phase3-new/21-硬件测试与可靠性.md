## 本章目标

学完本章，你应该能够：

1. 区分功能测试、性能测试、环境测试、可靠性测试。
2. 设计一份覆盖电源/接口/通信/温度的测试计划。
3. 用高低温、振动、老化、EMC 预测试发现“实验室看不到”的问题。
4. 理解降额、余量、失效模式（FMEA）的基本思路。
5. 计算 MTBF 的粗略概念，知道它不能代替实测。
6. 写测试记录与问题闭环表。
7. 说出至少 8 个可靠性设计常见坑。

板子“能跑”不等于“能卖”。可靠性测试是把边界条件提前施加到板子上，让问题在出厂前暴露。

## 正文

### 21.1 它解决什么问题：三个真实场景

#### 场景一：常温正常，高温复位

板子在空调房跑一周没事，夏天户外 60℃ 时 MCU 反复复位。LDO 结温超限/晶振频偏/电容 ESR 变化。高温测试要覆盖最坏环境。

#### 场景二：实验室 EMC 过，现场死机

实验室辐射发射勉强过，现场变频器/继电器干扰一来，MCU 跑飞。EMC 不只是“过认证”，还要看抗扰度。

#### 场景三：出货 3 个月，批量虚焊

首批 100 台，3 个月后 5 台虚焊。焊点当时目视 OK，但热循环后开裂。可靠性要用温度循环/振动加速暴露。

### 21.2 它是什么：四层测试

| 层级 | 目的 | 典型项目 |
|---|---|---|
| 功能测试 | 每个功能是否工作 | 电源/接口/通信/按键 |
| 性能测试 | 指标是否达标 | 纹波/精度/速率/温升 |
| 环境测试 | 极端条件下是否工作 | 高低温/湿热/振动/跌落 |
| 可靠性测试 | 寿命/失效概率 | 老化/温度循环/MTBF |

> **术语第一次出现**：降额（derating）是让器件工作在额定值以下（如电容耐压用 50%），以降低失效率。余量（margin）是设计指标与极限之间的差距。

### 21.3 关键参数与标准

| 测试 | 条件 | 判据 |
|---|---|---|
| 高低温 | −20～+70℃（按产品） | 功能正常/无复位 |
| 温度循环 | −40～+85℃，若干循环 | 无焊点开裂 |
| 湿热 | 40℃/93%RH | 无漏电/腐蚀 |
| 振动 | 按运输/使用 | 无松脱 |
| ESD | 接触/空气放电 | 不损坏/可自恢复 |
| 辐射/传导 | CISPR/EN | 限值内 |
| 老化 | 满载 24～72h | 无异常 |

### 21.5 选型与降额

| 器件 | 降额建议 | 原因 |
|---|---|---|
| 电容 | 耐压 50%，温度按最坏 | ESR/寿命 |
| 电阻 | 功率 50% | 温升 |
| 连接器 | 电流 50% | 接触电阻 |
| LDO | 结温留 20℃ | 热 |
| 继电器 | 触点 50% | 寿命 |
| 晶振 | 温度范围覆盖 | 频偏 |

### 21.7 常见坑

1. **只测常温**：高温复位/低温不起振漏掉。
2. **样本太少**：1 台通过不代表批量。
3. **不测最坏负载**：满载掉压。
4. **忽略连接器/线缆**：现场松脱。
5. **EMC 只做发射**：抗扰度不过。
6. **降额不足**：电容/电阻长期漂移。
7. **测试记录不全**：问题无法复现。
8. **问题不闭环**：改版又犯。
9. **MTBF 当实测**：计算值不能代替寿命测试。

### 21.8 本章复盘

#### 21.8.1 公式与规则表

| 公式/规则 | 用途 | 条件与注意 |
|---|---|---|
| 降额 50% | 电容/电阻/连接器 | 按最坏 |
| 温度循环 −40～+85℃ | 焊点 | 按标准 |
| ESD ±4kV 接触 | 接口 | 按产品 |
| FMEA 三维 | 风险排序 | 严重/发生/探测 |
| MTBF ≠ 实测 | 可靠性 | 仅参考 |

#### 21.8.2 术语表

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 降额 | derating | 工作在额定值以下 |
| 余量 | margin | 指标与极限的差距 |
| FMEA | failure mode and effects analysis | 失效模式分析 |
| MTBF | mean time between failures | 平均无故障时间 |
| 温度循环 | thermal cycling | 高低温度交替 |
| 抗扰度 | immunity | 抵抗干扰的能力 |
