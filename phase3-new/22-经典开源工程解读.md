# 第 22 章 · 经典开源工程解读

> **所属阶段**：阶段三 · 单片机与第一块项目板
> **前置课程**：第 21 章 硬件测试与可靠性
> **本课难度**：⭐⭐

## 本章目标

学完本章，你应该能够：

1. 用“结构—电源—接口—布局—测试”五步法读一个陌生开源工程。
2. 在 GitHub/立创开源广场找到可复现的 STM32/ESP32 项目。
3. 判断一个开源工程是否“能打样”：BOM、Gerber、封装、许可证。
4. 从开源工程里提取可复用的电路块和布局规则。
5. 避免直接抄板导致的许可/封装/器件停产问题。
6. 写一份工程解读笔记，列出优点、风险、可复用点。
7. 说出至少 8 个读开源工程的常见坑。

读开源工程不是“下载来打样”，是学别人的设计决策。看懂“为什么这样接”，比抄一张图值钱。

## 正文

### 22.1 它解决什么问题：三个真实场景

#### 场景一：下载了工程，打开全是未知封装

GitHub 上的 KiCad 工程缺库/缺 3D，打开一片红。作者只传了 `.kicad_pcb`，没传 `fp-lib-table`/自定义库。读工程先看库依赖。

#### 场景二：BOM 里器件全停产

一个 2018 年的开源板，BOM 里 LDO/连接器全停产，替代料没写。直接打样买不到料。开源工程要检查器件生命周期。

#### 场景三：许可证不允许商用

工程标 MIT，但原理图里引用了某公司的参考设计/受版权保护的库。商用前要读 LICENSE 和第三方声明。

### 22.2 它是什么：五步读图法

1. **结构**：板子分几个功能块，接口在哪。
2. **电源**：输入→各级稳压→负载，电源树和去耦。
3. **接口**：USB/串口/显示/无线，保护/匹配。
4. **布局**：分区、地平面、晶振、差分、散热。
5. **测试**：有没有测试点、Bring-Up 文档、已知问题。

> **术语第一次出现**：可复现（reproducible）指别人拿到工程、BOM、Gerber、说明，能做出同样的板并复现测试结果。只传 PCB 文件不算可复现。

### 22.3 关键检查项

| 检查项 | 看什么 | 风险 |
|---|---|---|
| LICENSE | 是否允许商用/修改 | 侵权 |
| 库依赖 | 自定义符号/封装 | 打不开 |
| BOM | 器件是否停产/替代料 | 买不到 |
| Gerber | 层数/钻孔/阻抗 | 做不出 |
| 文档 | 上电/测试/已知问题 | 复现不了 |
| 版本 | 最后更新/issue | 过时 |

### 22.5 选型与降额

| 工程来源 | 可信度 | 注意 |
|---|---|---|
| 芯片原厂参考设计 | 高 | 按 EVB 改 |
| 大厂开源硬件 | 高 | 读许可证 |
| GitHub 个人项目 | 中 | 看 issue/更新 |
| 立创开源广场 | 中 | 库/封装要复核 |
| 论坛附件 | 低 | 无版本/无测试 |

### 22.6 测量与仿真

#### 22.6.1 读工程顺序

1. 读 README/LICENSE。
2. 看原理图 PDF/图片。
3. 看 BOM 和 Gerber。
4. 打开工程，检查库依赖。
5. 看 issue/已知问题。
6. 提取 2～3 个可复用块。

### 22.7 常见坑

1. **只看图不看 LICENSE**：商用侵权。
2. **直接打样不查 BOM**：器件停产。
3. **缺库打不开**：浪费时间。
4. **照抄参数不重算**：工况不同。
5. **忽略已知问题**：issue 里已写。
6. **封装不复核**：丝印/焊盘不对。
7. **不看版本**：老工程器件过时。
8. **把开源当“免测试”**：别人测试条件不同。

### 22.8 本章复盘

#### 22.8.1 公式与规则表

| 公式/规则 | 用途 | 条件与注意 |
|---|---|---|
| 五步读图 | 读工程 | 结构/电源/接口/布局/测试 |
| LICENSE 先读 | 合规 | 商用/修改 |
| BOM 查生命周期 | 可制造 | 替代料 |
| 复用要重算 | 参数 | 工况不同 |
| 可复现 = 工程+BOM+Gerber+文档 | 判断 | 缺一不可 |

#### 22.8.2 术语表

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 可复现 | reproducible | 别人能做出同样的板 |
| 库依赖 | library dependency | 自定义符号/封装 |
| 生命周期 | lifecycle | 器件是否停产 |
| 参考设计 | reference design | 原厂给的样板 |
| 许可证 | license | 使用/修改/商用权限 |
