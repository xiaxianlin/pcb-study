## 正文

### 17.1 它解决什么问题：三个真实场景

#### 场景一：GPIO 直接驱动 LED，电流超限

LED 串联电阻算错，GPIO 输出 20mA 已经接近极限；多路 LED 同时亮，端口总电流超限，MCU 发热/复位。GPIO 有单脚和总和两个限制，驱动负载要查手册。

#### 场景二：I²C 设备不响应，地址/上拉错

传感器地址脚悬空，实际地址和软件里写的不一致；上拉电阻 10k 太大，总线电容大，上升沿变慢。I²C 不是“接两根线就行”。

#### 场景三：ADC 读数跳，参考电压/输入阻抗没算

ADC 输入直接接高阻分压，采样保持电容充电不够；参考电压用 VDDA 但 VDDA 有纹波。ADC 前端要加 RC/缓冲，参考要干净。

### 17.2 它是什么：MCU 是“带外设的 CPU”

MCU（Microcontroller Unit，微控制器）把 CPU、Flash、RAM、时钟、复位、外设集成到一颗芯片。最小系统：

- 电源（VDD/VDDA/VSS）
- 时钟（晶振/内部 RC）
- 复位
- 启动模式（BOOT）
- 调试（SWD/JTAG）

常用外设：

| 外设 | 硬件本质 | 典型用途 |
|---|---|---|
| GPIO | 可配置数字引脚 | LED、按键、使能 |
| 定时器 | 计数器/比较器 | 延时、PWM、捕获 |
| ADC | 采样保持 + 逐次逼近 | 电压/电流/温度 |
| UART | 异步串行 | 串口、Modbus |
| SPI | 同步串行（4 线） | Flash、屏、传感器 |
| I²C | 两线总线 | EEPROM、传感器 |
| DMA | 外设↔内存搬运 | ADC/SPI 大数据 |

> **术语第一次出现**：推挽（push-pull）输出能主动拉高/拉低；开漏（open-drain）只能拉低，必须外加上拉。I²C 的 SDA/SCL 就是开漏。

### 17.3 关键参数与手册

| 参数 | 看哪里 | 设计影响 |
|---|---|---|
| 工作电压 | VDD 范围 | 电平匹配 |
| GPIO 电流 | 单脚/总和 | 驱动能力 |
| GPIO 耐压 | 5V 容忍？ | 能否直连 5V |
| ADC 位数/速率 | 12bit/1MSPS | 精度/采样 |
| 参考电压 | VREF/VDDA | 精度 |
| UART 波特率 | 时钟/分频 | 通信误差 |
| SPI 速率 | 主/从 | 走线/匹配 |
| I²C 速率 | 100k/400k/1M | 上拉/电容 |

### 17.5 选型与降额

| 外设 | 选型 | 降额 |
|---|---|---|
| GPIO 驱动 LED | 电阻按 5～10mA | 不超单脚/总和 |
| 按键 | 上拉 10k + 100nF | 去抖 |
| ADC 分压 | 源阻抗 ≤ 手册 | 加 RC/缓冲 |
| UART | 波特率误差 <3% | 晶振精度 |
| SPI | 速率按走线 | 长线降速 |
| I²C | 上拉按速率/电容 | 总线电容 <400pF |

### 17.7 常见坑

1. **GPIO 直驱大电流负载**：端口烧/复位。
2. **5V 信号直连 3.3V GPIO**：除非手册标 5V 容忍。
3. **I²C 上拉太大/太小**：上升沿差/功耗大。
4. **SPI CS 共用**：多设备冲突。
5. **ADC 源阻抗太高**：采样不准。
6. **UART TX/RX 没交叉**：通信不通。
7. **BOOT 脚悬空**：启动模式随机。
8. **复位脚无滤波**：干扰复位。
9. **时钟配置错**：波特率/定时全偏。

### 17.8 本章复盘

#### 17.8.1 公式与规则表

| 公式/规则 | 用途 | 条件与注意 |
|---|---|---|
| `R=(VDD−VF)/I` | LED 限流 | 按目标电流 |
| `Vout=Vin×R2/(R1+R2)` | ADC 分压 | 源阻抗要低 |
| UART 交叉 TX/RX | 通信 | 共地 |
| I²C 开漏+上拉 | 总线 | 地址不冲突 |
| SPI 独立 CS | 多设备 | 速率/走线 |

#### 17.8.2 术语表

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| GPIO | general purpose IO | 通用输入输出 |
| 推挽 | push-pull | 主动拉高/拉低 |
| 开漏 | open-drain | 只能拉低，需上拉 |
| ADC | analog-to-digital converter | 模数转换 |
| UART | universal asynchronous receiver/transmitter | 异步串口 |
| SPI | serial peripheral interface | 同步四线总线 |
