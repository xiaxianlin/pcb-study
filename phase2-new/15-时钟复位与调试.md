## 正文

### 15.1 它解决什么问题：三个真实场景

#### 场景一：晶振不起振，MCU 卡在启动

晶振负载电容选错/走线太长，起振失败。MCU 用内部 RC 能跑，但 USB/串口波特率不准。晶振要靠近芯片，负载电容按手册，走线短、包地。

#### 场景二：复位脚被电容“按住”，程序不跑

复位电路 RC 时间常数太大，上电后复位脚长时间低电平，MCU 一直不启动。或者复位按键卡住，现场“死机”。复位要按手册的复位时间设计。

#### 场景三：SWD 少接一根地，下载失败

SWD 只接了 SWDIO/SWCLK，没接 GND，或者 GND 接触不良。下载器能识别芯片但不稳定。调试接口必须 GND、VCC、SWDIO、SWCLK 四根可靠连接。

### 15.2 它是什么：四件套与小模块

- **时钟**：晶振/陶瓷谐振器/内部 RC，给 MCU 和外设提供节拍。
- **复位**：上电复位（POR）、手动复位、看门狗复位、低电压复位。
- **调试**：SWD（Serial Wire Debug）两线调试，JTAG 四/五线。
- **常见模块**：EEPROM、按键、蜂鸣器、I²C 传感器、LED。

> **术语第一次出现**：负载电容（CL）是晶振两端到地的电容，和晶振的指定负载电容匹配。选错会导致频率偏移或不起振。

### 15.3 关键参数与手册

| 项目 | 关键参数 | 说明 |
|---|---|---|
| 晶振 | 频率、负载电容 CL、ESR、精度 | 按 MCU 手册选 |
| 负载电容 | C1/C2 | `C1≈C2≈2×(CL−Cstray)` |
| 复位 | 复位阈值、复位时间 | 按 MCU 手册 |
| SWD | SWDIO/SWCLK/GND/VCC | 上拉/串联电阻按手册 |
| EEPROM | 地址、I²C 速率 | 地址不能冲突 |
| I²C 上拉 | 2.2k～10k | 按速率/总线电容 |
| 按键 | 上拉/下拉、去抖 | RC/软件去抖 |

晶振负载电容估算：

`C1 = C2 ≈ 2×(CL − Cstray)`

例：CL=8pF，Cstray=3pF，则 `C1=C2≈10pF`，取 10pF/12pF 标准值。

### 15.5 选型与降额

| 模块 | 选型要点 | 降额 |
|---|---|---|
| 晶振 | 频率/CL/精度/封装 | 负载电容按手册，不随意 |
| 复位 IC | 阈值/延时/手动复位 | 阈值覆盖电源波动 |
| EEPROM | 容量/接口/地址 | 地址不冲突 |
| 按键 | 行程/寿命/防水 | 上拉/去抖 |
| 蜂鸣器 | 有源/无源/电压/电流 | 三极管/MOS 驱动 |
| I²C 传感器 | 地址/速率/量程 | 上拉/总线电容 |

### 15.7 常见坑

1. **晶振负载电容拍脑袋**：频率偏/不起振。
2. **晶振走线太长**：易受干扰。
3. **复位电容太大**：上电不启动。
4. **复位按键卡住**：现场“死机”。
5. **SWD 不接地**：下载不稳定。
6. **I²C 地址冲突**：总线读不到。
7. **I²C 上拉太小/太大**：波形上升沿差/功耗大。
8. **蜂鸣器直接用 GPIO 驱动**：电流超限。
9. **EEPROM 写保护脚悬空**：数据被误写。
