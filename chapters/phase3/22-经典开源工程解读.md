# 第 22 章 · 经典开源工程解读

> **所属阶段**：阶段三 · 单片机与第一块项目板
> **前置课程**：第 21 章 硬件测试与可靠性
> **本课难度**：⭐⭐

## 本章目标

学完本章，你应该能够：

1. 用“结构—电源—接口—布局—测试”五步法读一个陌生开源工程。
2. 在 GitHub/立创开源广场找到可复现的 STM32/ESP32 项目。
3. 判断一个开源工程是否“能打样”：BOM、Gerber、封装、许可证。
4. 从开源工程里提取可复用的电路块和布局规则。
5. 避免直接抄板导致的许可/封装/器件停产问题。
6. 写一份工程解读笔记，列出优点、风险、可复用点。
7. 说出至少 8 个读开源工程的常见坑。

读开源工程不是“下载来打样”，是学别人的设计决策。看懂“为什么这样接”，比抄一张图值钱。

## 正文

### 22.1 它解决什么问题：三个真实场景

#### 22.1.1 场景一：下载了工程，打开全是未知封装

GitHub 上的 KiCad 工程缺库/缺 3D，打开一片红。作者只传了 `.kicad_pcb`，没传 `fp-lib-table`/自定义库。读工程先看库依赖。

#### 22.1.2 场景二：BOM 里器件全停产

一个 2018 年的开源板，BOM 里 LDO/连接器全停产，替代料没写。直接打样买不到料。开源工程要检查器件生命周期。

#### 22.1.3 场景三：许可证不允许商用

工程标 MIT，但原理图里引用了某公司的参考设计/受版权保护的库。商用前要读 LICENSE 和第三方声明。

### 22.2 它是什么：五步读图法

1. **结构**：板子分几个功能块，接口在哪。
2. **电源**：输入→各级稳压→负载，电源树和去耦。
3. **接口**：USB/串口/显示/无线，保护/匹配。
4. **布局**：分区、地平面、晶振、差分、散热。
5. **测试**：有没有测试点、Bring-Up 文档、已知问题。

> **术语第一次出现**：可复现（reproducible）指别人拿到工程、BOM、Gerber、说明，能做出同样的板并复现测试结果。只传 PCB 文件不算可复现。

### 22.3 关键检查项

| 检查项 | 看什么 | 风险 |
|---|---|---|
| LICENSE | 是否允许商用/修改 | 侵权 |
| 库依赖 | 自定义符号/封装 | 打不开 |
| BOM | 器件是否停产/替代料 | 买不到 |
| Gerber | 层数/钻孔/阻抗 | 做不出 |
| 文档 | 上电/测试/已知问题 | 复现不了 |
| 版本 | 最后更新/issue | 过时 |

读图要点：AM335x + DDR3 + eMMC + 以太网 + HDMI + cape 排针；PRU 可做实时 IO，是它区别于普通 MCU 的特色。5V 输入→3.3V/1.8V/1.5V/1.1V 多路，DDR 电源与 VREF 单独，上电时序按 AM335x 手册。HDMI TMDS 100Ω、以太网 100Ω、USB 90Ω；cape 排针有电平/保护，扩展板可能反灌。6 层，DDR 与 SoC 相邻层参考，HDMI/USB 差分靠板边，晶振包地。

可复用块：

| 块 | 为什么值得复用 | 复用时改什么 |
|---|---|---|
| AM335x 多路电源 | 工业级稳定 | 按手册改时序/滤波 |
| DDR3 拓扑 | 中等速率 | 按速率/位宽改等长 |
| cape 扩展排针 | 生态扩展 | 按电平/电流加保护 |
| HDMI/以太网 ESD | 接口可靠 | 按连接器/标准改器件 |

容易踩的点：cape 扩展板反灌、DDR 电源噪声、HDMI ESD 电容影响眼图、eMMC 与 SD 启动顺序。读工程时看“cape 兼容性说明”和“电源时序图”。

#### 22.4.10 BOM 对比表

| 类别 | Uno | OrangePi Zero | CM4IO | BBB |
|---|---|---|---|---|
| 主控 | ATmega328P（TQFP） | H3（BGA） | CM4 模块 | AM335x（BGA） |
| 存储 | 无 | DDR3 + microSD | LPDDR4 + eMMC | DDR3 + eMMC |
| 电源 | 5V/3.3V LDO | 多路 DCDC | 12V Buck + 多路 | 多路 LDO/DCDC |
| 接口 | USB-B/排针 | RJ45/USB/天线 | PCIe/HDMI/USB/M.2 | HDMI/RJ45/USB/cape |
| 保护 | 保险丝/ESD | ESD/变压器 | ESD/共模 | ESD/变压器 |
| 关键成本 | 低 | 中 | 高 | 高 |

读 BOM 的顺序：先看主控/存储/连接器（长交期、易停产），再看电源芯片（替代难），最后看阻容（可替代）。四块板都体现一个规律：**越靠近接口和电源的器件，越决定可制造性**。

### 22.7 常见坑

1. **只看图不看 LICENSE**：商用侵权。
2. **直接打样不查 BOM**：器件停产。
3. **缺库打不开**：浪费时间。
4. **照抄参数不重算**：工况不同。
5. **忽略已知问题**：issue 里已写。
6. **封装不复核**：丝印/焊盘不对。
7. **不看版本**：老工程器件过时。
8. **把开源当“免测试”**：别人测试条件不同。
