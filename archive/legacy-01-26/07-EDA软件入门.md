# 第 07 课 · EDA 软件入门

> **所属阶段**：阶段二 · EDA、PCB 与基础制作
> **前置课程**：第 04 课 · 硬件基础
> **本课难度**：⭐⭐

## 🎯 本课目标

学完这一课，你应该能够：

1. 说清 EDA 软件是什么、在 PCB 设计全流程中处于什么位置
2. 对比立创EDA、Altium Designer、KiCad、PADS 四款主流软件的定位，明确"入门用哪个、主修用哪个"
3. 独立完成软件安装与基础设置（单位、栅格）
4. 理解工程文件、原理图文件、PCB 文件、库文件之间的关系
5. 在原理图环境中完成放置元件、连线、放网络标号；在 PCB 环境中认识层、走线、过孔、铺铜并各操作一次
6. 会从官方库、立创商城库、第三方库获取元器件并装入自己的工程

## 📖 正文

第 04 课认识了元器件和电路理论，这一课把"纸上的电路"搬进电脑。EDA 软件就是 PCB 设计师的"办公桌"，本课结束时，你要能独立画出一张小原理图并把它导入 PCB 随手走几根线——操作先混个脸熟，设计规范在第 09 课展开。

### 07.1 EDA 软件是什么、主流软件对比

EDA（Electronic Design Automation，电子设计自动化）软件覆盖"从电路到板子"的全部数字化工作：原理图绘制、电路仿真（部分软件）、封装库管理、PCB 布局布线、设计规则检查（DRC）、生产文件输出。你可以把它理解为"电路界的 CAD + 办公全家桶"。

主流软件对比：

| 软件 | 背景 | 费用 | 生态 | 学习曲线 | 行业使用 |
|---|---|---|---|---|---|
| 立创EDA | 立创商城 | 免费 | 与商城元件库/下单打样打通，中文资料多 | 平缓 | 国内爱好者、教学、中小团队 |
| Altium Designer（AD） | Altium | 商业收费 | 教程最多、功能全面 | 中等 | 国内消费电子、中小企业主流 |
| KiCad | 开源社区 | 免费开源 | 国外社区活跃、官方库完善 | 中等 | 开源硬件、不少国外公司 |
| PADS | Siemens EDA（原 Mentor） | 商业收费 | 高速设计与仿真生态强 | 中等偏缓 | 工控、通信、大型企业 |

选择建议：

- 目标就业国内电子行业：**主修 Altium Designer**，辅看立创EDA。可按岗位及设备选择 AD、KiCad 或立创EDA；工具的具体操作以对应版本手册为准
- 兴趣党/想最快出板：立创EDA 起步最快，元件库一键导入，下单打样无缝衔接
- 好消息：四款软件的设计思想完全相通——都需要表达原理图、网络、封装和 PCB 之间的关系。迁移时还需重新学习库、规则、文件和协作流程，不只是换快捷键

初学者最常问的三个问题：

- **问：要不要两款都学？** 答：不要。先用一款画完第 09 课的完整项目，再考虑第二款；换软件的成本远比想象低。
- **问：公司用 PADS，我学 AD 白学了吗？** 答：不白学。布局布线的"思路"是通用的，软件只是工具，面试考的也是思路。
- **问：老电脑带不动 AD 怎么办？** 答：立创EDA 对配置要求低，浏览器即可用，功能足够完成本阶段全部练习。

### 07.2 软件安装

#### 07.2.1 Altium Designer

- 系统要求：Windows 10/11 64 位；内存建议 16GB 起，显卡支持 OpenGL（经验配置；大板更吃资源）
- 版本建议：选近三年的稳定版本。新版本功能新但教程少，太老的版本缺新特性——原则是"选你能找到配套教程的版本"
- 获取渠道：官网下载安装包，按学校/公司/个人订阅情况合规使用正版（学生有教育优惠渠道，可搜索 "Altium 教育版"）
- Mac 用户注意：AD 无原生 Mac 版。方案：Windows 虚拟机/远程主机，或改用 KiCad、立创EDA（浏览器即用）

#### 07.2.2 立创EDA

- 标准版和专业版是不同产品版本；专业版既有网页版也有客户端。可按设备、功能与项目协作选择，版本间数据迁移方式见[专业版官方说明](https://prodocs.lceda.cn/cn/introduction/introduction/)。
- 官网注册账号后免费使用，工程可云端保存
- 最大优势：直接调用立创商城元器件（可能包含原理图符号、封装和 3D 模型，仍需逐项核对器件资料），画完即可下单

#### 07.2.3 安装后的基础设置

- 单位切换：AD 中按 Q 键在 mil/mm 之间切换。国内板厂多用 mm，老工程师习惯用 mil，你两种都要能读（1mil ≈ 0.0254mm，20mil ≈ 0.5mm）
- 栅格（Grid）：原理图可视栅格 100mil；PCB 布局栅格 0.5mm 级、布线栅格 0.05~0.1mm 级（经验值，先照抄，后面理解）
- 层颜色：用默认即可。关键是认层名而不是认颜色——换一台电脑颜色可能就不一样了
- 自动备份：AD 在设置里可开自动保存（默认间隔较短即可），立创EDA 有云端历史版本——但都替代不了手动另存版本的习惯
- 显示与卡顿：画面卡顿时可关掉不必要的层显示（如 3D 模式、网络高亮），笔记本建议插电使用

### 07.3 界面认识与基本操作

#### 07.3.1 工程结构与三种文件的关系

AD 中一个典型工程的文件构成：

- xxx.PrjPcb —— 工程文件（相当于"文件夹"，管理下面所有文件）
- xxx.SchDoc —— 原理图文件（电路的逻辑连接）
- xxx.PcbDoc —— PCB 文件（物理实现）
- xxx.SchLib / xxx.PcbLib —— 原理图符号库 / PCB 封装库

一句话讲清关系：**原理图描述"电路在逻辑上怎么连"，封装描述"元件在板上长什么样"，PCB 文件是两者结合后的物理板**。原理图到 PCB 之间靠"网表（Netlist）"传递——它是一张"谁和谁该连通"的清单。

立创EDA 对应概念：工程 → 原理图 → PCB → 元件库，一一对应，只是文件后缀不同。

#### 07.3.2 常用快捷键（Altium Designer）

先记住"高频十条"，其余用到再查：

| 快捷键 | 环境 | 功能 |
|---|---|---|
| P → W | 原理图 | 放置导线（Wire） |
| P → P | 原理图 | 放置元件（Part） |
| P → N | 原理图 | 放置网络标号（Net Label） |
| Space 空格 | 通用 | 旋转选中对象 90° |
| Tab | 放置中 | 修改正在放置对象的属性 |
| P → T | PCB | 交互式布线（走线） |
| P → G | PCB | 铺铜（Polygon Pour） |
| Ctrl + M | PCB | 测量距离 |
| Q | PCB | mil / mm 单位切换 |
| V → F | 通用 | 视图缩放至适合全部（图丢了就按它） |

补充：布线中按小键盘 * 或 +/- 切换信号层，会自动放下过孔；Shift+R 循环切换布线推挤模式（绕开/推挤障碍物）。

立创EDA 用户：功能集中在顶部菜单与右侧属性面板，快捷键可在设置中自定义，入门阶段直接用菜单即可。

第二组"操作习惯类"快捷键，同样高频：

| 快捷键 | 环境 | 功能 |
|---|---|---|
| Ctrl + Z / Ctrl + Y | 通用 | 撤销 / 重做 |
| Shift + S | PCB | 单层显示模式（只看当前层，查线神技） |
| 3 / 2 | PCB | 切换 3D / 2D 视图（3D 里检查元件干涉） |
| E → O → S | PCB | 设置相对原点（Edit » Origin » Set，需英文输入法；重置为 E → O → R） |
| G | PCB | 弹出捕获栅格菜单（新版 AD；循环切换是 Shift+G） |
| X / Y | 原理图放置中 | 水平 / 垂直镜像 |

记快捷键的方法：一次只记两三个，用到顺手了再加下一批。把快捷键表打印出来贴在显示器边上，是很多工程师的真实做法。

#### 07.3.3 原理图环境实操

画一张"电源 + 限流电阻 + LED"原理图的标准动作：

1. 新建工程，添加原理图文件
2. 放置元件：在库面板搜索并放置电阻、LED；放置电源端口（VCC 与 GND 符号）
3. 连线：P → W 从引脚拖到引脚；在需要连接的位置放置或确认节点（Junction）；交叉线是否相连以软件网络高亮与电气检查为准
4. 放网络标号：连接较远或跨页的网络用 P → N 打标签（如 +5V、LED_OUT），同名标签是否跨页相连取决于其作用域及软件设置；用网络高亮或网表核对
5. 分配位号：用"注释（Annotate）"功能把 R?、D? 自动编号成 R1、D1
6. 检查：编译工程（Compile），看 Messages 面板的错误与警告（如引脚悬空）

网络命名规范（从第一张图就养成）：

- 全大写、无空格、无中文：+5V、3V3、USB_DM
- 电源网络带电压信息：5V、3V3、1V8，一眼识别电压
- 控制信号带方向或用途后缀：LED_EN、UART_TX、KEY1
- 地网络统一 GND；确需区分时用 AGND/PGND（第 10 课会用到）
- 命名规范的网络，能让原理图、PCB、调试记录三者对得上话

新手必懂概念：**网络（Net）= 一组该连在一起的引脚**。原理图的本质工作就是定义网络——这是理解后面一切（网表、飞线、DRC）的钥匙。

#### 07.3.4 PCB 环境实操

1. 从原理图导入网表：AD 中 Design → Update PCB Document，确认变更后，元件带着"飞线（Ratsnest，指示该连未连的细线）"堆在板框外
2. 认识层（Layer）——先认这 6 类（展开就是下表的 10 个层）：

| 层 | 名称 | 用途 |
|---|---|---|
| Top / Bottom Layer | 顶/底层信号层 | 走线、焊盘 |
| Keep-Out Layer | 禁布层 | 限制器件或铜线放置；板框的定义和绘制层按软件及输出流程确认 |
| Mechanical | 机械层 | 装配尺寸、工艺说明 |
| Top/Bottom Overlay | 丝印层 | 白色位号、极性、外框 |
| Top/Bottom Solder Mask | 阻焊层 | 绿油开窗（露出焊盘） |
| Top/Bottom Paste | 锡膏（钢网）层 | 定义贴片锡膏印刷开孔 |

3. 画板框：用当前 EDA 的板框定义功能建立闭合外形；禁布边界不必然等于生产板框。导出后在 Gerber 查看器核对板边
4. 走线：P → T，点一根飞线连到另一端（本课随便走，规范在第 09 课讲）
5. 过孔：走线中按 * 切换到另一层，自动生成过孔（via）——贯穿板层的小铜柱
6. 铺铜：P → G 拉一个覆盖全板的矩形，网络选 GND——这块板"地平面"的雏形就有了
7. 3D 检查：按 3 进入 3D 视图拖动旋转，直观看到元件是否摆反、是否相互干涉；按 2 返回 2D
8. 保存纪律：随手 Ctrl+S；重要节点用"另存为"留版本档案，改坏了能回退

#### 07.3.5 原理图 vs PCB 环境的分工

| | 原理图环境 | PCB 环境 |
|---|---|---|
| 关心什么 | 电气连接对不对 | 物理位置、线宽间距够不够 |
| 主要对象 | 符号、网络 | 焊盘、走线、过孔、铺铜 |
| 检查工具 | 编译（ERC） | 设计规则检查（DRC） |

按软件的变更清单同步原理图与 PCB；同步方向和可回写的内容取决于软件及操作；养成"原理图为准、改动先改原理图再同步"的习惯，避免两边对不上。

**原理图操作与检查的通用顺序**

建立工程并确定器件 → 放置符号和位号 → 按电路连接导线及网络标签 → 标记明确不使用的引脚 → 检查电源、引脚类型和网络 → 给每个器件匹配并核对封装 → 更新 PCB。连线必须落在引脚电气连接点，线条交叉是否连接要看连接点和软件显示；图形线、文字注释本身不产生电气连接。不同软件可能把原理图检查叫 ERC 或原理图 DRC，检查结果必须结合电路复核。

[嘉立创 PCB 设计教程](https://wiki.lceda.cn/zh-hans/contest/e-contests/basic-training/pcb-design.html)可用于对照立创 EDA 的界面和操作；菜单名称、云端功能及版本区别以所用软件当前文档为准。

**立创 EDA 对照练习：从电路意图到可检查的 PCB**

以本课 RC 低通为例，在所用版本中新建工程和原理图；放置电阻、电容、输入排针及输出测试点，为每个器件指定值、唯一位号和候选封装。将 J1 一脚作为输入、另一脚作为地，R1 接输入与 LP_OUT，C1 接 LP_OUT 与地，TP1 接 LP_OUT。用电气导线连接引脚，查看连接点；网络标签用来命名电气网络，装饰线和文本不会产生连接。

完成原理图检查后，查看警告对应的实际网络：未用脚应明确处理，电源输入、无驱动网络或引脚类型提示需结合真实电路判断；不为消除警告随意更改电气属性。导入或更新 PCB 时阅读变更列表，检查位号、网络和封装；确认外形尺寸，预留插接与测试空间，再按板厂约束进行布局布线。修改原理图后重新同步并检查差异，不能只在 PCB 上改网络。

绘制板框、铺铜、生成钻孔和输出生产文件的具体菜单会随立创 EDA 版本变化；按所用版本的官方帮助操作。课程提供的是可验证的动作与结果，不把某个界面菜单截图当成永久步骤。练习板还要核对器件额定值、网络、DRC 和生产文件后才能考虑制作。

### 07.4 元器件库的查找与使用

库的来源，按优先级排：

1. **官方自带库**：AD 安装时自带大量通用库（如 Miscellaneous Devices），电阻电容、接插件、二极管三极管最常用
2. **立创商城库（强烈推荐）**：在立创EDA 中搜索型号 → 一键"复制"该元件 → 导出为 Altium 格式 → 在 AD 中导入使用。可能提供符号、封装和 3D 模型；引脚、尺寸和所选实物仍须对照原厂资料
3. **第三方库平台**：SnapEDA、Ultra Librarian 等提供各大芯片厂商官方符号与封装（搜索"平台名 + 芯片型号"）
4. **自建库**：查不到、或要求严格时必须自建——这是第 09 课的重点，也是招聘方最看重的基本功之一

AD 中安装库的操作路径：Components 面板 → 面板右上角下拉 → File-based Libraries → Install From File，选中库文件（.IntLib / .SchLib / .PcbLib）即可；也可以直接把库文件加入工程（工程树右键 → Add Existing Document），让它跟着工程走。

拿到第三方封装后的验证三步：

1. 对照目标器件的推荐焊盘图检查焊盘中心距、尺寸及公差；若只有器件引脚尺寸，还应结合装配工艺计算焊盘，不能默认统一误差阈值
2. 检查 1 脚标识、极性标识是否齐全正确
3. 放一个器件到 PCB 里目检丝印与焊盘的关系（丝印不压焊盘）

使用纪律（从今天养成）：

- 每个工程挂自己的库文件，不依赖别人电脑上的库——"换台电脑文件打不开"的根源就是库没跟着工程走
- 用过的元件按"厂商_型号"命名存入自己的库，日积月累成"私人武器库"
- 下载的第三方封装，用之前必须对数据手册核一遍焊盘（第 09 课教核对方法）

1. 新建工程 L05_Practice，添加原理图与 PCB 文件
2. 放置元件：电阻 R1、电容 C1、一个 2P 输入排针 J1 和一个输出测试点 TP1
3. 连线构成 RC 低通结构：J1 输入 → R1 → 输出节点 → C1 到地；J1 另一脚接 GND
4. 在输出节点接 TP1 并标记 LP_OUT；输入信号与地接 J1，不要无依据将交流输入直接标为 +5V
5. 自动编号、编译，确认无错
6. 导入 PCB，画一个 30mm × 20mm 的板框
7. 摆开元件，P → T 走通所有飞线，中途换一次层体验过孔
8. P → G 给整板铺 GND 铜
9. 按 3 看一眼 3D，按 Ctrl+M 量板框尺寸是否是 30mm
10. 保存工程，把这 10 步整理成自己的操作笔记

这个流程就是第 09 课九步流程的"迷你彩排"——操作顺了，第 09 课就能专注学规范。

### 07.6 Allegro 与 PADS：什么时候需要学

07.1 的对比表里有立创EDA、AD、KiCad、PADS 四款，还有一位重量级选手没有出场：Cadence Allegro。这两款商业软件在招聘 JD 里出镜率很高，这里专门补齐它们的定位，并回答新手高频问题——"要不要都学"。

#### 两款软件的定位对比

| 软件 | 厂商 | 定位 | 典型用户 | 学习曲线 | 操作风格 |
|---|---|---|---|---|---|
| Cadence Allegro | Cadence | 高端高速板、高密度大型板的事实标准 | 大厂（通信、服务器、手机）、专业 PCB 设计公司 | 陡峭 | 图形界面与可配置脚本结合，约束驱动设计 |
| PADS | Siemens EDA（原 Mentor） | 中端主力，常规板到中等高速板 | 消费电子、中小公司、部分工控 | 中等偏缓 | 图形界面菜单为主，上手快 |

Allegro 的两个标签：

- **大厂高端板主流**：十几层的服务器主板、密度极高的手机主板，很多出自 Allegro；它的约束规则系统（Constraint Manager）极为强大，阻抗、等长、时序规则能精确管到每一根网络
- **学习曲线陡**：需要熟悉命令、界面、约束与库结构（焊盘 Padstack 可独立管理）——入门比 AD 痛苦不少，但天花板也更高

PADS 的两个标签：

- **消费电子与中小公司常见**：规格介于"入门级"与 Allegro 之间，常规 4~8 层板加中等高速需求都能胜任
- **上手快**：整体逻辑与 AD 接近（原理图 Logic → PCB Layout → 库），从 AD 迁移通常一两周即可开工

#### 要不要都学？

**不要。** 先用一款走完 2 层板 → 4 层板 → 8 层板的完整进阶，把叠层、阻抗、等长、电源完整性这些"设计内功"练扎实。入职后根据公司工具和项目复杂度逐步迁移——**软件只是工具，设计思维才是核心**，迁移时仍要学习新软件的库、约束和协作流程。面试官问的是"你的叠层怎么设计、等长怎么处理"，而不是"你按的是哪个快捷键"。

#### 迁移学习法：概念映射表

换软件时不要从零学，而是做一张"概念映射表"——把旧软件里已掌握的概念，挨个找到新软件里对应的名字，迁移效率翻倍：

| 概念 | Altium Designer | 立创EDA | PADS | Allegro |
|---|---|---|---|---|
| 原理图传到 PCB | Update PCB | 原理图转 PCB | 原理图同步（ECO） | 生成网表再导入 |
| 封装库 | .PcbLib | 元件库三件套 | 封装 Decal + 焊盘 | 焊盘 Padstack 与封装 Symbol 分离 |
| 设计规则 | PCB 规则与约束 | 设计规则面板 | 校验规则（Setup） | 约束管理器 Constraint Manager |
| 布线命令 | 交互式布线 P→T | 布线工具 | 走线 Route | add connect |
| 铺铜 | Polygon Pour | 铺铜 | 灌铜 Flood | 铺铜 Shape |

（表内名称为常见叫法，随软件版本有差异，以各软件官方文档为准。）

迁移的实操打法：挑一块你画过的旧板子，在新软件里重画一遍——封装重建、规则重设、布局布线重来。一块板下来，新软件的"肌肉记忆"就建好了。

## ⚠️ 新手常见坑

1. **看着连上了，其实没连上**：导线端点没落在引脚的电气点上（栅格不对齐，或误用绘图直线 Line 代替导线 Wire）。对策：画完跑编译看悬空警告；记住两条导线交叉有节点才连通。
2. **网络标号不一致**："5V"与"5v"、多一个空格，就是两个不同的网络。统一命名风格（建议全大写、无空格）。
3. **网表导入报"找不到封装"**：元件没挂封装，或库没安装、没加入工程。导入前逐个确认元件的 Footprint 属性非空。
4. **单位混乱**：mil 和 mm 差 39 倍。8mil 是常见信号线宽，8mm 是"高速公路"。动工前先按 Q 看清当前单位。
5. **板框画错层**：画在丝印层或信号层，板厂可能识别不了外形。使用 EDA 的板框定义功能，并按板厂要求导出外形；禁布层或机械层图形不一定自动成为生产板框。
6. **高版本文件低版本打不开**：协作或存档时统一软件版本，必要时导出低版本兼容格式。
