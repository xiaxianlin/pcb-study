## 📖 正文

### 19.1 EMC/EMI 处理：不吵别人，也不被吵

**是什么**：EMC（Electromagnetic Compatibility，电磁兼容）指设备在电磁环境中能正常工作、且不向环境发出不可接受的干扰。它包含两面：EMI（Electromagnetic Interference，电磁干扰，"吵别人"）和 EMS（Electromagnetic Susceptibility，电磁抗扰度，"被吵"）。民用产品要做 EMC 认证（国内常见依据 GB 标准族，如信息技术设备类标准），过不了认证产品就不能上市。

**干扰从哪来（先分清传导与辐射）**：

- **传导干扰**：噪声沿电源线、信号线"顺线跑出去"，经验上以 30MHz 以下频段为主，在电源入口处被测。
- **辐射干扰**：噪声通过空间电磁场"空中传播"，经验上以 30MHz 以上为主，在电波暗室或近场测量。

板子上典型的干扰源，排查时按"强度"依次想：

1. **DCDC 的开关节点（SW）**：高 dv/dt、di/dt 的方波，是板内最强干扰源；
2. **时钟与高速总线**：晶振、DDR、HDMI/LVDS 等，边沿越陡谐波越丰富；
3. **感性负载通断**：继电器、电机、接触器断开瞬间的反电动势；
4. **大电流环路**：环路面积越大、电流越大，辐射越强。

**干扰源速查表（看到什么想到什么）**：

| 干扰源/现象 | 常见对策 |
|:---|:---|
| DCDC SW 节点 | 缩小 SW 铜面积、加 RC 吸收电路（Snubber）、栅极串小电阻减缓边沿 |
| 晶振 | 两侧包地 + 地过孔、远离板边与接口、下方内层不走高速线 |
| 高速总线 | 端接、阻抗控制、参考平面完整、减少长距离平行走线 |
| 从接口进来的 EMI/ESD | 共模电感/磁珠滤波、TVS 防护、接口地与机壳地处理好 |
| 大电流环路 | 缩小环路面积、功率路径短而粗、输入输出电容紧靠开关管 |
| 板边辐射 | 板边地过孔缝合、电源平面内缩（20H 原则，见 19.7） |

**怎么做——滤波**：

- 交流输入端典型滤波链路：保险丝 → 压敏电阻（MOV，浪涌钳位）→ X 电容（跨接 L-N，滤差模）→ 共模电感（Common Mode Choke）→ Y 电容（L/N 对地，滤共模）。X/Y 电容是"安规电容"，失效模式可控，**绝不能用普通电容替代**。
- 直流电源入口用磁珠 + 大容值电容组合抑制高频；芯片级用去耦电容（见 19.3）。

**怎么做——接地**：

| 方式 | 适用频率（经验值） | 原理 |
|:---|:---|:---|
| 单点接地 | 低频（约 <1MHz） | 所有地回流到一个点，避免地环路引入共模噪声 |
| 多点接地 | 高频（约 >10MHz） | 就近打地过孔，减小地阻抗和驻波 |
| 混合接地 | 宽频段 | 低频单点 + 高频经电容多点，工程中最常见 |

**怎么做——屏蔽与缝合**：WiFi/射频模块加金属屏蔽罩；大面积铺铜的地平面之间，沿板边与接口每隔一小段距离打**地过孔缝合（Via Stitching）**，经验间距取所关注最高频率波长的 1/20 量级（仅为经验起点，以仿真/实测为准）。

**怎么做——展频**：Spread Spectrum Clocking（SSC 展频时钟）把时钟能量在频率上"摊开"来压低峰值发射。注意：HDMI 等对时钟有严格抖动/频偏要求的接口，乱开展频可能违反规范，能不能开以芯片手册为准。

**敏感信号防护**：复位线、晶振线、模拟小信号要远离 SW 节点、接口连接器与高速总线；必要时两侧包地并加密集地过孔（包地线要真的接地，浮空的包地线反而变成天线）。

**接口防护（ESD/浪涌）**：

- **ESD（静电放电）**：TVS 管 / ESD 二极管阵列，**靠近连接器放置**，让静电能量先泄放到地、再进入芯片；信号路径顺序是"连接器 → 防护器件 → 共模电感/滤波 → 芯片"。
- **浪涌（Surge）**：MOV + 气体放电管（GDT）+ PPTC 自恢复保险丝组合，按防护等级选参数。
- 网口用网络变压器 + Bob Smith 75Ω 端接；USB 常用共模电感 + ESD 阵列；防护器件的地要就近低阻抗接地。

**EMC 整改的通用流程（面试常问"超标了怎么办"）**：

1. **先定位**：用近场探头扫板找"热点"，对照超标频点锁定源头（超标频点往往正好是某个时钟的谐波，这是重要线索）；
2. **源头降**：减缓边沿（源端串小电阻）、降低驱动强度、开启展频；
3. **断路径**：加滤波（磁珠/电容/共模电感）、加屏蔽罩、地平面缝合；
4. **保受体**：接口加 ESD/浪涌防护、敏感信号远离干扰源并包地。

记住顺序是"定位 → 源头 → 路径 → 受体"，不要一上来就乱贴磁珠乱加电容——没定位的整改是碰运气。

### 19.2 SI 信号完整性：反射、串扰、损耗与端接

下面的传输线仿真使用 CircuitJS 的 [端接示例](https://github.com/pfalstad/circuitjs1/blob/master/ts/public/circuits/tlterm.txt)：四条理想 75Ω 传输线分别比较 75Ω 匹配、10kΩ 高阻、10Ω 低阻负载，以及低源阻抗配高阻负载。观察波在线路中往返与端点反射；这是理想传输线示范，不能直接代表某块 PCB 的波形或端接数值。

```circuitjs

```

**是什么**：SI（Signal Integrity，信号完整性）研究信号在传输过程中波形是否还"像它自己"。低速板不需要太操心 SI，但 DDR、HDMI、百兆/千兆网这类信号，走线要按"传输线"对待。

**反射（Reflection）——阻抗突变**：信号遇到阻抗变化就反射，反射系数 Γ = (Z₂ − Z₁)/(Z₂ + Z₁)。常见突变原因：走线宽度变化、过孔、分支桩线（stub）、参考平面切换、跨分割。经验判断：当走线延时超过信号上升沿时间的 1/6 左右，就要按传输线处理，认真做阻抗匹配（经验阈值，精确判定以仿真为准）。

**串扰（Crosstalk）——线与线互相干扰**：通过寄生电容（容性耦合）和互感（感性耦合）传递。三条经验对策：

1. **3W 规则**：线中心距 ≥ 3 倍线宽（即线间净间距 ≥ 2 倍线宽），经验上能显著削弱相邻线耦合（常被引用为约 70%，具体以仿真/实测为准）；对关键信号可放宽到 4W~5W。
2. **相邻信号层走线垂直**：一层横向、一层纵向，减少平行重叠面积。
3. 关键信号（时钟、复位）两侧包地 + 地过孔隔离。

**损耗（Loss）**：长走线的导体损耗（趋肤效应，频率越高电流越集中在表面）与介质损耗随频率增大。对策：长线适当加宽、高频高速场合评估低损耗板材（普通 FR4 与高频板材的 Df 差异明显，选型以板材规格书为准）。

**端接（Termination）策略**：反射治不了就"吸收"它。

| 端接方式 | 做法 | 优点 | 缺点 |
|:---|:---|:---|:---|
| 串联端接 | 源端串电阻（常见 22~33Ω 经验值，按阻抗差算） | 省功耗、最常用 | 只适合点对点 |
| 并联端接 | 末端接电阻到地或电源 | 匹配好 | 持续漏电流 |
| 戴维南端接（Thevenin） | 末端上下两电阻分压 | 兼容性好、匹配稳 | 静态功耗更大 |
| AC 端接 | 末端串电容再接电阻 | 无直流功耗 | 只适合特定总线/时钟 |

**阻抗控制（Impedance Control）——匹配的前提**：单端走线常见目标 50Ω 左右，由线宽、介质厚度、介电常数共同决定。微带线（Microstrip，表层走线）与带状线（Stripline，内层夹在平面之间）的计算模型不同——同一阻抗在不同层的线宽不一样。实际操作流程：定层叠 → 用 EDA 自带阻抗计算器或板厂提供的阻抗计算工具算出各层线宽 → 下单时勾选"阻抗控制"，由板厂按层叠微调保证。理解了这一点，你就明白"走线随意换层"为什么等于阻抗突变。

**回流路径（Return Path）——SI 的灵魂**：高频电流走"感抗最小"的路径，也就是**信号正下方的参考平面**。由此推出本课最重要的一条纪律：

> 信号线下方的参考平面必须完整。跨分割、换参考层、参考平面被挖洞，都会迫使回流绕远路，形成大环路——SI 变差、串扰变大、EMI 变强，三个问题一起爆。

换层时如果参考平面从地层换到电源层，在过孔旁放一个缝合电容（接地/接电源）给回流一条低阻抗通路。

### 19.3 PI 电源完整性：让芯片每一纳秒都"吃得上电"

**是什么**：PI（Power Integrity，电源完整性）研究从电源芯片到芯片内部晶体管这整条供电网络（PDN，Power Delivery Network，电源分配网络）能否在芯片电流快速变化时仍把电压稳定在允许纹波内。

**PDN 阻抗与目标阻抗**：工程师用"目标阻抗"量化 PI 要求——

```
Z_target = (电源电压 × 允许纹波百分比) / 瞬态电流变化量
```

设计目标是让**全频段**内 PDN 阻抗都低于目标阻抗。频率从低到高分别由 VRM（电源芯片）、板级电容、平面电容、芯片封装内电容接力承担，任何一段"掉链子"都会出现一个阻抗尖峰，对应频段的噪声就会超标。

**去耦电容搭配（数量、容值、摆放）**：

1. **大小容值组合**：大容值（如 10µF/22µF）管低频储能，小容值（如 0.1µF/0.01µF）管高频去耦——电容实际是"电容 + ESR + ESL"的串联结构，安装电感决定了它的高频有效性，不是"多并几个大电容"就能解决高频问题。
2. **摆放**：最小容值的电容最靠近芯片电源管脚，大电容可稍远、放在电源进入区域；每个（组）电源管脚附近都要有电容，数量与组合**优先按芯片手册 Layout 章节的推荐执行**。
3. **接地要"就近且粗"**：电容电源/地焊盘到过孔的距离尽量短，条件允许时一个焊盘打两个过孔，比电容本体更靠近谁更有效。
4. 电容之间避免"共享一条细长的地过孔链"。

**电源平面谐振（Cavity Resonance）**：电源平面与地平面构成谐振腔，在某些频段会把边缘当成天线向外辐射，造成 EMI 问题。对策：合理布置去耦电容打乱谐振模式、板边地过孔缝合、必要时平面内缩（见 20H 原则）。

**平面分割的利弊**：分割电源平面可以把"脏电源"与"干净电源"隔离（如数字 3.3V 与模拟 AVDD），但分割边界会切断信号的回流路径。原则：分割边界尽量放在没有高速线穿过的区域；跨越时优先重新规划走线和参考层；是否需要及如何设置跨平面回流连接，须根据电源域、电路功能和具体回流路径设计，不能随意用磁珠或 0Ω 跨接不同电源轨。

**6 层板层叠参考示例**（仅示意思路，具体以阻抗计算结果与板厂叠构确认为准）：

| 层 | 用途 | 设计意图 |
|:---:|:---|:---|
| L1 | 信号（器件面） | 表层走关键信号，紧邻 L2 完整地 |
| L2 | 地（GND） | L1 的完整参考平面 |
| L3 | 信号 | 带状线层，适合走高速线 |
| L4 | 电源（PWR） | 与 L5 地平面紧耦合 |
| L5 | 地（GND） | 主参考地平面 |
| L6 | 信号（底层） | 常规走线与低速信号 |

层叠设计的通用思路：每个信号层都紧邻完整参考平面；电源平面与地平面相邻（层间距压小）以提高平面间电容、改善 PI；多个地平面之间打地过孔缝合，并联降低整体地阻抗。层数与排布永远在成本与性能之间做取舍。

### 19.4 高速信号完整性综合：眼图、等长、差分

**眼图（Eye Diagram）**：把高速比特流按单位间隔（UI）在示波器上无限叠加，得到"眼睛"状的图形。眼睛张得越开（眼高越大=噪声容限大，眼宽越大=抖动小），信号质量越好；抖动（Jitter）和噪声会让眼睛"闭合"。眼图是仿真软件（如 Sigrity 类工具）与示波器通用的语言，面试考概念时能画出示意图并解释眼高/眼宽即可。

**等长与等延时**：DDR、RGB 屏线、MIPI 等并行/高速总线要求组内信号"同时到达"。但严格说**等长只是手段，等延时才是目的**——不同层、不同线宽的走线单位长度延时不同，精细设计按延时匹配。实操规则：

1. 以芯片手册/控制器参考设计给出的误差范围为准（不同总线宽严差异很大，例如 DDR 数据组与时钟的相对偏差通常在百皮秒级、对应的长度误差常控制在几十 mil 量级——均为经验量级，以手册为准）。
2. 常用手法：蛇形绕线（serpentine）。绕线区的线间距、绕线幅度会影响延时与串扰，不要紧贴着绕；绕线放在有余量的区域，且同组尽量同层。
3. 差分对内等长要求远比组间严格，先保对内再保组间。

**差分对（Differential Pair）完整性**：

1. **差分阻抗**：USB 常用 90Ω、以太网常用 100Ω 是常见经验值，实际以接口规范与板厂阻抗计算为准（下单时可选阻抗控制工艺，由板厂按层叠保证）。
2. **紧耦合 vs 松耦合**：紧耦合（线间距小）抗共模干扰好，是主流做法；松耦合用于大功率差分或特殊场合。
3. **对称性**：两根线同层、同长、少打孔、打孔也成对对称，避免一处走粗一处走细。
4. **对内等长**：对内偏差控制在远小于组间偏差的量级（经验上几个 mil 以内，以规范为准）；**对间间距** ≥ 3W 或按规范拉开。

**DDR 等长布线实操要点（项目中最常见的等长场景）**：

1. **分组**：数据线按字节分组（DQ/DQS/DM 同组），地址/控制/时钟归另一组；组内误差要求严、组间宽松，具体公差以控制器手册的长度匹配表为准；
2. **先定拓扑**：是点对点直连还是 Fly-by 串联拓扑，拓扑定了再谈等长；桩线（Stub）越短越好；
3. **绕线手法**：蛇形绕线放在同层、有余量的区域，绕线间距适当加大避免自耦合，不要为了等长把线绕成密密麻麻的"弹簧"；
4. **过孔一致**：同组信号的过孔数量尽量一致——每个过孔的延时与寄生电容不同；
5. **工具终验**：用 EDA 的等长检查规则（如 Matched Lengths）跑报告，而不是肉眼估计。

### 19.5 DFM 可制造性设计：让产线造得出你的板

**是什么**：DFM（Design for Manufacturability，可制造性设计）——设计阶段就按工厂能力来画，避免"画得出来、造不出来、造得贵"。

**板厂工艺能力**（常见打样厂典型值，**必须以你所选板厂的能力表实时为准**，先进工艺可更小但加价）：

| 项目 | 常见能力/经验值 | 说明 |
|:---|:---|:---|
| 最小线宽/间距 | 常见 3.5~4mil 可做 | 不是"能画多细"而是"造得起多细"，越细越贵 |
| 最小机械钻孔 | 常见 0.2mm，0.15mm 级加价 | 更小需激光孔（HDI 工艺） |
| 过孔焊盘环形宽度（Ring） | 经验 ≥0.15mm | 太小钻孔偏心就破环 |
| 阻焊桥（Solder Mask Dam） | 经验 ≥0.1mm | 焊盘间距过近时桥造不出来，可能连锡 |

**阻焊与丝印**：

- 阻焊桥：相邻焊盘之间保留的阻焊隔离带；间距太近的密集焊盘要主动放大间距保桥。
- **丝印不许压焊盘**：丝印油墨落在焊盘上会影响可焊性，输出光绘前用 DFM 检查项筛一遍。
- 丝印字号建议高度不小于约 0.8mm（经验值，以板厂为准），否则印刷模糊；极性标、一脚标、接口名必须清晰。

**拼板与工艺边**：小板批量生产时拼板（Panelization），四周留工艺边（经验 5mm 左右，以贴片厂要求为准）；连接方式用 V-CUT（直线分板，省成本）或邮票孔（异形板/应力敏感板）。工艺边上按产线要求加定位孔与光学点（Mark 点）。

**测试点（Test Point）**：批量要做 ICT（In-Circuit Test，在线测试）就得预留测试点——经验直径约 1mm、中心间距 ≥2mm 量级（以测试厂治具能力为准）；测试点不能被屏蔽罩/散热器挡住；BGA 区域底下无法探测的网络要靠 X-Ray 或 FCT 兜底。

**AOI / X-Ray**：AOI（Automated Optical Inspection，自动光学检测）检查贴件、极性、外观，替代目检；X-Ray 穿透检查 BGA 等看不见的焊点（空洞、桥连、偏移）。设计时要给 BGA 焊球阵列的"看视角度"留出邻位空间（周边至少一排无高大元件），具体以产线要求为准。

### 19.6 爬电距离与电气间隙：安规的硬指标

**是什么**：这是强电/隔离电源设计的"保命尺寸"。

- **电气间隙（Clearance）**：两导体之间**空气中的最短直线距离**，防的是击穿放电。
- **爬电距离（Creepage）**：沿**绝缘表面**的最短距离，防的是表面漏电起痕（灰尘受潮后沿面爬电）。

**一次侧/二次侧（Primary/Secondary）**：隔离电源里接市电的一次侧与安全超低电压的二次侧之间，必须满足相应绝缘等级（基本绝缘/附加绝缘/加强绝缘）的间隙与爬电要求。**经验数值仅作量级参考**：老标准（IEC/GB 60950 时代）中 250V 系统一次侧对二次侧的加强绝缘常被引用为爬电约 6.4mm 之类的数值；现行标准（如音视频/信息技术设备的 IEC/GB 62368-1、信息技术设备安全 GB 4943 类标准）的取值随工作电压、污染等级、材料 CTI、绝缘等级变化——**实际设计必须查现行标准原文并按认证机构（如 CQC/UL/TÜV）要求执行，不可背一个数走天下**。

**设计手法**：

1. 高压区与低压区**分区布局**，一、二次侧之间拉距离；
2. 距离不够时在两者之间**开槽（挖孔/开窗）**，用空气拉长爬电路径（开槽位置不能破坏结构强度）；
3. 变压器、光耦、Y 电容等跨隔离器件自身提供隔离，其爬电要求同样按标准；
4. 高压走线加宽、远离可触碰部位，加危险警示丝印；
5. 保险丝之后的走线按故障电流考虑载流能力。

**安规间距设计措施速查**：

| 目的 | 设计措施 |
|:---|:---|
| 拉大电气间隙 | 一、二次侧分区布局，高压走线相互间距加大 |
| 拉长爬电距离 | 在分界区开槽（挖长条孔/开窗），让沿面路径变长 |
| 靠器件隔离 | 变压器、光耦、Y 电容等跨隔离器件按绝缘等级选型（规格书有标注） |
| 让人看得见 | 高压区丝印警告标识，一次侧区域轮廓丝印标出 |

### 19.7 电源平面分割与 20H 原则

**分割岛（Power Island）**：一层电源平面被划成多块，分别给不同电压域供电。要点：

1. 每个电压域的岛要包住自己的用电区域，岛大小按电流与去耦需求留够；
2. 岛与岛之间留出间隙（经验 1~2mm 量级，兼顾工艺与隔离，以设计规范为准），边界避开高速走线；
3. **跨分割走线是大忌**：信号跨过电源平面的分割沟，回流路径被切断——阻抗突变、振铃、EMI 全来了。路由前先规划哪些信号会跨域，要么改层、要么加桥接缝合电容。

**20H 原则**：电源平面相对相邻的地平面**内缩 20 倍层间介质厚度**，让板边的电源-地边缘场不至于外泄，抑制边缘辐射。这是流传很广的经验规则；在实际高速设计中其效果与层叠、频率相关，业界对有效性有讨论，可作为了解并在有条件时结合仿真/实测验证，不必教条执行。

### 19.8 模数混合设计：数字地、模拟地、大电流地

**为什么要分地**：数字电路的开关噪声通过共用地阻抗耦合进模拟小信号（ADC 一个 LSB 可能只有毫伏甚至微伏级），所以地的"纯净度"直接决定精度。

**分地三原则**：

1. **先分区，再分地**：布局上把数字区、模拟区、大电流区（功放/电机/电源功率级）物理分开，地自然就分开了；分地治不了布局混乱的病。
2. **单点连接**：优先按芯片手册规划完整参考地与布局分区；如确需分地，连接位置和回流路径应依具体电路设计，而非固定单点；大电流地单独走，最终汇到电源地，不让大电流流经模拟地。磁珠/0Ω 电阻可以用于地的连接，但要理解它是"高频阻抗、直流近似导通"，不能替代正确的拓扑。
3. **跨界的芯片跨在地界上**：ADC/DAC 一只脚踩数字区一只脚踩模拟区——数字引脚朝向数字区布线、模拟引脚朝向模拟区布线，不要让数字信号穿越模拟区。

**ADC/DAC 布局要点**：

1. 参考电压（VREF）是精度的命根子：VREF 去耦电容按手册要求紧贴管脚，参考源走线短、粗、远离干扰；
2. 模拟输入信号线短而直，两侧包地，远离晶振、SW 节点、时钟线；
3. 模拟区铺铜完整、多打地过孔；晶振布局在数字侧；
4. 数字电源与模拟电源之间按需用磁珠隔离，但大电流场合慎用磁珠（直流电阻压降与饱和问题）。

**一句话总结本课**：EMC 讲"源—路径—受体"，SI 讲"阻抗—回流"，PI 讲"目标阻抗—接力去耦"，DFM 讲"按工厂能力画"，安规讲"距离就是安全"，模数混合讲"分区+单点"。所有经验数值都以现行标准（如 IPC 系列与国标安规类标准）与板厂/产线实际能力为准。

## ⚠️ 新手常见坑

1. **把 EMC 当"最后补丁"**：Layout 完成后才想加屏蔽罩、加磁珠。EMC 的 80% 在布局布线阶段就已决定，回来改的成本是设计期的数倍——布局时就把"源—路径—受体"想清楚。
2. **盲目分地**：听说要分地就把地割得七零八落，结果数字信号跨分割、回流绕大圈，EMC 反而更差。正确顺序是先分区布局，再谈分地，且单点连接。
3. **去耦电容乱摆**：电容放在"有空的地方"离芯片两三厘米，高频去耦形同虚设。记住经验法则：0.1µF 级电容到芯片电源管脚的距离通常控制在几毫米内，越近越好。
4. **等长教条化**：为了等长满板蛇形线，绕出大量耦合与延时误差。等长是手段不是目的，蛇形线的耦合效应和"同层同宽"优先级要心里有数，误差范围以芯片手册为准。
5. **拿别人的数值当圣旨**：6.4mm、3W、λ/20、1/6 上升沿……全是经验起点。不同电压等级、不同污染等级、不同板厂，取值都会变，最终以现行标准与板厂能力表为准。
6. **丝印/阻焊细节不检查**：丝印压焊盘、阻焊桥缺失、Mark 点遗漏，打样能过、量产必翻车。输出光绘前务必跑一遍 DFM 检查（见第 15 课）。
