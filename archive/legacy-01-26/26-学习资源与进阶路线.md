# 第 26 课 · 附录：学习资源与进阶路线

> **所属阶段**：阶段五 · 选修与职业发展
> **前置课程**：无（配合任意课程使用）
> **本课难度**：⭐

## 🎯 本课目标

学完这一课，你应该能够：

1. 在学习的每个阶段，快速找到与之匹配的免费视频教程、官方文档和书籍
2. 知道去哪里找开源参考工程（原理图 + PCB 源文件）和社区求助渠道
3. 根据先修关系与阶段成果制定适合自己的学习计划
4. 入行后知道朝哪些方向持续进阶（高速 / 射频 / 电源 / 团队管理）

## 📖 正文

本课是整套课程的"资源地图"，资源可能变更、收费或失效；使用前核实当前链接、费用、版本和许可，再选择适合自己的资料。

**用开源工程的正确姿势**：先自己画一遍，再对照开源工程找差距——直接照抄学不到东西，但"抄后再对比"是最高效的提升手段。

### 26.5 按成果推进，而非按时间推进

跟随 README 中的学习顺序，完成电路计算、简单板、MCU 项目和模块分析等阶段成果。遇到知识缺口及时回看对应章节；资源用于补充当前问题，不必同时追完全部教程。高速项目在资料、工具和工艺满足条件后再开展。

### 26.6 入行后的进阶方向

- **高速数字**：Bogatin 全书 → Fedevel 付费进阶课 → 10Gbps+ SerDes/DDR5 项目
- **射频/无线**：史密斯圆图与匹配网络 → 天线设计 → WiFi/BT/4G/5G 产品
- **电源专家**：LTspice 深度仿真 → 大功率/高密度电源（填孔盘上过孔 POFV 散热、多相）→ 高功率密度电源（服务器电源、汽车 OBC）
- **模拟/传感**：低噪声设计、精密测量、ADC/DAC 系统
- **技术管理**：设计规范制定、DFM 体系建设、带团队与供应商管理

持续学习的两个习惯：**每周精读一份芯片数据手册**；**每个项目复盘沉淀一页经验**——五年后你和别人的差距就在这两个习惯里。

## ⚠️ 新手常见坑

1. **收藏 ≠ 学会**：资源收藏夹满满、一课没学完是最常见的"学习幻觉"。选定一条主线（本课程），资源只做配菜。
2. **教程囤积症**：入门教程看三套不如跟一套做完所有练习。同一主题的视频超过两套就该警惕。
3. **只看不做**：PCB 是手上功夫，每课的动手练习是主线不是选修。
4. **迷信付费课**：入门到就业所需的内容网上免费资源完全覆盖；付费的价值在于督学与答疑，不是内容本身。
5. **追新版本教程**：AD19 和 AD25 的核心操作差异极小，不必非等最新版教程——软件操作只占 PCB 能力的一小部分。
