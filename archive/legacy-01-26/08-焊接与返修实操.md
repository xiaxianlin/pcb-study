## 🎯 本课目标

1. 配齐一张规范焊接工位，说得出每样工具的用途、参数与适用场景；
2. 掌握插件件三步法、贴片两步法、QFP 拖焊与 QFN 底部散热焊盘处理，能结合焊料和工艺要求进行目检；
3. 会用热风枪、吸锡带完成拆片、焊盘清理与焊盘/走线修复（飞线）；

5. 按"复现→定位→拆换→复测→记录"流程完成一块不良板返修并填写返修记录表；
6. 养成通风、焊后洗手、防静电、防烫伤的操作习惯。

#### 08.1.1 电烙铁：恒温 + 对口的烙铁头

选**恒温（温控）电烙铁**。关键指标不是功率而是回温速度：焊大焊盘时烙铁头温度会被"吸走"，回温慢的烙铁焊着焊着就"焊不动"了。功率、烙铁头形状和热响应需匹配焊点与板材，不能仅凭功率保证覆盖所有作业；老式"插电直热式"烙铁温度随负载大幅漂移，不建议用于贴片。

**烙铁头型号怎么选：**

| 烙铁头类型 | 形状特点 | 适用场景 |
|---|---|---|
| IIS / 细尖头 | 尖细、传热集中 | 0603/0402 小焊盘、IC 单脚补焊、修连锡 |
| 刀头（K 型） | 刃口宽、储热大 | QFP 拖焊、多引脚同时加热、粗导线上锡 |
| 斜面头（B/C 型小斜面） | 接触面适中，万金油 | 插件件、0805 等常规焊点 |

**温度设置参考表**（经验值，具体以所用焊锡丝规格书与烙铁说明书为准）：

| 焊接对象 | 参考温度 | 说明 |
|---|---|---|
| 含铅锡丝（Sn63Pb37）常规焊点 | 300~330 °C | 熔点约 183 °C，留足过热余量 |
| 无铅锡丝（SAC305 等）常规焊点 | 350~380 °C | 熔点约 217 °C，温度不足必出"豆腐渣"焊点 |
| QFP 拖焊（无铅） | 360~380 °C | 需持续熔锡，回温差的烙铁拖到一半就凝固 |
| 大面积地焊盘 / 粗引脚 | 依焊料、焊台及板材调试 | 优先改善烙铁头接触和预热，避免无依据地提高温度或延长加热 |

**保养口诀：用完挂锡再上架。** 烙铁头在高温下裸露会快速氧化发黑（俗称"烧死"），烧死的头不挂锡、传热差。每次用完在铜丝清洁丝上蹭几下，再挂一层新鲜锡保护镀层。湿海绵擦头别太勤——温度骤缩骤胀伤镀层。

烙铁头已经轻度氧化时的抢救步骤：

1. 按烙铁头厂商说明，使用适合的清洁工具或活化剂，避免用砂纸打磨破坏保护镀层；
2. 在合适温度下清洁后重新挂锡；
3. 仍不能润湿时更换烙铁头，避免反复高温损伤焊盘。

#### 08.1.2 热风枪：风温 + 风量双旋钮

热风枪靠热风整体加热焊点，用于拆装贴片件。两个旋钮要一起调：**风温决定锡是否熔化，风量决定热量传给谁**——风量过大，0402 会整颗被吹飞。

风嘴选择：小圆嘴（拆 0402~SOT 封装）、大圆嘴（拆 QFP/QFN/SOP）、扁嘴/屏蔽罩嘴（拆屏蔽罩、大连接器）。

**拆片温度/风量经验表**（以设备说明书标称为准，先在废板上试）：

| 拆卸对象 | 风温 | 风量 | 加热时间参考 |
|---|---|---|---|
| 0402/0603/0805 | 300~330 °C | 低档（1~3 档） | 5~10 s |
| SOT-23 / SOT-89 | 320~340 °C | 中低档 | 10~15 s |
| QFP / SOP / QFN | 330~360 °C | 中档 | 30~60 s，画圈均匀加热 |
| 屏蔽罩 / 大连接器 | 350~380 °C | 中高档 | 60 s 以上，注意烫伤周围塑料件 |

补充两点：一是拆**双排/四排引脚的连接器、屏蔽罩**这类大热容器件时，可在引脚区预涂助焊剂帮助传热，时间宁可靠表的下限慢慢试，别一步到位开高温；二是拆**排线座、SIM 卡座**等带塑料件的器件，塑料软化温度比锡低得多，必须用最低可行温度+最短时间，拆下后检查塑体有无变形再决定是否复用。

#### 08.1.3 吸锡带与吸锡器

- **吸锡带（desoldering wick）**：浸过助焊剂的编织铜带，贴在焊盘上用烙铁加热，熔化的锡被毛细作用"吸"进带里。用于清理贴片焊盘、拆 IC 后清残锡。
- **吸锡器（吸锡枪）**：手动真空泵，先加热熔化插件焊点的锡，再按按钮把液态锡抽走。用于插件孔退锡、拆卸直插元件。

#### 08.1.4 镊子：直头与弯头

直头镊子用于夹持元件放入焊盘；弯头镊子俯视操作时手不挡视线，适合在放大镜下做精细定位。选防静电型号，夹尖端要能紧密闭合、无错位。

#### 08.1.5 焊料与助焊剂：含铅 vs 无铅

| 对比维度 | 含铅 Sn63Pb37 | 无铅 SAC305 |
|---|---|---|
| 熔点 | 约 183 °C | 约 217 °C |
| 手感 | 润湿快、光泽亮、好上手 | 需要更高烙铁温度，润湿慢 |
| 健康/法规 | 含铅，废弃按当地要求处理 | 是否符合 RoHS 取决于成分及适用豁免；量产要求按产品法规和工艺确认 |
| 练习建议 | 新手找手感可以先用 | 最终要按工厂标准练无铅 |

**助焊剂（flux）**是手工焊接的"外挂"：去掉氧化层、降低表面张力。免洗型笔式助焊剂日常够用；拖焊、拆 QFN 时用膏状助焊剂更持久。**锡膏**是焊料粉与助焊剂的混合物，可按工艺用于印刷与返修。储存温度、回温时间、开封寿命和搅拌方式应遵循具体产品说明，不同锡膏要求不同。

锡膏使用注意：按产品要求密封保存和回温，避免冷罐开盖结露；依说明决定是否搅拌，并记录开封时间和可使用期限。过期或受污染的锡膏不能继续使用。

#### 08.1.6 锡炉与放大设备

**锡炉**是一锅熔化的锡，把成排引脚插进去一次完成上锡或退锡，量产插件线常用，学习阶段了解即可。**放大镜台灯**（5~10 倍）用于日常目检；**体视显微镜**（7~45 倍连续变倍）检查 0402、QFN 焊点和修连锡时几乎是必需品——很多虚焊肉眼根本看不出来。

**基础练习的完整过程**

先确认工位通风、工具状态、器件型号及极性；在废板或练习板上按“清洁焊盘 → 固定元件 → 加热焊盘和引脚 → 送适量焊料 → 撤离并等待凝固 → 放大检查”的过程练习。贴片件可先固定一端、确认对齐后再焊另一端；插件件要确保器件贴合且引脚受热充分。出现连锡时先断电，使用适当助焊剂和吸锡带处理，避免拉扯焊盘。

验收时检查方向、对齐、润湿、桥连、少锡和焊盘损伤，并结合电路做断电连通检查；外观良好不等于电气可靠。返修采用适合器件与板材的温度和时间，先在废板练习。原资料的工具与工序可参考 [电子焊接训练](https://wiki.lceda.cn/zh-hans/contest/e-contests/basic-training/welding-training.html)。

### 08.2 手工焊接基本功

先立一条总原则：**焊点是"加热被焊面、让锡自己流上去"形成的，不是把锡抹上去粘住的。** 烙铁同时加热引脚和焊盘两个被焊面，锡送到位后靠润湿作用铺开——理解了这句，下面所有手法都只是它的变体。

#### 08.2.1 插件件三步法

1. **插装**：器件插正、贴板（或按工艺要求留 1~2 mm 应力间隙），弯脚固定防掉落；
2. **加热**：烙铁头同时压住引脚与焊盘，接触 1~2 s，让两个被焊面一起升温；
3. **送锡撤离**：在烙铁接触点送锡 0.5~1 s，见锡顺润湿角铺满焊盘后**先撤锡丝、后撤烙铁**，烙铁沿 45° 方向快速撤离，避免拉出锡尖。

| ✔️ 正确手法 | ❌ 错误手法 |
|---|---|
| 烙铁同时压引脚 + 焊盘 | 只烫引脚或只烫焊盘，另一面没热，锡不流 |
| 先撤锡、后撤铁，撤离干脆 | 锡丝和烙铁一起拽走，拉出毛刺锡尖 |
| 加热 1~2 s 即送锡 | 长时间干烧焊盘，阻焊发白、焊盘翘起 |
| 焊完目检：焊点呈裙状包裹引脚 | 焊点是个"锡疙瘩"盖在上面，一撬就掉 |

检查外观时观察润湿、焊料量、桥连、引脚与焊盘；光亮或亚光均不能单独判定焊点可靠性。具体接受标准应结合焊料、封装、适用等级和检验规范。

焊完全部引脚后再统一做收尾：剪掉过长的插件引脚（留 1~2 mm，剪口朝外防飞溅伤眼）；检查板底无锡珠散落；残留物是否清洗取决于助焊剂、板材、连接器及产品工艺；先查材料兼容性和清洗要求。若需清洗，使用指定清洗剂、断电操作并充分干燥后再测试。

#### 08.2.2 贴片两步法：先吃锡，再定位

1. **第一步——吃锡**：先在一个焊盘上熔一小颗锡珠（约焊盘大小的 1/3~1/2）；
2. **第二步——定位补锡**：左手镊子夹元件按丝印方向放到焊盘上，右手烙铁熔化锡珠同时接触元件端头，元件被锡的表面张力"吸"到位后撤铁；再给另一端焊盘送锡补焊，补锡时烙铁轻碰元件端头与焊盘交界处。

练习路线：先焊 0805 五十颗找手感，再降到 0603，0402 选做。**立碑**（元件一头翘起）多因两端加热不均——先焊端先凝固、后焊端回熔时把另一端拉起，手法要点是补焊第二端时动作快、别回头重熔第一端。

从 0805 到 0603 的难点变化要心里有数：0603 本体小、镊子夹持更容易打滑，锡珠也要相应减半；0402 则连"看清端头是否润湿"都需要放大镜，送锡几乎不能直接碰到元件，全靠焊盘上的锡量控制。逐级练的意义就是让每个动作的"分辨率"提上去。

| ✔️ 正确手法 | ❌ 错误手法 |
|---|---|
| 一端定位、一端补焊，两步走 | 两端同时送锡，元件被夹在中间对不准 |
| 锡量以能看到元件端头轮廓为准 | 锡堆成山，元件"淹死"看不见方向 |
| 镊子轻压元件中部定位 | 镊子戳元件边缘，一压就飞 |
| 发现位置歪：重熔单端微调 | 冷态硬拨元件，端头脱落报废 |

#### 08.2.3 QFP 拖焊五步法（补细节版）

第 14 课焊 STM32（LQFP48）时走过一遍流程，这里补足手法参数——拖焊是"助焊剂的表演，锡只是配角"：

1. **对角定位**：烙铁熔锡先固定对角两个引脚，显微镜/放大镜下确认四方引脚均落在焊盘中央，歪了就重熔对角微调；
2. **涂助焊剂**：引脚区整体薄涂一层膏状助焊剂，量以"覆盖引脚、能看见引脚轮廓、不汪成水洼"为准——太少拖不动，太多锡乱跑；
3. **刀头挂锡**：刀头清洁后在锡丝上蘸一下，刃口挂一层薄锡，不是挂一大滴；
4. **拖焊**：刀头刃口平贴引脚，与芯片边呈 30~45° 夹角，从引脚根部向尖端方向、以 2~5 mm/s 匀速一次性拖过整边，中途不停顿、不回拖；
5. **检查补焊**：放大镜下逐脚检查，发现连锡就在该处补点助焊剂再用刀头轻拖一次——助焊剂激发表面张力，会把多余的锡"带走"收回到刀头上。

| ✔️ 正确手法 | ❌ 错误手法 |
|---|---|
| 助焊剂足量、边涂边拖 | 干拖（无助焊剂），越拖越桥连 |
| 匀速一次拖完一边 | 反复来回蹭，把成型焊点搅成锡渣 |
| 刀头与板面小角度贴引脚 | 刀头立起来"戳"引脚，勾弯引脚 |
| 连锡靠助焊剂二次拖走 | 用尖头硬挑锡桥，挑断引脚 |

补充：连锡修理三招（按顺序试）——

1. **补助焊剂再拖**：在连锡处点一滴助焊剂，刀头轻挂薄锡慢拖一次，表面张力会把多余锡带走（成功率最高）；
2. **尖头吸锡**：刀头清洁后不挂锡，用干净尖头点住锡桥，熔化后多余的锡会爬到尖头上被带走；
3. **吸锡带定点**：细吸锡带盖住锡桥，加助焊剂后烙铁轻压一秒——只在锡桥很大时用，注意别带歪正常引脚。

#### 08.2.4 QFN/DFN 底部散热焊盘处理

QFN/DFN 的端子位于封装底面或侧边；部分器件带中央**裸露焊盘（EP）**。EP 的电气网络和散热要求因型号不同，必须查手册，不能默认接地。以下只说明工艺思路，量产或可靠性要求较高的板应按器件与装配工艺验证：

1. 依器件和装配建议设计钢网开口及锡膏覆盖率；锡量过多可能顶起芯片，过少可能影响散热与焊接，不能简单认定越少越好；
2. 散热过孔及其塞孔、盖油或开放方案应在 PCB 制造和装配前确定；按器件及板厂建议检查吸锡和空洞风险，不要在焊接时自行用锡堵孔；
3. 芯片对准丝印框（第一脚方向务必核对），四周端子同样薄涂锡膏；
4. 在练习板上按焊料、器件和设备要求控制预热与回流条件；表面张力可能帮助小幅对位，但不能代替正确放置和检查；
5. 冷却后检查可见端子和桥连。底部焊点无法靠手感或一次功能测试确认可靠性；需要时按工艺使用 X-Ray 等检测，并结合电气测试和验收要求。

#### 08.2.5 焊点缺陷速查表：自己给自己当质检

练完每种手法，都要回到这张表自查。目检判据的完整版可参考 IPC-A-610（见延伸学习），下面是手工焊接最常见的七种缺陷：

| 缺陷 | 外观特征 | 常见成因 | 对策 |
|---|---|---|---|
| 虚焊/冷焊 | 焊点发灰粗糙、锡与引脚有分界线 | 被焊面温度不够就送锡；烙铁只碰锡不碰板 | 重新加热补锡；调整烙铁接触位置 |
| 连锡（锡桥） | 相邻焊点被锡短接 | 拖焊锡量过多、无助焊剂 | 按连锡修理三招处理 |
| 锡尖（毛刺） | 焊点拉出尖刺 | 撤离烙铁太慢或方向不对 | 重熔后 45° 快速撤离 |
| 立碑 | 片式元件一头翘起 | 两端加热不均 | 重熔两端复位；补焊第二端要快 |
| 锡过量 | 焊点堆成球看不见元件端头 | 心里没底、怕不牢多送锡 | 吸锡带吸走部分残锡再补 |
| 锡不足 | 焊点干瘪、覆盖不全 | 送锡时间过短 | 清洁后补锡 |
| 焊盘剥离 | 焊盘边缘翘起/缺失 | 温度过高、加热过久、硬撬 | 按 08.3.3 焊盘修复流程处理 |

判断口诀：**看轮廓、看润湿、看贴合**是初步检查；不同焊料的光泽可能不同，外观正常也不能单独保证电气和长期可靠性。接受标准以具体工艺和规范为准。

**从练习板到检查记录**

插件练习可按“核对器件与方向 → 固定 → 同时加热焊盘和引脚 → 送适量焊料 → 等待凝固 → 检查”进行。贴片练习先用镊子定位并固定一端，确认未偏移再焊另一端；QFP 先对准一脚和边界、固定对角，再检查引脚并逐步焊接。焊料成分、温度和工具不同，焊点外观会有差异，不能只凭是否光亮判定合格。

出现桥连，可断电后用适量助焊剂与吸锡带清理，再检查相邻引脚是否导通和焊盘是否受损。拆卸时待焊料充分熔化再轻取器件，不强撬；清理后检查板铜、阻焊及相邻器件，再记录处理前后照片、方法和复测结果。热风枪、加热台与焊台的具体温度、预热和材料兼容性应按设备及元件资料确定；初学先在废板练习。

### 08.3 拆焊与返修

#### 08.3.1 热风枪拆片：温度曲线与保护

1. **拍照**：拆前拍下器件方向（第一脚/极性标记）和周围环境，装回时对照；
2. **保护邻居**：怕热元件（排线、塑料连接器、电解电容、邻近小元件）用**高温胶带**覆盖，大范围防热用**铝箔**弯个挡风罩；
3. **设定参数**：按 08.1.2 经验表设风温风量，装对风嘴；
4. **画圈加热**：风嘴距板 5~10 mm，对器件本体和引脚焊点做小圈匀速移动，别盯一点吹；
5. **起撬时机**：用镊子轻推器件侧面——器件"自己滑移"的一瞬间立即夹走。没滑移就继续加热，**绝不能硬撬**：锡没全熔时撬，焊盘连铜皮一起被撕下来。

| ✔️ 正确手法 | ❌ 错误手法 |
|---|---|
| 画圈均匀加热，推得动才起撬 | 锡未全熔就上镊子撬，焊盘连根拔起 |
| 高温胶带/铝箔保护周围 | 裸吹，把旁边塑料座吹化、小元件吹飞 |
| 拆下器件放金属托盘散热 | 拆下的芯片随手放桌上，烫坏桌面也烫手 |
| 冷却到可安全操作后检查焊盘状态 | 忽略焊盘损伤，直接装新件 |

#### 08.3.2 吸锡带清理焊盘

拆完器件的焊盘上留着一层残锡，不平整就没法焊新件：

1. 剪一段吸锡带，**先在吸锡带上加一滴助焊剂**（最容易被漏掉的一步，没有助焊剂铜带几乎不吸锡）；
2. 干净的烙铁头隔著吸锡带压在焊盘上，感觉到锡"嘶"地熔入带中；
3. 保持轻压，沿焊盘**缓慢拖动**，让吸饱锡的段落移走、新段落接上；
4. 一段吸饱（发亮鼓起）就剪掉换新段，别反复用旧段"刮"焊盘。

| ✔️ 正确手法 | ❌ 错误手法 |
|---|---|
| 加助焊剂、隔带加热、缓慢拖 | 干带直接压上去，吸不动就加大力气 |
| 轻压拖动，让锡自己熔入 | 用力下压来回刮，铲掉焊盘露出基材 |
| 吸饱就剪段换新 | 旧带反复刮，越刮越不吸 |

#### 08.3.3 焊盘与走线修复

返修中焊盘脱落、走线刮断很常见，修复规范如下：

- **焊盘轻度翘边**：先停止加热并评估铜箔、基材和孔壁损伤；能否修复及使用何种修补材料应按返修规范和产品可靠性要求判断，不能直接压回就视为修好；
- **焊盘整片脱落**：刮开焊盘末端走线的阻焊露出铜，先镀锡；取 0.1~0.2 mm 镀锡导线（漆包线去皮挂锡），一端焊在露铜处替代原焊盘，另一端直接上到器件引脚；过孔和孔壁受损时应评估层间连接及可修复性，不要直接穿线替代；
- **断线飞线（jumper wire）规范**：走最短路径；避开高频线、差分线和天线区（见第 19 课信号完整性强化）；飞线两端焊点光亮饱满；跨过长距离用胶点固定，多根飞线并排理顺不交叉；修复完成后结合线长、表笔和被测路径核对通断及相邻网络绝缘；低阻读数不能单独证明高速、功率或可靠性要求合格。

#### 08.3.4 植锡网与植球简介

**植锡网（reballing stencil）**是一块与芯片焊球位一一对应的激光钢片。流程：清理芯片残锡焊盘 → 涂助焊剂膏 → 植锡网对位覆盖 → 刮锡膏填孔 → 热风回流成球 → 脱网检查。**植球（reballing）**指恢复封装底部焊球，可按工艺使用锡膏或预制焊球。这是 BGA/网格封装返修的标准前置工序，新手了解原理即可，精度靠设备，属于专业返修公司的日常。

### 08.4 BGA 认知与返修

#### 为什么 BGA 难

BGA（球栅阵列）的焊点藏在封装底部，普通目检难以检查；装配加热要依器件和工艺控制。X-Ray 可帮助检查桥连、空洞等缺陷，但并不能可靠识别所有虚焊，仍需结合电气和其他检测方法（第 15 课 SMT 工艺一节有讲，这也是链第 16 课做测试验证前必须确认的一环）。

#### 返修台（BGA rework station）工作原理

三个核心部分：

1. **底部预热**：红外或热风给整板预热到 100~150 °C，减小板面温差与变形（受热不均的 PCB 会像薯片一样翘曲，焊球随之断开）；
2. **顶部热风喷嘴**：只对目标芯片局部加热，喷嘴形状与芯片匹配，热风在喷嘴内旋回，不吹偏周围元件；
3. **光学对位系统**：分光棱镜让芯片与 PCB 焊盘两个影像重叠显示，人眼看"十字线对齐"后再贴装，解决"焊点在底下看不见怎么对准"的问题。

整机跑的是**可编程温度曲线**：预热→恒温（活化助焊剂）→回流（峰值）→冷却，模仿回流炉的曲线，只是范围缩小到单颗芯片。

#### 植球/重焊流程概述

拆下不良 BGA → 清理 PCB 焊盘（吸锡带）→ 芯片植球（08.3.4）→ 光学对位贴装 → 曲线回流 → X-Ray 复检空洞率与连锡 → 功能测试。

#### 新手建议：先学"判断"，再谈"动手"

BGA 返修对温度曲线、对位精度、板变形控制要求极高，自学阶段用热风枪吹 BGA 的结局大概率是：板子吹鼓包、焊球内部连锡，一块主板直接报废。正确的目标是学会**判断"是不是 BGA 的问题"**：

- 典型线索：摔落后不开机或故障时有时无可能涉及多种连接或器件问题；不要带电按压芯片、板面或焊球来判断。
- 板级证据：供电、时钟、复位都正常，外围元件无损坏，唯独 CPU/存储器相关功能异常；
- 进一步排查：由具备条件的人员结合 X-Ray、边界扫描、供电波形及其他测试；X-Ray 和功能测试各有盲区，不能凭单一现象确诊 BGA 焊点故障。

判断清楚后，写清故障现象与定位结论，把重焊交给专业返修公司——会判断、会写返修单的工程师，比会吹风枪的更值钱。

### 08.5 出厂不良品返修流程

对应培训机构"不良品返修"模块，也是工厂返修岗（修理技术员）每天的工作。标准流程七步：

1. **接收登记**：核对板号、版本、序列号，记录来料不良描述；板子全程防静电袋取放、上腕带；
2. **复现现象**：按标准测试条件（规定电压、规定工装、规定程序）复现故障——**不复现的板单独标记"待观察"，严禁直接退回**；
3. **定位故障**：按第 15 课故障速查表的顺序排查：电源→时钟→复位→通信，用万用表/示波器逐步收窄范围（仪器操作见第 06 课，第 16 课继续讲测试）；
4. **拆坏件**：拍照留档 → 按 08.3.1 热风枪拆下 → 吸锡带清理焊盘 → 检查焊盘/走线有无连带损伤，有则先按 08.3.3 修复；
5. **换新件**：核对料号、极性/第一脚方向，按 08.2 对应手法焊接（ chip 两步法 / QFP 拖焊 / QFN 刮锡膏）；
6. **复测**：先复测原故障点，再跑整机功能测试，通过后清洗助焊剂残留、烘干；
7. **记录归档**：填写返修记录表，按不良原因分类统计——这些数据是后续设计改进与来料反馈的依据（与第 16 课可靠性验证的失效分析闭环）。

**返修记录表模板：**

| 字段 | 填写示例 |
|---|---|
| 板号 / 版本 / 序列号 | PCB-REV2.1 / S/N 0037 |
| 来料不良描述 | 上电电源灯不亮 |
| 复现条件 | 12 V 适配器上电，100% 复现 |
| 定位过程 | 测 U2 输入与输出，核对使能、负载、短路和外围；确认后再判断器件 |
| 根因 | 示例：经进一步隔离测试确认 U2 失效；仅凭输出 0V 不能定论 |
| 处理措施 | 更换 U2，吸锡带清焊盘后按两步法重焊 |
| 复测结果 | 3.3 V 正常，整机功能测试通过 |
| 返修人 / 日期 | 张三 / 2026-10-26 |

注意：返修超过两次仍不良的板子要升级处理（换人或送工程分析），不要在工位上反复"试运气"；所有返修板复测通过不代表可以免检出厂，要按抽样规则再过一道测试（链第 16 课）。

### 08.6 安全与健康

| 风险点 | 防护措施 |
|---|---|
| 焊接烟雾和残留（助焊剂烟雾、焊料及残留） | 优先使用适用的局部排烟设备并按工作场所要求通风；普通风扇吹离面部不等于有效排烟；**焊后必须洗手才能吃东西**，食物饮料不上工位 |
| 烙铁/热风烫伤 | 烙铁离手回架，热风枪按说明冷却；发生烫伤按当地急救指南处理，必要时及时就医 |
| 静电（ESD）击穿 MOS/MCU | 操作敏感器件戴防静电腕带，腕带紧贴手腕皮肤、接地端接 ESD 地；板子放防静电台垫上操作 |
| 火灾 | 酒精、助焊剂、纸巾远离烙铁与热风枪出风口；下班断电确认 |

再强调一次铅的卫生：铅主要经**手→口**摄入，皮肤接触焊锡本身风险有限，但焊后不洗手就拿东西吃等于"自投罗网"。含铅锡丝剪下的锡渣、吸锡带废料集中回收，不当普通垃圾丢弃。

## ⚠️ 新手常见坑

1. **烙铁温度开到 450 °C 追求"一烙就化"**——焊盘铜皮与基材经不起持续高温，轻则阻焊发白脱落，重则焊盘连根翘起。按 08.1.1 温度表设定；感觉"焊不动"先查是不是无铅锡 + 回温慢的组合问题，不是猛加温度。
2. **热风枪一开最大风量**——0402/0603 直接被吹飞，邻居元件"躺枪"。小件用小风嘴 + 低风量，风枪垂直对准，先在废板上试风再上正板。
3. **带电焊接**——板子不断电就上烙铁，烙铁头漏电/杂散电流可能一击穿一片 MOS 和 MCU。任何焊接/拆焊前：断电、大电容放电。
4. **湿手摸烙铁头"试温"、徒手抓刚拆下的芯片**——300 °C 的金属不需要用皮肤确认，烙铁挂不挂锡、风枪吹多久锡熔，试锡就知道。刚热风拆下的器件和板子余热同样烫人。
5. **无铅锡丝被当成"不好用"**——无铅熔点通常较高，焊接效果还受热容量、烙铁头、助焊剂及氧化情况影响，然后误以为锡丝质量差。先升温、换刀头储热，再评价锡丝。
6. **BGA 盲目自己返修**——拿热风枪对着 BGA 猛吹，大概率高温把板吹鼓、焊球内部连锡，一块主板直接报废。学会按 08.4 的方法判断与写返修单，重焊交给专业返修公司。
